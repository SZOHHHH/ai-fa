# 记号规范（统一符号表）

> [!purpose] 目的
> 论文间符号混乱（开式/闭式、ε/x₀/v-预测、去噪方向不一）是本库要解决的核心痛点。本规范定义全库**标准记号**；任何论文原文的非标准记号，入库时一律改写为本表标准，原文记法记录在公式页的"表示对照表"中。

## 0. 立法原则

1. **领域主流优先**：每条研究线采用该领域最主流学派的记号作为标准（扩散=DDPM 记号，FM=速度场记号，RL=PPO/DPO 记号）。
2. **全局冲突消解**：跨领域符号冲突时，以本表为准改写。
3. **改写留痕**：改写过的记号在公式页"表示对照表"中与原论文记法一一对应。

## 1. 通用记号

| 符号 | 含义 | 备注 |
|---|---|---|
| $\theta$ | 神经网络参数（统一，不用 $\phi,\psi,W$ 泛指参数） | 子网用下标：$\theta_E$ 编码器参数 |
| $f_\theta(\cdot)$ / $h_\theta(\cdot)$ | 神经网络 | |
| $\mathbb{E}_{x\sim p}[\cdot]$ | 期望 | 必须写明采样分布 |
| $\|\cdot\|_2$ | L2 范数 | 平方写 $\|\cdot\|_2^2$ |
| $\nabla_x$ | 梯度（必须带下标指明变量） | |
| $\odot$ | 逐元素乘 | |
| $\mathcal{N}(\mu,\sigma^2)$ | 高斯分布 | 协方差矩阵时 $\mathcal{N}(\mu,\Sigma)$ |
| $D_{\mathrm{KL}}(P\,\|\,Q)$ | KL 散度 | 方向：P 相对 Q |
| $\sigma(\cdot)$ | sigmoid | |
| $[K]$ | 集合 $\{1,\dots,K\}$ | |

## 2. 生成建模（VAE / GAN / 扩散 / 流匹配）

| 符号 | 含义 | 备注 |
|---|---|---|
| $x_0$（或 $x$） | 干净数据样本 | 统一用下标 0 表示"原始"，不用 $x_{\text{clean}}$ |
| $z \sim \mathcal{N}(0, I)$ | 噪声源样本 | FM 中源分布记 $p(z)$，不引入别的字母 |
| $x_t$ | $t$ 时刻中间态 | |
| $t \in [0,1]$ | **归一化连续时间**（全库标准） | DDPM 原文 $t\in\{1..T\}$ 改写为 $t\in[0,1]$；离散步记 $t_i = i/N$ |
| $\epsilon \sim \mathcal{N}(0,I)$ | 加性高斯噪声 | |
| $\epsilon_\theta(x_t,t)$ | 噪声预测网络 | **扩散线的标准预测目标（ε-预测）** |
| $\hat{x}_0$ | 由网络反解的干净样本估计 | |
| $v_\theta(x_t,t)$ | 速度场网络 | **FM 线的标准预测目标** |
| $u_t(x)$ | 目标速度场（边缘场） | FM 目标配对分布 |
| $s_\theta(x_t,t)$ | score：$\nabla_{x_t}\log p_t(x_t)$ | score-based 线标准 |
| $\alpha_t,\ \bar\alpha_t$ | 噪声调度 | $\bar\alpha_t=\prod_{s\le t}\alpha_s$ |
| $q(x_t \mid x_0)$ | 前向过程 | 近似后验统一记 $q$，模型分布统一记 $p_\theta$ |
| $dx/dt = v(x_t,t)$ | ODE 形式 | |
| $dw$ | 维纳过程增量（SDE 用） | |

**去噪方向立法**：前向 = 加噪（$t:0\to1$，$x_0$ 干净 → $x_1$ 纯噪声）。若原论文相反（如 rectified flow 部分记法），入库改写方向并留痕。

## 3. 强化学习与对齐

| 符号 | 含义 | 备注 |
|---|---|---|
| $s,\ a,\ r(s,a)$ | 状态、动作、奖励 | |
| $\gamma$ | 折扣因子 | |
| $\pi_\theta(a\mid s)$ | 策略（语言模型即策略） | prompt 视为 $s$，生成 token 视为 $a$ |
| $\pi_{\mathrm{ref}}$ | 参考策略（对齐线） | SFT 后的初始模型 |
| $V_\pi(s),\ Q_\pi(s,a)$ | 价值/动作价值函数 | |
| $A_\pi(s,a) = Q_\pi - V_\pi$ | 优势函数 | GAE 记 $\hat{A}_t$ |
| $\hat{\mathbb{E}}[\cdot]$ | 批内经验期望 | 与真期望 $\mathbb{E}$ 区分 |
| $\beta$ | KL 惩罚系数 / 温度（按上下文，公式页注明） | |
| $y^+,\ y^-$ | 同一 prompt 下被偏好/被拒绝的回答（DPO 系） | 统一替代 chosen/rejected 各种记法 |
| $\mathcal{D}$ | 数据集 | |
| $\mathcal{I}$ | 指示函数 $\mathcal{I}[\cdot]$ | |

## 4. 训练与目标函数

| 符号 | 含义 | 备注 |
|---|---|---|
| $\mathcal{L}(\theta)$ | 损失（最小化） | |
| $J(\theta)$ | 目标（最大化，RL 惯例） | |
| $\mathcal{L}_{\text{FM}}, \mathcal{L}_{\text{DPO}}\dots$ | 具名损失，用领域标准缩写下标 | 如 FM/DPO/GRPO/ELBO/NCE |
| $\min\max$ | 对抗型目标统一写法 | GAN：$\min_G\max_D$ |

## 5. 变体记录规范

每个公式页必须含"表示对照表"，格式：

| 表示名 | 公式 | 出处记法差异 | 等价性说明 |
|---|---|---|---|
| ε-预测（本页标准） | $\epsilon_\theta = \dots$ | DDPM 原文 | — |
| x₀-预测 | $\hat{x}_0 = \frac{1}{\sqrt{\bar\alpha_t}}(x_t-\sqrt{1-\bar\alpha_t}\,\epsilon_\theta)$ | progressive distillation | 与 ε-预测互相线性等价 |
| v-预测 | $v=\sqrt{\bar\alpha_t}\,\epsilon-\sqrt{1-\bar\alpha_t}\,x_0$ | v-prediction | 同上 |

规则：**标准行只允许一个**，其余全部归入对照表；开式/闭式同理。
