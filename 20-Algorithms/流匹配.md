# 流匹配 Flow Matching

## 1. 定义

**非数学语言**：不学"去噪"，学"搬运"。给数据分布和噪声分布之间修无数条路（每条路连着一个数据点和一个噪声点），训练一个网络知道任意位置、任意时刻该朝哪个方向、走多快（速度场）；生成 = 从噪声出发沿速度场滑到数据区。

**数学语言**：构造插值 $x_t = \alpha_t x_0 + \sigma_t z$，定义条件速度场 $u_t(x_t \mid x_0, z) = \alpha_t' x_0 + \sigma_t' z$，回归学习边缘速度场 $u_t(x_t)$；采样解 ODE $dx/dt = v_\theta(x_t, t)$。

## 教程：学一个速度场（直线轨迹的最小现场）

**第 1 步：插值定义轨迹。** FM 不加噪链，直接定义 $x_t = \alpha_t x_1 + \sigma_t z$（$x_1$=数据、$z$=噪声）：取线性插值 $\alpha_t = 1-t,\ \sigma_t = t$，数据点 $x_1 = 2$、抽 $z = 0$：$x_t = 2t$——**从 0 到 2 的直线**。

**第 2 步：目标速度场。** $v^*(x_t, t) = \frac{dx_t}{dt} = x_1 - z = 2-0 = 2$——**恒定速度**：直线的导数处处相等。训练 = 回归 $\|v_\theta(x_t,t) - v^*\|^2$（与 DDPM 的 ε-回归同构，预测量换成速度）。

**第 3 步：采样 = 解 ODE。** 从 $x_0 = 0$ 出发积分 $\frac{dx}{dt} = v_\theta$：一步欧拉（$t: 0\to1$）直接得 $x = 0+1\times2 = 2$——**直线轨迹一步到终点**（一般情形多步，但轨迹越直步数越少——这是 [[20-Algorithms/矩形流]] 的动机）。

**第 4 步：与扩散的关系。** $x_t = \alpha_t x_1+\sigma_t z$ 正是 DDPM 闭式的推广（[[30-Formulas/DDPM前向过程]] §2：$\alpha_t = \sqrt{\bar\alpha_t}$ 时逐点相同）；FM 学的 $v_\theta$ 就是概率流 ODE 的右端（[[30-Formulas/概率流ODE]] §2 换算表：v-参数化行）——**扩散与流是同一枚硬币的两面，FM 给了更简洁的训练推导**。

**第 5 步：读法。** 扩散的调度/噪声表 = FM 的插值路径选择；"好调度"翻译过来 = "好路径"（直、好积分）——SD3/Flux 一代已把默认配方从扩散挪到 rectified flow。

## 自测

1. 线性插值下 $x_1=2, z=0$ 的轨迹与速度？（$x_t = 2t$ 直线；$v^* = 2$ 恒定）
2. FM 学的速度场与概率流 ODE 什么关系？（就是其右端——v-参数化）
3. 轨迹直的好处？（好积分敢大步跳——步数少；矩形流专修拉直）
4. FM 与 DDPM 闭式的关系？（$\alpha_t = \sqrt{\bar\alpha_t}$ 时插值逐点相同——同一数学不同推导）
