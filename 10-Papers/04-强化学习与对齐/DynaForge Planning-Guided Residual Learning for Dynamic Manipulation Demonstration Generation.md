# DynaForge

## 1. 一句话贡献

动态操作的示范生成器：低频全局运动规划+高频物体中心 IK 组成相位结构化规划先验，残差策略只学"接触边界处的执行级修正"；再配隐式课程——按匹配扰动条件分组做组相对更新、全对/全错组丢弃——训练分布自动钉在能力边界上；九个仿真任务示范生成成功率 41.3%→78.4%，喂出的 DP3 策略真机动态任务 30-60%（DOMINO 对照 0-10%）。

## 2. 核心贡献

- **规划先验的正确切分**：稳定自由空间相位交给低频全局规划（碰撞自由、几何可行），动态接触相位交给高频物体中心 IK（目标位姿定义在物体坐标系、物体一动期望跟一动）——两类方法各用在它强的地方
- **相位门控残差策略**：残差修正只在动态相位激活，规划动作 $a^{\text{plan}}$ 永远在桌面上——RL 只负责先验覆盖不了的接触细节，探索空间大幅缩小
- **隐式课程（无难度表）**：同扰动条件 $\xi$ 下的 rollout 成组，全成功/全失败组没有比较信息、直接退出本轮更新；只剩混合成败组进组相对目标——随着残差变强，"仍混合"的条件自动变难
- **系统级数字**：Can/Bottle 上用 0.73× 的优化器步数（同环境步预算）超过 vanilla GRPO 的最终成功率；800 示范/任务训 DP3，仿真 49.11% vs DOMINO 7.07%

## 3. 方法概要

1. 任务=带相位的程序（每相位给物体中心目标+成功判据+控制模式+残差门）+外部动态条件 $\xi$（场景初始化与物体外生运动）
2. 规划先验：稳定相位低频调路径规划器出全局无碰轨迹；接触相位高频物体中心 IK 逐拍跟踪局部交互几何
3. 残差策略（本体感知 MLP）输出 $a^{\text{res}}$ 修正规划动作，仅动态相位启用
4. 匹配条件分组：同 $\xi$ 组内 GRPO 式组相对更新+能力边界过滤（混合成败组才训）
5. 成功 rollout 存为示范 $\mathcal{D}=\{(o_{0:T}, a_{0:T}) \mid y(\tau)=1\}$，喂下游模仿学习（DP3）并真机部署

## 4. 核心公式

物体中心 IK：

`$^{W}T_{E,t} = {}^{W}T_{O,t} \cdot {}^{O}T_{E}^{\ell_t}$`

**直觉**：期望末端位姿写在**物体坐标系**里（${}^{O}T_E^{\ell_t}$，当前相位的目标），左乘物体当前世界位姿得到世界系目标——物体动，目标跟着动，"追着物体跑"不需要显式预测物体轨迹。这是把"动态性"吸收进坐标系的干净做法。

残差执行+隐式课程：

`$a_t = a^{\text{plan}}_t + a^{\text{res}}_t;\quad \text{组 } G_k \text{ 进更新当且仅当 } 0 < \frac{1}{\lvert G_k \rvert} \sum_{i \in G_k} y(\tau_i) < 1$`

**直觉**：残差形式划定了学习范围——策略不为规划器已经会的部分浪费探索，只在先验的误差残差上做 RL。组过滤再进一步：组内全同（全对/全错）说明这个难度上没有可比较的执行差异，丢弃；剩下的组恰是"同一条件下有人成有人败"——差异只能来自残差策略本身，梯度全部指向它。课程难度由残差能力的成长内生推动，无需手工分级。

## 6. 影响后续

- "规划先验+残差 RL+组过滤"三件套是动态操作数据-scaling 的可复制配方；规划保可行性、残差保反应性、过滤保样本效率
- 隐式课程给出一个通用结论：组相对目标+全同组丢弃=免难度标签的课程学习，任何"按条件分组"的 RL 场景可搬
- 示范质量→下游策略的传导（49.11% vs 7.07%）为"生成器评估应看下游而非生成成功率"再添证据
