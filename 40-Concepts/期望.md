# 期望 Expectation

## 1. 定义（直觉 → 形式）

**直觉**：期望 = 无限次重复实验后的平均值。掷骰子的期望是 3.5——你永远掷不出 3.5，但掷一万次的平均会非常接近它。

**形式**：
$$\mathbb{E}[f(x)] = \int f(x)\, p(x)\, dx \quad\text{(连续)},  \qquad \mathbb{E}[f(x)] = \sum_i f(x_i)\, P(x_i) \quad\text{(离散)}$$

**本库标准记号**：必须写明采样分布下标：$\mathbb{E}_{x \sim p}[\cdot]$ 或 $\mathbb{E}_{t, x_0, \epsilon}[\cdot]$（多变量时）。批内经验平均记 $\hat{\mathbb{E}}[\cdot]$（训练时用有限 batch 估计真期望）。

## 2. 数学形式

关键运算规则：
- **线性**：$\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]$
- **条件期望**：$\mathbb{E}[X \mid Y=y]$：已知 $Y$ 时 $X$ 的平均
- **塔性质（全期望公式）**：$\mathbb{E}[\mathbb{E}[X \mid Y]] = \mathbb{E}[X]$（对分布建模推导极其重要）
- **蒙特卡洛估计**：$\mathbb{E}_{x\sim p}[f(x)] \approx \frac{1}{N}\sum_{i=1}^N f(x_i),\ x_i \sim p$——深度学习损失函数的底层来源

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| 几乎所有训练损失 | $\mathcal{L}(\theta) = \mathbb{E}_{\text{数据}}[\ell(\theta)]$，实践中用 batch 近似 |
| [[30-Formulas/DDPM训练目标]] | $\mathbb{E}_{t, x_0, \epsilon}$：随机抽时刻、数据、噪声三者求平均 |
| [[30-Formulas/条件流匹配损失]] | $\mathbb{E}_{t, x_0, z}$：同样结构 |
| RL | 策略的目标 $J(\theta) = \mathbb{E}_{\pi_\theta}[r]$ |

**训练的本质**：用 batch 平均 $\hat{\mathbb{E}}$ 近似真期望 $\mathbb{E}$，梯度下降把近似最小化。

## 4. 常见误区

- **误区**："期望就是平均"——平均是期望的**估计**，期望是分布的**属性**
- **误区**：期望存在不等于能算出来——高维积分没有解析解，只能蒙特卡洛
- **误区**：$\mathbb{E}[f(g(x))] \neq f(\mathbb{E}[g(x)])$（非线性不可交换，Jensen 不等式的来源）
