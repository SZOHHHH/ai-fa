# 特征值与特征向量

## 1. 定义（直觉 → 形式）

**直觉**：对一个线性变换（矩阵 $$A$$），大多数向量被推得晕头转向（又转又缩）；但存在一些**特殊方向**——变换后**方向不变、只被拉伸 $$\lambda$$ 倍**。这些方向=特征向量，拉伸倍数=特征值。**矩阵的"性格"被它的特征方向完全暴露**。

**形式**：
$$A v = \lambda v \qquad (v \neq 0)$$
求法：$$\det(A - \lambda I) = 0$$（特征方程）解出 $$\lambda$$，再解 $$(A-\lambda I)v=0$$ 得 $$v$$。

## 2. 教程：三步吃透

**第 1 步：手算 2×2。** $$A = \begin{bmatrix} 3 & 1\\ 0 & 2 \end{bmatrix}$$：
$$\det(A-\lambda I) = (3-\lambda)(2-\lambda) = 0 \;\Rightarrow\; \lambda_1 = 3,\; \lambda_2 = 2$$
$$\lambda_1=3$$：$$(A-3I)v=0 \Rightarrow v_1=(1,0)^\top$$；$$\lambda_2=2$$：$$v_2=(1,-1)^\top$$。**验证**：$$A v_1 = (3,0)^\top = 3\,v_1$$ ✓。几何：x 轴方向纯放大 3 倍；(1,−1) 方向纯缩 2 倍——其余方向都被"搅拌"。

**第 2 步：幂迭代——大 $$\lambda$$ 如何统治一切。** 随机向量 $$x$$ 反复乘 $$A$$：$$x, Ax, A^2x, \cdots$$。把 $$x$$ 写成特征向量的组合 $$x = c_1 v_1 + c_2 v_2$$，则 $$A^k x = c_1\lambda_1^k v_1 + c_2\lambda_2^k v_2$$——**$$|\lambda|$$ 最大的项指数级碾压其余**，几十步后 $$A^k x$$ 几乎平行于最大特征向量。两个直接推论：
- **PCA**：数据协方差矩阵（[方差与协方差](/ai-fa/explore/40-Concepts/方差与协方差)）的最大特征方向=方差最大方向=主成分（数据最"胖"的朝向）
- **稳定性**：线性系统状态 $$h_{t+1}=Ah_t$$ 是否收敛 $$\Leftrightarrow$$ **所有 $$|\lambda_i|<1$$**（谱半径 <1）——$$\lambda$$ 就是每步的衰减/放大率

**第 3 步：对角化——把矩阵换成"坐标刻度"。** 若 $$A$$ 有 $$n$$ 个无关特征向量，$$A = P\Lambda P^{-1}$$（$$\Lambda$$=对角阵放 $$\lambda$$）。则 $$A^k = P\Lambda^k P^{-1}$$——**幂运算=换坐标、各方向独立缩放、换回来**（矩阵指数 $$e^{At}=Pe^{\Lambda t}P^{-1}$$ 同理，正是 [矩阵指数时间衰减](/ai-fa/explore/30-Formulas/矩阵指数时间衰减) 的内核）。**库内最重的应用**：SSM 的 $$h_{t+1}=\bar A h_t + \bar B x_t$$ 稳定性、Mamba 的记忆衰减率，全部读 $$\bar A$$ 的特征值谱（[状态空间模型方程](/ai-fa/explore/30-Formulas/状态空间模型方程)）。

## 4. 常见误区

- **误区**：任何方阵都有完整特征向量——**实对称矩阵**才有保证（谱定理）；一般矩阵可能缺（如剪切矩阵）或为复数（旋转矩阵 $$\lambda=\pm i$$——纯旋转无拉伸方向）
- **误区**：特征值只属于方阵——严格是的；长方阵用**奇异值**（SVD，$$A^\top A$$ 特征值的开方）——谱归一化约束的其实是奇异值
- **误区**：$$\lambda$$ 正负无所谓——**符号**决定震荡（负=每步翻转）；稳定性要的是 $$|\lambda|<1$$ 而非"小"
- **误区**：特征向量唯一——差任意非零倍数都是；正交性只在对称阵时免费获得

## 5. 自测

1. $$\begin{bmatrix}0.5&0\\0&0.9\end{bmatrix}$$ 的系统 50 步后两方向各剩多少？（$$0.5^{50}\approx 0$$；$$0.9^{50}\approx0.5\%$$——"慢通道"是记忆主力）
2. 为什么幂迭代自动找最大 $$|\lambda|$$？（指数碾压——组合系数里的相对差距被 $$\lambda^k$$ 指数放大）
3. RNN 里 $$\lambda_{max}=1.01$$ 与 0.99 各自的远期命运？（爆炸需 clip / 消失学不动——一对孪生病）
4. 对称矩阵的特征向量为什么天然正交？（谱定理；不同 $$\lambda$$ 的特征向量内积可证为 0）
