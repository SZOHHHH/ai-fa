# 层归一化 Layer Normalization

## 1. 标准形式

$$\mathrm{LN}(x) = \gamma \odot \frac{x - \mu(x)}{\sigma(x)} + \beta, \qquad \mu(x) = \frac{1}{d}\sum_{j=1}^{d} x_j, \quad \sigma(x) = \sqrt{\frac{1}{d}\sum_j (x_j - \mu)^2 + \epsilon}$$
统计**在单个样本的 $d$ 个特征维上**算（与 batch 完全无关）。

## 2. 教程：一句话的差别，手算看穿

**第 1 步：同一个张量换轴。** 某层输出：样本 1 = $(1, 3)$，样本 2 = $(5, 7)$（2 样本 × 2 特征维，与 [[30-Formulas/批归一化]] §2 同一批数字——直接对照）。
- **BN（跨样本，逐特征）**：特征维 1 的统计来自 $(1, 5)$，特征维 2 来自 $(3, 7)$
- **LN（单样本内，跨特征）**：样本 1 自己算 $\mu=2, \sigma=1$：$\mathrm{LN}(1) = -1,\ \mathrm{LN}(3)=+1$；样本 2 自己算 $\mu=6,\sigma=1$：$(−1, +1)$——**每个样本独立把整层拉回零均值单位方差**

**第 2 步：手算后的关键差异读出来。** BN 后样本 1 和样本 2 的相对大小关系跨样本可比；LN 后每个样本自成标准位——**样本间不可比、但每条样本内部维度可比**。序列/变长场景（一句话 3 个词另一句 30 个词）没有"batch 对齐"概念，只有"句内自洽"有意义——**Transformer 选 LN 不是口味是结构必然**。

**第 3 步：Transformer 里放哪（Pre-LN 配方）。** $h' = h + \mathrm{Attn}(\mathrm{LN}(h))$（Pre-LN：归一化在子层**输入**处）——对比 Post-LN（原版，归一化在残差求和后）训练更稳（深栈梯度更顺，[[30-Formulas/残差连接]] 配合）。现代大模型标配 Pre-LN/RMSNorm。

**第 4 步：训练推理零差异。** 统计只依赖当前样本——**没有滑动平均、没有模式切换**（BN 的最大工程坑在 LN 根本不存在）；batch=1 推理、变长序列、RL rollout 全都天然安全。

## 4. 直觉解释

- **"每个样本自带标准位"**：不问别的样本长什么样，只管本层自己的 $d$ 维分布拉正——序列模型的自然选择
- γ/β 语义同 BN（先标准化再学回去多少）——可学习参数是"归一化的逃生门"
- 为什么 NLP 不用 BN：序列长度不一+batch 统计在词元间意义混乱+自回归训练时未来 token 不能进统计
