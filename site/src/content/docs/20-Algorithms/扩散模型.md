# 扩散模型 Diffusion Models

## 1. 定义

**非数学语言**：学习"把一张图逐渐加噪到纯噪声"的逆过程。训练时反复加噪再学着猜噪声；生成时从纯噪声出发一步步去噪，图像像从雾里显影。

**数学语言**：定义前向马尔可夫链 $$q(x_t \mid x_{t-1})$$ 逐步加噪（$$t: 0 \to T$$，数据 → $$\mathcal{N}(0,I)$$），学习反向链 $$p_\theta(x_{t-1}\mid x_t)$$ 使轨迹回到数据分布。等价视角：训练 denoising score matching，采样跑反向 SDE 或概率流 ODE。
