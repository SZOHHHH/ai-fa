# 矩阵指数时间衰减（擦除门递归）

## 1. 标准形式

$$S_i = \alpha_i\, S_{i-1} + (\gamma_i - \alpha_i)\, v_i k_i^{\top}$$

- $$S$$：线性注意力的（外积）记忆矩阵——每步新信息 $$v_i k_i^\top$$ 写入，旧内容按 $$\alpha_i$$ 衰减
- **$$\alpha_i$$：擦除门**（保留多少旧记忆，对角衰减≈矩阵指数 $$e^{-\Delta A}$$ 的对角版）；**$$\gamma_i$$：写入门**（新信息写多满）
- 本式为 GDN2（Gated DeltaNet-2）的核心递归——**把"擦除"与"写入"两个度拆开**（旧 DeltaNet 里 $$\gamma = \alpha$$ 绑死）

## 教程：一条标量记忆的四步演化（+解耦的必要性）

**第 1 步：标量宇宙。** 记忆 $$S$$ 是一个数；新信息 $$v k^\top = 2$$（这一步学到的关联强度）；$$\alpha = 0.5$$（擦一半）、$$\gamma = 0.9$$（几乎全写）。

**第 2 步：四步递归。** $$S_0 = 0$$：$$S_1 = 0.5\times0 + (0.9-0.5)\times2 = 0.8$$；$$S_2 = 0.5\times0.8+0.8 = 1.2$$；$$S_3 = 0.5\times1.2+0.8 = 1.4$$；$$S_4 = 0.5\times1.4+0.8 = 1.5$$——**指数逼近稳态** $$S^\ast = \frac{(\gamma-\alpha)\cdot 2}{1-\alpha} = \frac{0.8}{0.5} = 1.6$$（记忆容量的天花板 = 写入速率/遗忘速率）。

**第 3 步：解耦前的束缚。** 旧 DeltaNet $$\gamma = \alpha = 0.5$$：写入强度 $$(\gamma-\alpha) = 0$$——**擦多少就恰好少写多少**，只剩"清空"没有"覆写"；想要大写入必须 $$\alpha\to0$$（全忘）——擦与写在同一根旋钮上打架。

**第 4 步：解耦后的自由度。** GDN2 拆开后可以 $$\alpha = 0.5$$（清一半）+ $$\gamma = 0.9$$（写九成）——**"边忘边学"的连续谱**：快速换题（α 小 γ 大=大换血）、巩固复习（α 大 γ 小=只巩固不刷新）、完全静态（α=1）都成了可达配置。

**第 5 步：与 Mamba 的同构。** $$\alpha_i \leftrightarrow \bar A_t = e^{-\Delta A}$$（数据依赖衰减）、$$(\gamma_i-\alpha_i)v k^\top \leftrightarrow \bar B_t x_t$$（数据依赖写入）——**门控线性注意力与选择性 SSM 是同一数学的两套记号**（Mamba-2 的 SSD 对偶把它们正式接通）。

## 3. 直觉解释

- **记忆的漏桶模型**：$$S$$ 是个漏桶，$$\alpha$$ 是桶底漏洞大小、$$(\gamma-\alpha)vk^\top$$ 是注水速率——稳态水位 = 注水/漏速
- **衰减为什么叫"矩阵指数"**：$$\alpha^k$$ 的衰减族在对角矩阵下即 $$e^{k\ln\alpha}$$——与 SSM 的 $$e^{-\Delta A}$$ 同源（衰减=负指数）
- 线性注意力的统一视角：Performer 随机特征（无衰减）、DeltaNet（可改写）、GDN（门控衰减）、Mamba（结构化指数）——**都是"外积记忆 + 衰减/修正规则"的变奏**
