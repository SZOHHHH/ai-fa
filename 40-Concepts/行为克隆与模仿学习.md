# 行为克隆与模仿学习

## 1. 定义（直觉 → 形式）

**直觉**：不试错、不拿奖励，**直接照抄老师的行为**——把"老师在这个局面做了什么"当标签，做监督学习。学习成本几乎全在"收集老师的示范"上。

**形式**（行为克隆 BC = 对示范数据 $\{(s_i,a_i)\}$ 做极大似然）：

$$\mathcal{L}_{BC}(\theta)=-\sum_i \log \pi_\theta(a_i\mid s_i)\qquad(\text{=交叉熵，}a\text{ 离散时})$$

## 2. 模仿学习三兄弟

| 方法 | 怎么学 | 死穴 | 解药 |
|---|---|---|---|
| **行为克隆 BC** | 离线拟合 $(s,a)$ 对 | **复合误差**：测试时一步小偏差→进入训练没见过的局面→错上加错（分布漂移），误差随时间累积 | 见下 |
| **DAgger** | 关键一步：拿**学生自己**跑出的新局面去问老师要标签（数据聚合），训练分布对齐执行分布 | 要能反复打扰老师 | [[10-Papers/03-后处理/A Reduction of Imitation Learning and Structured Prediction to No-Regret Online Learning（DAGGER）|DAGGER]]（有定理：误差线性而非平方级） |
| **逆强化学习 IRL** | 反过来学"老师在优化什么奖励"，再解出策略 | 计算重 | 奖励学习/RLHF 一族 |

**复合误差一图**：训练数据覆盖的是老师走的路；学生 90 分相似度也意味着 10% 的偏差概率，第二步在偏出的局面里没有学过……$T$ 步后错误率 $1-(1-\epsilon)^T\to 1$。**"开环模仿必死于漂移"**——与 RL 世界模型蒸馏里"开环约束不覆盖策略到访分布"是同一数学。

## 教程：复合误差的复利账单（+一步 loss）

**第 1 步：单步 loss。** 示范 $(s, a{=}右)$，学生输出 $\pi_\theta(右|s) = 0.7$：$\mathcal{L}_{BC} = -\ln 0.7 = 0.357$——就是 [[30-Formulas/交叉熵]] 的 one-hot 形态（BC 没有任何新数学，新的是数据来源）。

**第 2 步：复利账单。** 单步偏差率 $\epsilon = 0.1$（学生 90 分相似），$T$ 步全程正确的概率 $= (1-\epsilon)^T$：$T{=}1$: 0.9；$T{=}10$: 0.35；$T{=}30$: 0.04；$T{=}50$: 0.005——**50 步后几乎必错**。机制：第一步小偏差 → 进入训练没见过的局面 → 错上加错——误差复利，正是"开环模仿必死于漂移"。

**第 3 步：DAgger 的解药。** 拿**学生自己**跑出的新局面去问老师要标签（数据聚合）——训练分布对齐执行分布；定理级效果：误差从 $O(\epsilon T^2)$（复合平方级）降到 $O(\epsilon T)$（线性级）——**不是更多数据，是对的数据分布**。

**第 4 步：库内实证呼应。** E1 的 p 线静态 BC 在 Boxing 只有 1.2 分（对专家帧的离线拟合，一开环就漂）而 v1 序列 BC 站住——**复合误差在真实任务上的具象**；世界模型蒸馏里"开环约束不覆盖策略到访分布"是同一数学的另一件衣服（[[40-Concepts/on-policy与off-policy]] §4 蒸馏行）。

**第 5 步：读法。** BC 的位置 = 模仿学习三兄弟中最便宜也最脆的一支：数据成本全在收集示范、训练就是监督学习；但只要执行分布会漂移，它就没有纠错机制——DAgger/IRL/RL 各从一边补。

## 3. IDM 与 BC：一对镜像零件

| | 行为克隆（BC） | 逆动力学模型（IDM） |
|---|---|---|
| 学什么 | $\pi(a\mid s)$（局面→动作） | $q(a\mid s,s')$（**前后两个局面**→动作） |
| 输入差 | 只看当前 | 多看一个未来 |
| 本质 | 学"老师的习惯"（条件分布） | 学"环境的因果"（转移逆问题） |
| 用途 | 直接当策略 | 给视频补动作标签 / 由目标反推动作 |

两者常配套：Genie/VPT 用 IDM 从无标注视频造动作标签，再用 BC/RL 训策略——**BC 学果（模仿行为），IDM 学因（反推机制）**。

## 4. 易混点

- **BC ≠ 有监督学习的全部**：BC 是其中最朴素的一支；模仿学习还包括 DAgger、IRL、对抗模仿（GAIL）等。
- **"离线"≠模仿**：离线 RL 有奖励信号且目标是回报最优；模仿学习只盯行为/示范。
- **DAgger 的本质**：不是"更多数据"，是"**对的分布**上的数据"——覆盖假设的训练侧执行。

## 5. 自测

1. $\pi_\theta(右|s) = 0.7$：BC loss？（$-\ln 0.7 = 0.357$——交叉熵 one-hot 形态）
2. $\epsilon = 0.1$、$T = 30$：全程正确率？（$0.9^{30} \approx 0.04$——复利账单）
3. DAgger 降误差的本质？（训练分布对齐执行分布（学生自己的局面问老师）——$O(T^2)\to O(T)$，"对的分布"非"更多数据"）
4. BC 与 IDM 学的分布差？（$\pi(a|s)$ 只看当前（学习惯）vs $q(a|s,s')$ 多看未来（学因果）——一对镜像零件）
