# 注意力核心公式（缩放点积）

## 1. 标准形式

$$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left( \frac{QK^\top}{\sqrt{d_k}} + M \right) V$$

- $Q \in \mathbb{R}^{n \times d_k}$，$K, V \in \mathbb{R}^{m \times d_v}$
- $M$：掩码矩阵（因果掩码：未来位置 $-\infty$；padding 掩码同理）
- 多头版：$\mathrm{Concat}(\mathrm{head}_1, \dots, \mathrm{head}_h)W_O$，$\mathrm{head}_i = \mathrm{Attention}(XW_Q^i, XW_K^i, XW_V^i)$

| 缩放点积（本库标准） | 如上 | Transformer 2017 | 全部现代变体的母体 |
| 加性注意力 | $\mathrm{score}(q,k) = v^\top \tanh(W_q q + W_k k)$ | Bahdanau 2014 | 前身（RNN 时代） |

## 教程：两个词的注意力手算全程

**第 1 步：设定。** 句子"猫 追"两词，$d_k=4$，单头无掩码。投影后：
$$q_{猫} = (1, 0, 0, 0),\quad q_{追} = (0, 1, 0, 0),\quad k_{猫} = (1, 0, 0, 0),\quad k_{追} = (0, 0.5, 0, 0)$$
$$v_{猫} = (9, 0),\quad v_{追} = (0, 7)$$

**第 2 步：打分矩阵 $QK^\top/\sqrt{d_k}$。** $q_{猫}^\top k_{猫}=1,\ q_{猫}^\top k_{追}=0$；除 $\sqrt4=2$：第一行 $(0.5,\ 0)$；同理第二行 $(0,\ 0.25)$。

**第 3 步：softmax 变权重。** 第一行：$(e^{0.5}, e^0)=(1.65,\ 1)$ 归一 → $(0.62,\ 0.38)$——"猫"的位置 62% 看自己、38% 看"追"。第二行：$(e^0, e^{0.25})=(1,\ 1.28)$ → $(0.44,\ 0.56)$。

**第 4 步：加权取值。** $\mathrm{out}_{猫} = 0.62\times(9,0) + 0.38\times(0,7) = (5.58,\ 2.66)$——**每个位置的输出=全位置的凸组合**（权重和恒 1），"追"的信息被按相关度揉进了"猫"的新表示里。这就是"可微分寻址"的全部动作：打分→归一→取货。

**第 5 步：√d 缩放为什么是数学必需（方差现场）。** 设 q、k 各分量独立同方差 1：$\mathrm{Var}(q^\top k) = \sum_{i=1}^{d_k} 1 = d_k$——$d_k{=}64$ 时打分标准差 8，softmax 的 logits 差动辄 ±16 → $e^{16}$ 倍差距 → **饱和成 one-hot**（梯度死区，[[40-Concepts/sigmoid函数]] 同款病灶）。除 $\sqrt{d_k}$ 把方差压回 1——不是调温度是**方差归一**（[[40-Concepts/内积]] §4 误区）。

**第 6 步：多头=平行读不同关系。** 同一句话 8 个头：某头专看句法邻接、某头看指代、某头看位置相近——Concat 后 $W_O$ 融合。手算上=把第 2-4 步平行跑 8 组不同 $W_Q/W_K/W_V$。

## 3. 直觉解释

- **三行合一的读法**：①$QK^\top$：每个词给所有词打相关分；②softmax：分数变权重；③乘 $V$：按权重混合信息
- **$\sqrt{d_k}$ 的必要性**：$q, k$ 各分量独立时 $q^\top k$ 方差 = $d_k$——不除以 $\sqrt{d_k}$，长向量打分天然巨大，softmax 饱和成 one-hot，梯度消失
- **为什么 V 存在**：打分（Q/K）与取值（V）解耦——"找谁"和"拿什么"分离，表达能力增强
- **信息瓶颈视角**：每个位置输出是全部位置的凸组合（softmax 权重和为 1）——注意力的本质是**可微分的寻址**

## 6. 自测

1. 教程例中"追"的输出？（$0.44\times(9,0)+0.56\times(0,7)=(3.96,\ 3.92)$）
2. 若去掉 √d 缩放、$d_k=100$、打分差 20，softmax 后什么样？（$e^{20}\approx5\times10^8$ 倍差 → 完全 one-hot：输出=单个 v，梯度消失）
3. 因果掩码加在哪一步？（打分后 softmax 前——未来位 $-\infty$，softmax 后权重恰 0）
4. 为什么 Q/K 与 V 分离？（"找谁"与"拿什么"解耦——同一词可"以身份被找到"且"携带别的信息"）
