# 状态空间模型递归

## 1. 标准形式

$$h_t = \bar A\, h_{t-1} + \bar B\, x_t, \qquad y_t = C\, h_t$$

- $$h_t \in \mathbb{R}^{d_{\text{state}}}$$：隐状态（"到目前为止的记忆摘要"）；$$\bar A, \bar B$$ 由连续参数经 ZOH 离散化而来（$$\bar A = e^{\Delta A}$$，见 [状态空间模型方程](/ai-fa/explore/30-Formulas/状态空间模型方程) §1）
- **本式是 SSM 的推理面孔**：每个新 token 到来，$$O(d_{\text{state}}^2)$$ 一步更新——没有 KV 缓存的增长（对照 [KV缓存](/ai-fa/explore/40-Concepts/KV缓存)：线性复杂度 vs 平方）

## 教程：递归、卷积、扫描三种算法算同一个序列

**第 1 步：标量宇宙。** $$\bar A = 0.5$$（每步记忆减半）、$$\bar B = C = 1$$；输入 $$x = (1, 2, 0, 1)$$。

**第 2 步：逐步递归。** $$h_1 = 0.5\times0 + 1\times1 = 1$$；$$h_2 = 0.5\times1 + 1\times2 = 2.5$$；$$h_3 = 0.5\times2.5 + 0 = 1.25$$；$$h_4 = 0.5\times1.25 + 1 = 1.625$$。

**第 3 步：展开成闭式（看清"记忆"结构）。** $$h_t = \sum_{j\le t} \bar A^{\,t-j}\, \bar B\, x_j$$——当前状态是**全部历史的指数加权和**：$$h_4 = 0.125\times1 + 0.25\times2 + 0.5\times0 + 1\times1 = 1.625$$ ✓（每个输入按"多久以前"打 $$0.5^{\text{年龄}}$$ 折）。

**第 4 步：卷积面孔。** 第 3 步的加权系数 $$(1, 0.5, 0.25, 0.125)$$ 就是卷积核——**递归 = 卷积**（一副参数两副面孔，完整对账见 [状态空间模型方程](/ai-fa/explore/30-Formulas/状态空间模型方程) 教程）。

**第 5 步：并行扫描为什么救了训练。** 递归有依赖链（$$h_4$$ 等 $$h_3$$）——串行慢；但 $$h_t$$ 的更新是**结合律友好的仿射复合**：把 $$(\bar A, \bar B x_t)$$ 当作二元算子，前缀积可用树形归约 $$O(\log n)$$ 深度并行（与 FlashAttention 的在线归约、Performer 的换序同属"用结合律重排计算"家族）。Mamba 的 selective scan 即此：时变参数破坏卷积性，但仿射复合结构还在，扫描照跑。

## 3. 直觉解释

- **"线性 RNN 的矩阵化"**：普通 RNN $$h_t = \tanh(W h_{t-1} + U x_t)$$ 的非线性去掉、参数换成结构化矩阵——换来可并行训练与可控记忆谱
- **记忆的数学**：$$\bar A$$ 的特征值 = 各记忆通道的衰减率（0.5 = 半衰期一步；0.999 = 千步）——**记忆不是黑箱是刻度盘**
- **推理红利**：状态固定大小 $$d_{\text{state}}$$，不随序列长度增长（vs 注意力的 KV cache 线性膨胀）——**长上下文推理的显存优势来源**
- 代价：时变参数后失去卷积并行（靠扫描）；固定 $$\bar A$$ 的线性限制表达力（Mamba 用输入依赖弥补）

## 6. 自测

1. $$\bar A = 0.5$$：$$x_1$$ 对 $$h_4$$ 的贡献系数？（$$0.5^3 = 0.125$$——按年龄指数折）
2. 递归与卷积何时等价？（参数固定（LTI）时——$$K$$ = 脉冲响应；时变（Mamba）即失效）
3. 并行扫描利用什么结构？（仿射复合的结合律——前缀积树形归约，$$O(\log n)$$ 深度）
4. 推理期相对注意力的显存优势从哪来？（状态固定 $$d_{\text{state}}$$ 不随长度增长——无 KV cache 膨胀）
