# 维纳过程 Wiener Process

## 1. 定义（直觉 → 形式）

**直觉**：**纯粹的随机抖动**。它是布朗运动的数学模型：粒子每微小时刻被随机撞一下，方向完全无记忆。也是"连续时间里抛硬币"——离散随机游走 $\Delta t \to 0$ 的极限。

**形式**：随机过程 $w(t)$ 满足三条公理：
1. $w(0) = 0$
2. 增量独立：$w(t_2) - w(t_1)$ 与历史无关
3. 增量高斯：$w(t+\Delta t) - w(t) \sim \mathcal{N}(0, \Delta t)$

**关键推论**（本库直接使用）：一小步 $dw \sim \mathcal{N}(0, dt\, I)$，即方差等于时间步长。

## 2. 数学形式

- **几乎处处不可导**：轨迹是"锯齿"的，所以 [[40-Concepts/随机微分方程（SDE）|随机微分方程]] 只能用增量 $dw$ 书写，不能写 $dw/dt$
- **二次变差**：$\sum (w_{i+1} - w_i)^2 \to t$——把"$dw^2 = dt$"这一形式运算合法化的来源
- **缩放性质**：$\sqrt{a}\, w(t/a) \sim w(t)$（时间-幅度对偶）
- **多维**：$w \in \mathbb{R}^d$ 各分量独立，$\mathcal{N}(0, dt\, I)$

## 教程：四步模拟 + 二次变差手算

**第 1 步：四步走。** $dt = 0.02$（每步增量 $\sim \mathcal{N}(0, 0.02)$，标准差 $\sqrt{0.02} = 0.141$）。抽四个增量：$dw = (+0.10,\ -0.20,\ +0.15,\ +0.05)$（都在 ±1.5σ 内，正常）：位置 $w$：$0 \to 0.10 \to -0.10 \to 0.05 \to 0.10$——**方向完全无记忆**（第 2 步掉头与第 1 步无关）。

**第 2 步：二次变差手算。** 增量平方和 $= 0.10^2 + 0.20^2 + 0.15^2 + 0.05^2 = 0.010+0.040+0.0225+0.0025 = 0.075 \approx 4\times0.02 = 0.08$——**步数越多越贴合**（大数定律）：这就是 $dw^2 = dt$ 形式运算的实证来源（Itô 微积分的基石）。

**第 3 步：方差 = 时间。** 一小时后 $w(1) - w(0) \sim \mathcal{N}(0, 1)$；四小时后 $\mathcal{N}(0, 4)$（方差可加）——**抖动的幅度按 $\sqrt{t}$ 扩散**（标准差 1→2），不是按 $t$。

**第 4 步：在扩散模型里的身份。** DDPM 每步注入的 $\epsilon\sqrt{\beta_t}$ 就是 $g\,dw$ 的离散化；记号换算 $\epsilon = dw/\sqrt{dt}$（单位时间噪声，方差归一）——网络预测的 $\epsilon_\theta$ 与过程增量 $dw$ 的关系一表分清（见 §记号警示）。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [[40-Concepts/随机微分方程（SDE）|随机微分方程]] | SDE 的噪声源：$dx = f\,dt + g\,dw$ |
| [[30-Formulas/Score-SDE前向过程]] | 前向加噪的连续时间极限 |
| 扩散采样 | 祖先采样每步注入的随机性 = 离散化的 $dw$ |

**记号警示**：DDPM 里的 $\epsilon \sim \mathcal{N}(0, I)$ 与 $dw$ 关系：$\epsilon = dw / \sqrt{dt}$，方差归一化后的"每单位时间噪声"。论文两者混用，本库统一：**网络预测的噪声记 $\epsilon_\theta$，过程增量记 $dw$**。

## 4. 常见误区

- **误区**：$dw$ 的期望为零，所以"平均没有噪声"——方差不为零，单条轨迹剧烈抖动
- **误区**：维纳过程是高斯分布——它是**过程**（轨迹族），每时刻的值才是高斯变量
- **误区**：SDE 里把 $dw$ 当确定小量做链式法则——需要 Itô 微积分，$dw^2 = dt$ 有额外项

## 5. 自测

1. $dt = 0.02$：单步增量的分布？（$\mathcal{N}(0, 0.02)$——方差=时间步长，标准差 0.141）
2. 四步增量 $(0.10,-0.20,0.15,0.05)$ 的二次变差？（0.075 ≈ 4dt = 0.08——$dw^2 = dt$ 的实证）
3. $w(4)$ 的方差是 $w(1)$ 的几倍？（4 倍方差（2 倍标准差）——按 $\sqrt t$ 扩散）
4. $\epsilon_\theta$ 与 $dw$ 的关系？（$\epsilon = dw/\sqrt{dt}$——单位时间归一化噪声）
