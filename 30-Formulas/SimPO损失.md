# SimPO 损失

## 1. 标准形式

$$\mathcal{L}_{\text{SimPO}}(\theta) = -\,\mathbb{E}\!\left[ \log\sigma\!\left( \frac{\beta}{|y^+|}\log\pi_\theta(y^+\mid x) - \frac{\beta}{|y^-|}\log\pi_\theta(y^-\mid x) - \gamma \right) \right]$$

- 奖励定义：$r(x,y) = \frac{\beta}{|y|}\log\pi_\theta(y\mid x)$——**长度归一化的平均对数似然**
- $\gamma > 0$：目标间距（margin）——$y^+$ 至少赢 $y^-$ 这个分数

## 教程：长度归一的必要性现场（判定翻转）

**第 1 步：不归一的污染。** $y^+$（10 token）对数比总和 $-0.3$；$y^-$（20 token）总和 $-0.5$——不归一的隐式奖励差 $= -0.3-(-0.5) = +0.2$，判 $y^+$ 赢。但换算成**每 token**：$y^+$ 平均 $-0.03$、$y^-$ 平均 $-0.025$——**平均口径下 $y^-$ 反而更高**！同一组数据，两种度量给出相反判定：总和对数比被长度污染（20 token 的每个 token 贡献都被计满两次量级），**模型可以通过把 $y^-$ 写长来"制造"压低空间**——长度偏置的病根。

**第 2 步：SimPO 奖励。** $r(x,y) = \frac{\beta}{|y|}\log\pi_\theta(y|x)$（对**绝对**平均对数似然打分，非对数比）。$\beta = 2$：$y^+$ 平均 $-1.2$ → $r^+ = -2.4$；$y^-$ 平均 $-0.9$ → $r^- = -1.8$——**每个 token 的质量才是度量**，长短可比。

**第 3 步：γ 间距。** $\gamma = 0.5$：内层 $z = r^+ - r^- - \gamma = -2.4-(-1.8)-0.5 = -1.1$ → $\sigma(-1.1) = 0.25$ → $\mathcal{L} = -\log 0.25 = 1.386$——此数据点上 $y^+$ 的平均似然还落后，损失大；模型必须把 $y^+$ 的平均抬过 $y^-$ **至少 γ** 才开始心安——**胜负线自带防过度自信**（没有 γ 时 0.0001 的领先也算赢）。

**第 4 步：为什么敢去掉参考模型。** $\pi_{\mathrm{ref}}$ 的职能是防漂移；SimPO 的奖励是**有界的平均对数似然**（$\le 0$）——概率本身自约束，无法靠无限压低对手刷分（对手也在平均口径下竞争）。省下的是：参考模型的显存与每次前向（部署成本近半）。

**第 5 步：家族读法。** DPO（有 ref、比差）→ SimPO（无 ref、绝对平均、带间距）——"简化者胜"路线；对照 ORPO 的另一条去 ref 路（odds + SFT 锚）与 IPO 的理论修正路（达标即停）——**同一 RLHF 闭式解的四个后裔，各修一个面**。

## 3. 直觉解释

- **两大改动**：① 去掉 $\pi_{\text{ref}}$（省一半显存/部署成本）② 奖励按**长度平均**（短回答天然对数概率和更小，不归一会偏好长回答——DPO 隐患之一）
- **为什么敢去参考**：参考的作用是防漂移；SimPO 用"平均对数似然本身当奖励"——隐式自约束（概率和有界）
- **γ 间距**：给 $y^+$/$y^-$ 设胜负线，防止过度自信；实验中 0.3–0.6
- 与 [[30-Formulas/DPO损失]] 的关系：**更简单且实测更强**——"简化者胜"路线的代表

## 6. 自测

1. $y^+$ 总对数比 $-0.3$（10 token）、$y^-$ 总 $-0.5$（20 token）：两种口径的判定？（总和：$y^+$ 赢（+0.2）；每 token 平均：$-0.03$ vs $-0.025$——$y^-$ 赢，判定翻转=长度污染现场）
2. SimPO 奖励的定义？（$r = \frac{\beta}{|y|}\log\pi$——绝对平均对数似然，长短可比）
3. $\gamma$ 的作用？（胜负线：$r^+$ 须超 $r^-$ 至少 γ——防 0.0001 式险胜的过度自信）
4. 去 ref 为什么安全？（平均对数似然有界自约束 + 无需 ref 显存——"简化者胜"路线）
