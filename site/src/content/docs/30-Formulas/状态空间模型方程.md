# 状态空间模型方程 SSM

## 1. 标准形式

**连续时间**（源自控制论）：
$$\frac{dh(t)}{dt} = A\, h(t) + B\, x(t), \qquad y(t) = C\, h(t) + D\, x(t)$$

**离散化后**（神经网络实际计算，零阶保持 ZOH 离散）：
$$h_t = \bar A\, h_{t-1} + \bar B\, x_t, \qquad y_t = C\, h_t$$
$$\bar A = e^{\Delta A}, \qquad \bar B = (\Delta A)^{-1}(e^{\Delta A} - I)\, \Delta B$$

- $$h_t \in \mathbb{R}^{d_{\text{state}}}$$：隐状态（"到目前为止的记忆"）
- $$x_t$$：输入 token；$$y_t$$：输出
- $$\Delta$$：步长（可学习——**Mamba 的"选择性"入口**）
- $$A, B, C$$：可学习参数矩阵

## 教程：一副参数两副面孔（递归=卷积逐位对账）

**第 1 步：标量宇宙（本库 SSM 族共用）。** 取衰减率 $$a=1$$、步长 $$\Delta = \ln 2 \approx 0.693$$ → $$\bar A = e^{-\Delta a} = e^{-0.693} = 0.5$$——**每步记忆减半**；$$\bar B = 1,\ C = 1$$。

**第 2 步：递归面孔。** 输入 $$x = (1, 2, 0, 1)$$：$$h_1 = 0.5\times0+1\times1 = 1$$；$$h_2 = 0.5\times1+1\times2 = 2.5$$；$$h_3 = 0.5\times2.5+0 = 1.25$$；$$h_4 = 0.5\times1.25+1 = 1.625$$。每步 $$O(1)$$——推理时增量为常数。

**第 3 步：卷积面孔。** 卷积核 $$=$$ 脉冲响应 $$K = (C\bar B,\ C\bar A\bar B,\ C\bar A^2\bar B, \dots) = (1,\ 0.5,\ 0.25,\ 0.125)$$。$$y_2 = K_0 x_2 + K_1 x_1 = 2+0.5 = 2.5$$ ✓；$$y_3 = 0+0.5\times2+0.25\times1 = 1.25$$ ✓；$$y_4 = 1\times1+0.5\times0+0.25\times2+0.125\times1 = 1.625$$ ✓——**两种算法逐位一致**：参数固定时序列算子就是卷积，训练时整个序列一次并行算完。

**第 4 步：记忆的刻度。** $$\bar A = 0.5$$：一步前的输入贡献减半，十步前只剩 $$0.1\%$$——短记忆通道；$$\bar A = 0.999$$：千步前还有 37%——长记忆通道。**$$\bar A$$ 的特征值谱 = 各记忆通道的半衰期表**（[特征值与特征向量](/ai-fa/explore/40-Concepts/特征值与特征向量) 的直接应用：不同特征方向各自衰减）。

**第 5 步：Mamba 打破了什么。** 选择性让 $$\Delta(x_t), B(x_t), C(x_t)$$ 随输入变 → $$\bar A_t$$ 时变 → 核不再是固定卷积（第 3 步的并行性失效）——代价换来的能力：**看内容决定记什么忘什么**（完整手算见 [选择机制](/ai-fa/explore/30-Formulas/选择机制)）。训练改用并行扫描（前缀积/和的树形归约——递归依赖链被打掉，与 FlashAttention 的在线归约同宗）。

## 3. 直觉解释

- **RNN 与 CNN 的合体**：训练用卷积形式并行快；推理用递归形式 $$O(1)$$ 步更新——两副面孔一套参数
- **"记忆"的数学**：$$h_t$$ 是压缩摘要；$$\bar A$$ 决定记忆衰减（特征值 <1 → 遗忘快）——**内容寻址 vs 位置寻址**（注意力）的根本差异
- **选择性**：让 $$\Delta(x_t), B(x_t), C(x_t)$$ 随输入变——模型能"看内容决定记什么忘什么"（这是 Mamba 相对 S4 的核心创新，代价是失去卷积形式，改用并行扫描/硬件友好算法）
- **对偶的意义**：Mamba-2 证明注意力（二次）与 SSM（线性）都是"半可分矩阵"族的端点——**架构之争被统一在一个矩阵族下**（类似扩散与流匹配的统一故事）

## 6. 自测

1. $$\bar A = 0.5$$、$$\bar B = C = 1$$、$$x = (1,2,0,1)$$：$$h_3$$？（$$0.5\times2.5+0 = 1.25$$；卷积验证 $$0.5\times2+0.25\times1 = 1.25$$ ✓）
2. 卷积核从哪来？（脉冲响应：喂 $$(1,0,0,\dots)$$ 输出即 $$(1, \bar A, \bar A^2, \dots)$$——参数固定时序列算子=卷积）
3. $$\bar A = 0.999$$ 的通道记忆多长？（千步前仍余 37%——特征值谱=各通道半衰期表）
4. 选择性打破了什么、换来什么？（固定卷积的并行性 → 看内容决定记/忘（时变 $$\bar A_t$$）——训练改并行扫描）
