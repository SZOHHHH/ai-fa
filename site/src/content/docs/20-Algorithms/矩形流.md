# 矩形流 Rectified Flow

## 1. 定义

**非数学语言**：把数据点和噪声点两两连成直线（矩形配对），学一个速度场让所有轨迹尽量直；然后用 reflow 迭代——用第一代模型自采样出配对再训第二代——轨迹越来越直，直到可以一步直飞。

**数学语言**：线性插值 $$x_t = (1-t)x_0 + t z$$，速度场回归 $$u_t = z - x_0$$（常数速度！）；reflow 迭代把配对分布向"不交叉的直传输"（最优传输）逼近。

## 教程：Reflow 把弯轨迹拉直（两轮迭代手算）

**第 1 步：为什么弯。** 流匹配学的速度场由随机耦合 $$(x_0, x_1)$$ 决定——同一个终点 $$x_1 = 2$$ 可能耦合自 $$x_0 = 0$$ 或 $$x_0 = 4$$（不同噪声）：两点速度场的平均在中间区域**交叉打架**，ODE 轨迹被迫弯曲（弯曲的轨迹不敢大步跳）。

**第 2 步：第一轮（学初始场）。** 标准 FM 训练（[流匹配](/ai-fa/explore/20-Algorithms/流匹配) 教程：直线耦合的速度回归），得到 $$v_1$$；从 $$x_0 = 0$$ 积分到终点，记轨迹 $$\hat x_1 = 2.1$$（略偏——弯轨迹的通病）。

**第 3 步：Reflow（重新耦合）。** 关键一步：把 $$(x_0 = 0,\ \hat x_1 = 2.1)$$ 这对**自己生成的起点-终点**当新耦合——新耦合的连线**正是自己走过的轨迹**：沿它学速度场，轨迹上每个点的速度都指向轨迹切线方向——**没有交叉打架，轨迹拉直**。

**第 4 步：第二轮。** 用新耦合重训得 $$v_2$$：从 0 出发积分，轨迹近乎直线、终点 2.1→更准。可迭代（2-rectified flow、3-rectified…），实践一轮已大幅拉直。

**第 5 步：收获。** 直线轨迹 = 一步欧拉就够（端点连线即路径）——**2-rectified flow 的一步生成质量**直追多步扩散采样；这是"少步化"的另一条路（不蒸馏、重新耦合），与 [一致性模型](/ai-fa/explore/20-Algorithms/一致性模型) 的蒸馏路线平行。

## 自测

1. 轨迹为什么弯？（随机耦合的速度场交叉打架——同一终点多个起点）
2. Reflow 的关键一步？（用自己生成的 (起点, 终点) 当新耦合——轨迹自洽拉直）
3. 拉直后收获什么？（直线一步欧拉即达——2-rectified flow 一步生成）
4. 与一致性模型路线差？（重新耦合 vs 蒸馏——两条平行的少步化路）
