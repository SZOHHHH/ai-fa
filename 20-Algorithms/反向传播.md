# 反向传播（Backpropagation）

## 1. 定义

**非数学语言**：训练一切神经网络的核心引擎。前向一趟算出损失并**记下途中每一步的中间值**；然后从损失出发，沿计算路径**反向**逐层追问"每个参数对这次误差负多大责任"，把责任（梯度）一路分摊回每个权重。它不是学习算法本身——它只是高效算梯度的簿记术，真正"学习"发生在梯度下降拿这些梯度去更新参数时。

**数学语言**：[[40-Concepts/梯度]] 上的**链式法则的动态规划实现**。对 $L$ 层网络记 $z_l = W_l h_{l-1} + b_l,\; h_l = \phi(z_l)$，定义误差信号 $\delta_l = \nabla_{z_l} \mathcal{L}$，则：
$$\delta_L = \nabla_{a}\mathcal{L} \odot \phi'(z_L), \qquad \delta_l = (W_{l+1}^\top \delta_{l+1}) \odot \phi'(z_l)$$
$$\nabla_{W_l}\mathcal{L} = \delta_l\, h_{l-1}^\top, \qquad \nabla_{b_l}\mathcal{L} = \delta_l$$

## 3. 核心公式

- **链式法则**（数学本质）：$\frac{\partial \mathcal{L}}{\partial x} = \frac{\partial \mathcal{L}}{\partial g}\cdot\frac{\partial g}{\partial x}$——见 [[40-Concepts/梯度]] §2
- **逐层递推**（上文 $\delta$ 两式）——**反向趟的全部内容**：每层只做一次矩阵乘+逐元素乘
- **梯度-激活解耦**：$\nabla_{W_l}$ 需要 $h_{l-1}$——这正是前向趟必须**记住中间值**的原因（空间换时间）

## 6. 对比表

| | 有限差分法 | 符号微分 | 反向传播（反向自动微分） |
|---|---|---|---|
| 原理 | 逐参数扰动重算损失 | 表达式化简后求导 | 链式法则沿计算图反向分摊 |
| 复杂度 | $O(N)$ 次前向（N=参数量，亿万级不可行） | 表达式膨胀 | **一次前向+一次反向 ≈ 2-3× 前向** |
| 数值 | 有截断误差 | 精确 | 精确 |
| 地位 | 只用于单元测试验梯度 | CAS 软件用 | **一切深度学习框架的地基** |

**为什么高效（一句话）**：朴素法对每个参数问一遍"你多重要"；BP 把问题反过来——从损失出发一次走完所有路径，**途经的每段路被所有路径共享复用**（动态规划思想），代价从"参数量×前向"塌缩到"常数×前向"。

**两大天敌**：梯度**消失**（连乘的因子绝对值 <1，如 sigmoid 饱和区 ≤0.25——二十层后信号所剩无几）与梯度**爆炸**（因子 >1 连乘发散）。对策三条线：激活换 [[40-Concepts/ReLU]]、结构加 [[30-Formulas/残差连接]]（恒等直通）、分布用 [[30-Formulas/批归一化]]/[[30-Formulas/层归一化]]；序列网络里这正是 LSTM 门控与 SSM 状态直通的动机（[[20-Algorithms/LSTM]]）。

**一句话总结**：前向算"错了多少"，反向算"该怪谁"——中间值的复用把责任分摊的成本压到常数倍前向，深度学习整个产业就跑在这一点簿记术上。
