# 内积 Dot Product

## 1. 定义（直觉 → 形式）

**直觉**：两个向量的"对齐程度"。方向一致 → 大正数；正交（无关）→ 零；相反 → 负数。机器学习里"相似度"的默认度量。

**形式**：
$$\langle a, b \rangle = a^\top b = \sum_i a_i b_i$$
几何意义：$$\|a\|\|b\|\cos\theta$$——模长 × 夹角余弦。

## 2. 数学形式

- **柯西-施瓦茨不等式**：$$|a^\top b| \le \|a\|\|b\|$$——注意力量级的来源（打分不会超模长乘积）
- **旋转不变性**：$$\langle R a, R b \rangle = \langle a, b \rangle$$（$$R$$ 正交）——RoPE 相对性的根据（[位置编码](/ai-fa/explore/40-Concepts/位置编码)）
- **与范数的关系**：$$\|a\|_2^2 = a^\top a$$（见 [范数](/ai-fa/explore/40-Concepts/范数)）
- **矩阵视角**：$$QK^\top$$ = 所有 query-key 对的内积打包（[注意力机制](/ai-fa/explore/40-Concepts/注意力机制) 的打分矩阵）

## 教程：四个向量算内积（读出"对齐度"的量级）

**第 1 步：手算三对。** $$a = (1, 0)$$（朝东）：
- $$b_1 = (0.8, 0.6)$$（偏东北）：$$\langle a, b_1\rangle = 0.8$$——**较对齐，正分**
- $$b_2 = (0, 1)$$（朝北）：$$\langle a, b_2\rangle = 0$$——**正交，无关**
- $$b_3 = (-1, 0)$$（朝西）：$$\langle a, b_3\rangle = -1$$——**完全反向**

**第 2 步：几何公式验证。** $$\langle a, b_1\rangle = \|a\|\|b_1\|\cos\theta = 1\times1\times\cos 36.9° \approx 0.8$$ ✓——内积=模长×夹角余弦：**方向与长度同时参与**。

**第 3 步：模长污染现场（为什么有 cosine 相似度）。** $$c = (80, 60)$$（与 $$b_1$$ 同方向、长 100 倍）：$$\langle a, c\rangle = 80$$——分数涨了 100 倍但**方向关系没变**。要纯方向相似度：$$\cos\theta = \frac{a^\top b}{\|a\|\|b\|}$$。注意力里 query 模长波动会整体抬高/压低所有 key 的分数——softmax 只看相对大小所以**方向排序不变**，但数值稳定要管（√d 缩放的来由，见 §4 误区）。

**第 4 步：内积全家桶在库内的位置。** [word2vec负采样](/ai-fa/explore/30-Formulas/word2vec负采样)：$$\sigma(v_c^\top v_t)$$ 真假邻居判别（内积当打分）；[CNN](/ai-fa/explore/20-Algorithms/CNN) §3：卷积=核与局部块的内积；[注意力核心公式](/ai-fa/explore/30-Formulas/注意力核心公式)：$$QK^\top$$ 打分矩阵——**整个深度学习的"相似度"都押在这个初等运算上**。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [注意力机制](/ai-fa/explore/40-Concepts/注意力机制) | 相似度打分 $$QK^\top/\sqrt{d_k}$$ |
| CLIP 对比学习 | 图文嵌入内积（线 8 预埋） |
- [位置编码](/ai-fa/explore/40-Concepts/位置编码) | RoPE 的相对性证明 |
| 词向量 | cosine 相似度（内积除以模长） |

## 4. 常见误区

- **误区**：内积大 = 相似——还受模长影响（长向量内积天然大）；要纯方向用 cosine
- **误区**：注意力里的 $$\sqrt{d_k}$$ 缩放"调温度"——是方差归一（点积方差 = $$d_k$$），与采样温度不同概念
- **误区**：内积可为负所以能表达"反对关系"——softmax 后只保留相对大小

## 5. 自测

1. $$(2,-1)$$ 与 $$(1,2)$$ 的内积？（0——正交）
2. 模长翻倍内积怎么变？（×2——除非对方是零向量；cosine 相似度则不变）
3. 柯西-施瓦茨不等式给注意力的分数什么保证？（$$|q^\top k|\le\|q\|\|k\|$$——打分不会超过模长乘积，量级可控）
4. RoPE 为什么用"旋转"？（正交变换保内积——旋转后的相对夹角不变=相对位置编码的合法性，[位置编码](/ai-fa/explore/40-Concepts/位置编码)）
