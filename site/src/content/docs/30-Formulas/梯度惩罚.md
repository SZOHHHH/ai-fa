# 梯度惩罚（WGAN-GP）

## 1. 标准形式

$$\mathcal{L} = \underbrace{\mathbb{E}_{\tilde x\sim p_G}[D(\tilde x)] - \mathbb{E}_{x\sim p_{data}}[D(x)]}_{\text{WGAN 判别器目标}} \;+\; \lambda\, \mathbb{E}_{\hat x\sim p_{\hat x}}\Big[\big(\|\nabla_{\hat x} D(\hat x)\|_2 - 1\big)^2\Big]$$
惩罚项在**真假样本的线性插值点** $$\hat x = \epsilon x + (1-\epsilon)\tilde x$$（$$\epsilon\sim U[0,1]$$）上：判别器的**梯度范数被推向 1**，$$\lambda$$ 常取 10。

## 2. 教程：从权重裁剪的病到插值惩罚的药（手算梯度范数）

**第 1 步：WGAN 为什么需要 1-Lipschitz。** 判别器 $$D$$ 逼近 Wasserstein 距离的前提是 1-Lipschitz（[Lipschitz连续](/ai-fa/explore/40-Concepts/Lipschitz连续)：输出变化不超过输入变化）——否则 W 距离可以被任意放大/无效化。

**第 2 步：原版药（权重裁剪）为什么病。** 把权重硬截断到 [−0.01, 0.01]：①容量被削（判别器只能学"极平缓"函数）；②梯度要走窄门（要么挤压要么爆炸）——训练不稳。**病根：约束施加在错误的量上**（权重小 ≠ 梯度处处 ≤1，只是必要非充分）。

**第 3 步：换约束对象——罚梯度本身。** "1-Lipschitz"的字面含义就是 $$\|\nabla_x D\|\le1$$ 处处成立；直接在损失里罚它的平方偏差（软约束）。**为什么在插值点上罚**：理论上最优判别器的梯度范数=1 恰好发生在真假分布**之间**的区域（高维下两支撑不重叠，真实数据点和生成点上的梯度反而正常）——插值带是"交锋前线"，罚这里最对症。

**第 4 步：手算惩罚项。** 某插值点 $$\hat x$$ 上判别器梯度范数 $$\|\nabla_{\hat x}D\| = 2$$：罚项 $$= (2-1)^2 = 1$$；另一处范数 0.5：罚 $$(0.5-1)^2 = 0.25$$——**双向惩罚**（太陡太缓都罚，目标=处处恰好 1）。$$\lambda=10$$ 时这两点分别贡献 10 与 2.5 到总损失。

**第 5 步：读出软约束的性格。** 罚项只影响梯度方向（鼓励但**不强制**），优化在"当好判别器"与"保持 Lipschitz"之间折衷；对比谱归一化的硬保证（直接除以 σ(W)，见 [谱归一化](/ai-fa/explore/30-Formulas/谱归一化)）——软硬取舍总表见 [梯度惩罚与谱归一对照](/ai-fa/explore/30-Formulas/梯度惩罚与谱归一对照)。

## 3. 表示对照表

## 4. 直觉解释

- **"在真假交界地带装测速仪"**：判别器在最前线允许最陡坡度恰为 1——既能拉开真假（判别信号强）又不至于作弊（无限陡=W 距离失真）
- 处处范数=1 是理论最优判别器的性质，GP 把"性质"当"目标"训练
- 惩罚项需要 $$\nabla_{\hat x}D$$（对**输入**的梯度）——与 [Score函数](/ai-fa/explore/40-Concepts/Score函数) 同款"对变量而非参数求导"的视角
