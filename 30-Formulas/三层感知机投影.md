# 三层感知机投影（VLM 视觉-语言接口）

## 1. 标准形式

$$V = \mathrm{MLP}_{2\text{-}3\ \text{layer}}\big(\mathrm{CLIP}_{\text{ViT}}(I)\big), \qquad h_{\text{ctx}} = [\,v_{\text{sys}};\ v_1, \dots, v_K;\ v_{\text{query}}\,]$$

- $I$：图像 → 冻结 ViT 编码出 $K$ 个 patch 嵌入（224²/16² = 196 个）→ **2-3 层 MLP 投到 LLM 词嵌入空间**
- 投影后的 $v_i$ 与文本 token 拼进同一上下文——LLM 像"读一段外语"一样读图
- **全部可训参数就是这个 MLP**（LLaVA-1.5：两层 MLP，~20M 参数——LLM 与 ViT 都冻结）

## 教程：196 个视觉 token 的翻译流水线

**第 1 步：编码（冻结）。** 224×224 图 → ViT/16 → 196 个 1024 维视觉嵌入——CLIP 预训练的"视觉方言"（[[30-Formulas/CLIP对比损失]] 训出的对齐空间）。

**第 2 步：翻译（唯一可训件）。** 两层 MLP：$v = W_2\,\mathrm{GELU}(W_1 e)$——把 1024 维视觉方言译成 LLM 的 $d_{\text{model}}$ 维"词表方言"。**为什么 MLP 就够**：两个空间都已是高质量语义空间，只需学一个低复杂度的"口音转换"，不需要重新理解视觉。

**第 3 步：拼上下文。** $h_{\text{ctx}} = [\text{系统指令};\ v_1..v_{196};\ \text{"图里有什么？"}]$——LLM 对 196 个"视觉词"做标准的自回归注意（每个视觉 token 都能被后续文本 token attend）。

**第 4 步：训练配方（两阶段）。** 阶段一（对齐）：图文对（CC3M）只训 MLP——学会"看图说话"的最小能力；阶段二（指令微调）：GPT-4 生成的图文指令数据，仍只训 MLP（LLaVA-1.5 解冻 LLM）——**文本指令范式直接迁移到图文**。

**第 5 步：与三代范式的账单对比。** Q-Former 把 196 压到 32（省上下文但丢信息）；交叉注意力要动 LLM 内部；MLP 投影**不动两头、只加翻译层**——简单到"糙"，却成了开源主流（LLaVA 系的胜出原因：冻结件可白嫖社区升级）。

## 3. 直觉解释

- **翻译官隐喻**：ViT 和 LLM 两位专家语言不通，MLP 是随身翻译——不懂专业知识但懂两种口音的对应
- 视觉 token 在输入侧不被预测（LLM 不"生成图像"）——只当上下文用（[[40-Concepts/视觉语言模型（VLM）]] 误区区）
- 投影层小 = 训练便宜 + 灾难性遗忘几乎为零（LLM 权重不动）
