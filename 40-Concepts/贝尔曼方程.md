# 贝尔曼方程

## 1. 定义（直觉 → 形式）

**直觉**："当前位置的价值 = 立刻拿到的奖励 + 下一位置价值（打折）"。递归定义价值——像房产估价：这房子值多少 = 租金 + 明年卖掉的价格。

**形式**：
$$V^\pi(s) = \mathbb{E}_{a \sim \pi}\!\left[ r(s, a) + \gamma\, \mathbb{E}_{s' \sim P}\left[ V^\pi(s') \right] \right]$$
**动作值版本**：
$$Q^\pi(s, a) = r(s, a) + \gamma\, \mathbb{E}_{s'}\!\left[ V^\pi(s') \right]$$
**优势函数**（对齐线的主角）：
$$A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)$$
——"这个动作比平均好多少"。正优势 → 加强，负优势 → 抑制。

## 2. 数学形式

- **最优版本**（规划视角）：$V^*(s) = \max_a [r + \gamma \mathbb{E} V^*(s')]$——Q-learning/DQN 的根
- **TD 误差**：$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$——贝尔曼方程的"残差"，GAE 的积木
- **贝尔曼算子**：压缩映射 → 值迭代收敛的依据
- **为什么 LLM 对齐不太用值函数**：回合制、奖励稀疏（只在结尾），$V$ 难学准——GRPO 干脆用组内均值当基线（去掉 critic）

## 4. 常见误区

- **误区**：$V$ 大 = 好状态——是"期望回报"大，不是"立刻奖励"大
- **误区**：优势 = 奖励——优势是**相对**基线的差，同一条轨迹换个基线优势完全不同
- **误区**：LLM 对齐里必须学 $V$——GRPO 证明可用组内基线替代（这是它出圈的原因）
