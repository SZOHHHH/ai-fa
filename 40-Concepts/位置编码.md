# 位置编码 Positional Encoding

## 1. 定义（直觉 → 形式）

**直觉**：注意力对输入顺序"失忆"（集合运算，谁先谁后无所谓）——但语言顺序显然重要（"狗咬人"≠"人咬狗"）。位置编码 = 给每个 token 别上一枚"位置胸牌"，随词向量一起进模型。

**形式**（三代表记法）：
- **绝对正弦**（Transformer 原文）：$PE_{(pos, 2i)} = \sin(pos/10000^{2i/d})$，$PE_{(pos,2i+1)} = \cos(\ldots)$
- **可学习绝对**（GPT/BERT）：$x + p_{\text{pos}}$，$p$ 是可训练参数
- **RoPE 旋转位置编码**（本库标准重点）：
$$\tilde q_m = R_m q, \quad \tilde k_n = R_n k, \quad \langle \tilde q_m, \tilde k_n \rangle = q^\top R_{n-m}^\top k$$
$R_\theta$ 为二维旋转矩阵块——**注意力打分只依赖相对位移 $n - m$**

## 2. 数学形式

- **RoPE 的妙处**：绝对位置旋转 → 内积自动呈现相对性（旋转矩阵 $R_m^\top R_n = R_{n-m}$）
- **外推问题**：绝对编码训练长度 $L$、推理超过 $L$ 时胸牌"查无此人"；RoPE 天然连续但频率分布仍限制外推——催生 PI/NTK/YaRN（线 6）
- **复数视角**：RoPE = 把向量按维度两两组成复数、乘 $e^{im\theta}$
- **LLM 惯例**：$\theta_i = 10000^{-2i/d}$（基频 base，NTK 缩放调的就是这个 10000）

## 4. 常见误区

- **误区**：注意力"知道"位置顺序——不知道！无位置编码时是纯集合运算
- **误区**：RoPE 是相对编码——实现上是**绝对旋转**，只是数学效果上打分呈相对性
- **误区**：位置编码只能加在输入层——RoPE 作用在每层 Q/K 上（V 不旋转）
