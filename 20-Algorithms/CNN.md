# CNN（卷积神经网络）

## 1. 定义

**非数学语言**：用"**滑动共享权重的小窗**"看图像的网络。不是让每个像素连到下层的每个神经元（参数爆炸），而是拿一个很小的权重模板在图上滑动扫描——同一个模板看遍全图。两个先验写死在结构里：**局部性**（邻近像素才相关）与**平移不变**（猫在左上角还是右下角是同一只猫）。层层堆叠后，浅层看边缘纹理、中层看部件、深层看物体。

**数学语言**：离散卷积（严格说是互相关）层叠：
$$y[i,j] = \sum_{k=1}^{K}\sum_{l=1}^{K} W[k,l]\, x[i+k-1,\, j+l-1] + b$$
单个 $K\times K$ 核 $W$ 在整张图上**共享**，参数量从 $d_{in}\times d_{out}$（全连接）降到 $K^2 \times C_{in}\times C_{out}$（与图像尺寸无关）。

## 3. 教程：一张图怎么流过 CNN（从头算一遍）

**第 0 步：图像即数字矩阵。** 一张 224×224 的 RGB 图 = 三个 224×224 的整数矩阵（每格 0-255，红/绿/蓝各一层）——**通道（channel）**就是"同尺寸矩阵的层数"：$C{=}3$。灰度图 $C{=}1$。

**第 1 步：卷积层——模板打分。** 想象一个 3×3 的小窗口权重（**卷积核**），把它贴在图像左上角，窗口内 9 个像素与 9 个权重**逐个相乘再求和**，得到 1 个数；然后窗口右移一格（**步幅 stride=1**），再算 1 个数……扫完整张图，得到一张"打分图"（**特征图 feature map**）。这个打分图的每个值回答："**图像这个位置长得像不像我负责找的那个图案？**"——本质就是 [[40-Concepts/内积]]（相似度）。

**手算例子**（3×3 图 × 一个 3×3 垂直边缘核）：
$$x=\begin{bmatrix} 1&0&1\\ 1&0&1\\ 1&0&1 \end{bmatrix},\quad W=\begin{bmatrix} 1&0&-1\\ 1&0&-1\\ 1&0&-1 \end{bmatrix} \;\Rightarrow\; y[1,1] = \sum(\text{逐元素乘}) = 3$$
窗口中心的值 3 = "这里有一条竖边，响应很强"。同一张图上其他 3×3 区域用**同一个** $W$ 扫——这就是**权重共享**：学会找一次"竖边"，就处处都会找。

**第 2 步：多核多通道。** 一个核只找一个图案，所以一层会用一**组**核（如 64 个），各自扫出一张特征图，叠成 64 通道的输出"立方体"。输入也是多通道时（RGB 3 层），核的深度=输入通道数：3×3×3 的核在 3 通道上同时乘、加成一个数。**输出通道数=核个数，输出尺寸由下面公式定。**

**输出尺寸公式**（输入边长 $n$、核 $K$、填充 $p$、步幅 $s$）：
$$n_{out} = \left\lfloor \frac{n + 2p - K}{s} \right\rfloor + 1$$
例：224×224 图、3×3 核、padding=1、stride=1 → 224×224（尺寸不变，"same" 配置）；stride=2 → 112×112（减半，代替池化做下采样）。

**第 3 步：非线性。** 每个打分过一层 [[40-Concepts/ReLU]]：负分归零（"这里不像我要找的图案"→沉默）。没有这步，多少层卷积叠起来仍等价于一层（线性代数坍缩）。

**第 4 步：池化——缩小与粗化。** 2×2 窗口取 max（**最大池化**）：4 格并 1 格、只留最强响应。效果=尺寸减半+**小位置偏移不再改变结果**（响应最强的位置挪一格，max 不变）——平移不变性的来源之一。

**第 5 步：层层堆叠，视野指数扩大。** 一层 3×3 只直接看原图 9 格（**感受野** receptive field=3）；两层后=5×5；$L$ 层后 $\approx 2L{+}1$——**深度=看多大的范围**。配套现象：浅层核学到边缘/颜色斑块，深层核学到"眼睛""轮子"级部件（特征层级）。

**第 6 步：收尾分类。** 最后的特征图拉平成向量 → 全连接层 → [[40-Concepts/softmax函数]] 输出各类概率，用 [[30-Formulas/交叉熵]] 当损失。

**第 7 步：训练。** 整条链跑在 [[20-Algorithms/反向传播]] 上；卷积的反传有漂亮结构：对输入的梯度=用翻转的核做卷积（**转置卷积**），对核的梯度=输入与误差信号的互相关——仍是卷积运算，GPU 天生擅长。

## 4. 核心公式速查

| 件 | 公式/规则 | 记忆点 |
|---|---|---|
| 卷积 | $y[i,j] = \sum_{k,l} W[k,l]\,x[i{+}k{-}1,\,j{+}l{-}1]+b$ | 核与局部块的内积 |
| 输出尺寸 | $n_{out}=\lfloor (n+2p-K)/s\rfloor+1$ | 代入算一遍就记住 |
| 感受野 | $L$ 层 3×3 堆叠 $\to 2L{+}1$ | 深度买视野 |
| 参数量/层 | $K^2\cdot C_{in}\cdot C_{out} + C_{out}$ | 与图像尺寸无关——共享的红利 |
| 最大池化 | $y[i,j]=\max_{k,l\in \text{窗}} x[k,l]$ | 粗化+小偏移免疫 |
| 空洞卷积 | 采样间隔 $r$ → 感受野 $(K{-}1)r{+}1$ 不加参数 | DeepLabv3+ 用 |

## 7. 对比表（CNN vs ViT：视觉两大范式的交易）

| | CNN | ViT |
|---|---|---|
| 归纳偏置 | 局部+平移不变**写死在结构里** | 几乎没有，靠数据学 |
| 小数据 | 强（先验顶半个老师）✅ | 弱（没数据学不出"平移不变"） |
| 大数据 | 先验反成天花板 | 持续受益，反超 CNN ✅ |
| 计算形态 | 稠密局部运算（对 GPU 极友好） | 全局注意力 $O(n^2)$ |
| 现代地位 | 边缘设备/下游骨干/扩散 UNet 的编码器 | 大规模预训练默认起点 |

## 8. 常见误区

- **误区**："卷积"=数学卷积——CNN 里实际是**互相关**（不翻转核）；两者差一个核翻转，学习场景下无差别（核是学出来的，翻转版同样可学）
- **误区**：池化=下采样同义词——池化额外贡献**局部平移不变**（max 对小偏移免疫），单纯 stride 卷积只缩不改语义
- **误区**：参数少=容易过拟合的反面——CNN 参数少靠共享，但**特征图大时仍会过拟合**（全连接层是重灾区），dropout/正则照样要（见 [[40-Concepts/过拟合与正则化]]）
- **误区**：CNN 被 ViT 淘汰——小数据、边缘部署、像素级稠密任务（分割/扩散 UNet）里 CNN 仍是默认；"范式更替"发生在"大数据预训练"这一段

## 9. 自测（读毕应能回答）

1. 224×224、3 通道、一层 64 个 3×3 核（pad=1, stride=1）：输出形状？参数量？（答：224×224×64；$3{\times}3{\times}3{\times}64{+}64 \approx 1.8$K）
2. 为什么权重共享天然带来平移不变？（同一核处处打同一种分；配合池化的局部 max 免疫）
3. 五层 3×3 堆叠的感受野？（11×11）
4. 卷积层对输入的反传为什么还是卷积？（链式法则展开后恰为翻转核的卷积——见 [[20-Algorithms/反向传播]] 逐层递推）

**一句话总结**：CNN 把"看图的方式"（局部、平移不变、层次化）焊进权重共享的结构里——先用先验省数据，ViT 用数据买掉先验；今天视觉系统大多两者混血（如 Swin 把注意力学回了层次化）。
