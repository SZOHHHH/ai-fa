# Bernoulli Flow Models: Self-Consistent Generative Modeling for Binary Data

## 1. 一句话贡献
为二值数据定义数据分布与纯噪声之间的**连续全局 Bernoulli 概率流路径**，并导出任意时间区间的解析闭式后验转移——于是"减少采样步数"从跳步近似变成换一套时间网格精确重算，不需要蒸馏、不需要额外训练。

## 2. 核心贡献
- **病理诊断**：离散二值扩散（单步前向路径+反向后验）在低 NFE 跨步采样时，被迫用单步似然转移近似真实多步似然，样本质量严重崩塌——这是离散链固有的训练-推理结构性失配。
- **BFM 路径**：不做逐步马尔可夫链，而是在数据与纯噪声之间定义统一的连续全局概率流，把生成动力学从固定离散时间步中解耦。
- **闭式后验**：任意时间区间 $t_s \to t_e$ 的后验转移有解析闭式，降 NFE = 在新时间网格上重算后验，无任何近似。
- **实证**：LSUN Churches 256×256 上 256 步训练、16 步采样 FID 9.22，而 SOTA 离散基线同设置崩到 204.10；全步数推理下与连续/离散基线仍有竞争力。

## 3. 方法概要
1. 为每个二值元素定义从数据比特到噪声比特的连续翻转概率流轨道（时间连续，不是一格一格跳）；
2. 推导任意时间区间上的后验转移闭式（从 $t_s$ 时刻状态直接算 $t_e$ 时刻翻转概率）；
3. 采样 = 在自选的时间网格上依次调用该后验——网格粗细即 NFE 多少，1 步、16 步、256 步都自洽；
4. 训练只在全步网格上进行，推理网格可自由加减密，无蒸馏、无附加训练。

## 4. 核心公式
- 任意区间后验转移（按摘要重述，闭式见原文）：$x_{t_e} \sim \mathrm{Bern}\big(\pi(t_s, t_e, x_{t_s})\big)$
  - 直觉：无论时间跨度多大，"这一段里比特怎么翻"都有解析答案——少步采样不再欠"跳步近似"的债；离散链则是把多步似然硬压成单步转移，步子一大就失真。
- 对照：离散链的后验推导见[[30-Formulas/DDPM后验分布|DDPM后验分布]]（高斯版同理）。
