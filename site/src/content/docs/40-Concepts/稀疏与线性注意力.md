# 稀疏与线性注意力

## 1. 定义（直觉 → 形式）

**直觉**：注意力 $$O(n^2)$$ 的账单来自"人人看人人"。但语言里大多数词对其实**不需要**互相看——像会场发言不需要每人和每人都握手。两类省法：
- **稀疏**：只看该看的（局部窗口+少量全局哨兵）——计算量降但仍是"挑选后的精确注意力"
- **线性**：改写数学让平方项消失（核技巧把 softmax 移进内积）——近似但 $$O(n)$$

**形式**（谱系对照）：

| 家族 | 代表 | 复杂度 | 机制 |
|---|---|---|---|
| 窗口+全局 | Longformer | $$O(nw + ng)$$ | 滑窗 + 全局 token |
| 随机图 | BigBird | $$O(nw + nr)$$ | 窗口+随机+全局三合一（理论：图灵完备&万能近似） |
| 核近似 | Performer | $$O(nd^2)$$ | $$\mathrm{softmax}(QK^\top) \approx \phi(Q)\phi(K)^\top$$（随机特征） |
| 分块环形 | Ring Attention | $$O(n^2)$$ 不变、跨设备分摊 | 序列分块跨 GPU 轮转 |
| 块选择 | MoBA / NSA | $$O(n\cdot k\cdot w)$$ | 路由器选块（top-k 块）——"注意力版 MoE" |
| 保留/压缩 | StreamingLLM（attention sink） | $$O(w)$$ | 只留窗口+起始 sink token |

## 2. 数学形式

- **Performer 的核化**：$$\mathrm{softmax}(q^\top k/\sqrt d) = \mathbb{E}_\omega[e^{\omega^\top q}e^{\omega^\top k}]$$（正交随机特征近似）——**乘法结合律换序**：$$(QK^\top)V \to Q(K^\top V)$$，$$n\times n$$ 消失
- **BigBird 理论保证**：稀疏连接图含窗口+随机+全局 → 序列任务图灵完备、可近似任何序列到序列函数（不止省算力，还有表达力证明）
- **attention sink（StreamingLLM 发现）**：LLM 把大量注意力倾泻到开头几个 token——它们是"注意力垃圾场"（模型学到的无信息泄压阀）。流式推理只要保留 sink + 窗口即可稳定——**一个反直觉的实证发现**
- **MoBA/NSA（2025）**：路由器给每个 query 选 top-k 个 KV 块——与 [混合专家（MoE）](/ai-fa/explore/20-Algorithms/混合专家（MoE）) 同构（专家=块）——稀疏注意力的 MoE 化

## 教程：Performer 换序的数学魔术（平方项消失现场）

**第 1 步：原式的瓶颈结构。** $$\mathrm{softmax}(QK^\top)V$$：$$QK^\top$$ 先算出 $$n\times n$$（**先乘出来**）——平方项就是这一步（[注意力计算复杂度](/ai-fa/explore/30-Formulas/注意力计算复杂度) §1 表）。

**第 2 步：核技巧改写 softmax。** 把 $$e^{q^\top k}$$ 拆成"各自的特征"：$$e^{q^\top k} = \mathbb{E}_\omega[e^{\omega^\top q}\, e^{\omega^\top k}]$$（随机特征 $$\omega$$，正负样本平均掉）——记 $$\phi(q), \phi(k)$$ 为特征映射，则权重矩阵 $$\approx \phi(Q)\phi(K)^\top$$。

**第 3 步：乘法结合律换序（关键一步）。**
$$(\phi(Q)\underbrace{\phi(K)^\top}_{d\times n} V)\; \text{代替}\; (\underbrace{\phi(Q)\phi(K)^\top}_{n\times n}) V$$
括号位置一挪：先算 $$\phi(K)^\top V$$（$$d\times d$$ 小矩阵！）再左乘 $$\phi(Q)$$——**$$n\times n$$ 从未落地**。复杂度 $$O(n^2 d)\to O(nd^2)$$：$$n=32$$k、$$d=128$$ 时从 $$10^{11}$$ 降到 $$5\times10^8$$——**200 倍差距**（代价：softmax 被"平均掉"的近似，精度有损）。

**第 4 步：稀疏路线的对比账本。** $$n=32$$k 时：全注意力 $$n^2 = 10^9$$ 对；Longformer 窗口 $$w{=}512$$：$$nw = 1.6\times10^7$$ 对（60 倍省）；MoBA top-k=8 块×块 512：更少。**稀疏=精确但挑着看；线性=全看但近似**——两条路在"长上下文"汇合（现代选择：原生稀疏 MoBA/NSA 或干脆 SSM 化，[SSM序列架构（Mamba系）](/ai-fa/explore/20-Algorithms/SSM序列架构（Mamba系）)）。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| 长文档 NLP | Longformer/BigBird（2020 代） |
- 百万级上下文训练 | Ring Attention（跨设备） |
| 流式生成 | StreamingLLM |
| 2025 长上下文标配 | MoBA/NSA（DeepSeek 系原生稀疏注意力） |

## 4. 常见误区

- **误区**：稀疏注意力=近似——Longformer/BigBird 是**精确**计算（只是少算对）；Performer 才是近似
- **误区**：线性注意力已被淘汰——SSM 对偶理论（[状态空间模型方程](/ai-fa/explore/30-Formulas/状态空间模型方程)）让它复活并统一
- **误区**：attention sink 是 bug——是模型自发的稳定机制，删掉反而崩

## 5. 自测

1. Performer 换序为什么能消平方项？（结合律：$$\phi(Q)(\phi(K)^\top V)$$——中间矩阵从 $$n\times n$$ 变 $$d\times d$$）
2. 稀疏与线性各牺牲什么？（稀疏牺牲"看到的对"（局部性假设）；线性牺牲 softmax 的精确性（核近似））
3. attention sink 是什么？（开头 token 吸走大量注意力=模型泄压阀；流式推理保 sink+窗口即稳）
4. MoBA 与 MoE 的同构点？（路由器选块=选专家——top-k 稀疏激活的同一数学）
