# 常微分方程 ODE

## 1. 定义（直觉 → 形式）

**直觉**：给每个位置的点规定一个"该往哪走、走多快"的速度场，ODE 描述的就是一颗粒子在这个速度场里随时间运动的轨迹。**确定性**：起点定了，整条轨迹就定了。

**形式**：
$$\frac{dx}{dt} = v(x_t, t)$$
- $v(x_t, t)$：速度场（每个位置、每个时刻的速度）
- 解 $x(t)$：轨迹（流线）
- **初值问题**：给定 $x(0)$，求 $x(t)$——数值上用欧拉法 / RK45 等积分器求解

**流 Flow**：把"从起点出发沿速度场走到终点"的映射记为 $\phi_t$：$x(t) = \phi_t(x(0))$。这个映射把初始分布推着走：$p_t = \phi_t \# p_0$（推前 pushforward）。

## 2. 数学形式

- **欧拉离散化**：$x_{t+\Delta t} \approx x_t + \Delta t \cdot v(x_t, t)$——所有"采样步数"的本质
- **存在唯一性**：$v$ 满足 [[40-Concepts/Lipschitz连续]] 时，初值问题有唯一解
- **与 SDE 的关系**：[[40-Concepts/随机微分方程（SDE）|随机微分方程]] 去掉噪声项 $dw$ 就是 ODE；概率流 ODE 与 Score-SDE 边缘分布相同（见 [[30-Formulas/概率流ODE]]）
- **常微分 ≠ 偏微分**：变量只有时间 $t$ 一个自变量的导数（PDE 还含空间偏导）

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [[20-Algorithms/流匹配]] | 训练速度场 $v_\theta$，采样 = 数值积分 ODE |
| [[30-Formulas/概率流ODE]] | 每个 SDE 都有同边缘分布的确定性 ODE 伴生 |
| [[20-Algorithms/矩形流]] | 目标是学"直"的 ODE 轨迹，一步到位 |
| 神经 ODE | ResNet 的连续深度极限 |
| Mamba/SSM（线 1） | 状态空间模型源于 ODE 的离散化 |

**生成模型的两大世界观**：随机（SDE 采样，多样性）vs 确定性（ODE 采样，可逆、快、可精确控制）。同一模型的两种采样方式等价。

## 4. 常见误区

- **误区**：ODE 解不出解析解 → 解不了。数值积分即可，生成模型全靠欧拉/RK
- **误区**：ODE 轨迹不交叉（流的自洽性）；流匹配想学的"直轨迹"正是不交叉的理想
- **误区**：步数少误差大是欧拉法的锅，不是 ODE 本身的问题——高阶积分器可换
