# 蒸馏损失（KD）

## 1. 标准形式

$$\mathcal{L}_{\text{KD}}(\theta_S) = \tau^2\, \mathbb{E}_{x}\!\left[ D_{\mathrm{KL}}\!\left( \mathrm{softmax}\!\left(\frac{z_T(x)}{\tau}\right)\ \Big\|\ \mathrm{softmax}\!\left(\frac{z_S(x)}{\tau}\right) \right) \right]$$

**总损失（实操标准）**：
$$\mathcal{L} = \alpha\,\mathcal{L}_{\text{KD}} + (1-\alpha)\,\mathcal{L}_{\text{CE}}(y, p_S)$$
（软标签 + 硬标签按 $\alpha$ 混合，典型 $\alpha = 0.5$–0.9，$\tau = 2$–4）

## 教程：教师软标签手算（学生一步降损 5 倍）

**第 1 步：设定。** 三分类（猫/狗/卡车）。教师 logits $(2, 1, 0)$（本库温度家族共用数字，见 [[40-Concepts/温度参数]]），$\tau = 4$：$p_T = \mathrm{softmax}(0.5, 0.25, 0) = (0.419,\ 0.326,\ 0.254)$。

**第 2 步：学生起点。** 学生 logits $(1,1,1)$ → $\tau=4$ 下 $(0.333, 0.333, 0.333)$。$\mathrm{KL}(T\Vert S) = 0.419\ln\frac{0.419}{0.333} + 0.326\ln\frac{0.326}{0.333} + 0.254\ln\frac{0.254}{0.333} = 0.0962 - 0.0070 - 0.0687 = 0.0205$。

**第 3 步：学一步。** 学生 logits → $(1.5, 1, 0.5)$（向教师方向挪）→ $\tau=4$ 下 $(0.376, 0.331, 0.293)$。$\mathrm{KL} = 0.0453 - 0.0050 - 0.0363 = 0.0040$——**挪 0.5，损失降 5 倍**：软标签的梯度面平滑连续，每一步都有信号。

**第 4 步：τ² 前缀的账。** 报告损失 $= \tau^2\times\mathrm{KL} = 16\times0.0040 = 0.064$——补偿 $\partial(z/\tau)$ 链式因子后，KD 项与硬标签 CE 项（$\sim1$ 量级）**同尺度可混合**：$\mathcal{L} = \alpha\,\mathcal{L}_{\text{KD}} + (1-\alpha)\,\mathcal{L}_{\text{CE}}$ 里的 $\alpha$ 才有意义。

**第 5 步：软硬信息对照。** 硬标签 $(1,0,0)$ 的 CE 只推猫的 logit——狗/卡车收到的都是"零"；软标签 $(0.419, 0.326, 0.254)$ 三个类都有信号：猫:狗 $= 1.29:1$ 教了"猫狗相近"、猫:卡车 $= 1.65:1$ 教了"猫卡车疏远"——**一次前向把 $\binom{K}{2}$ 对类间关系全部传递**（暗知识的账本）。

## 3. 直觉解释

- **软标签的信息增益**：教师说"0.7 猫 0.2 狗 0.1 卡车"——猫狗相似性是**免费的结构信息**，硬标签没有
- **τ 的作用**：高温把微小 logit 差放大成可学的概率差；$\tau^2$ 前缀补偿梯度幅度（$\partial z/\tau$ 的链式因子）
- **KL 方向**：$\mathrm{KL}(T\|S)$——学生覆盖教师的全部支撑（前向 KL 的质量覆盖性质，见 [[40-Concepts/KL散度]]）
- `#loss/expectation-of-ratio`（log-概率比期望族）

## 6. 自测

1. 教师 $(2,1,0)$、$\tau=4$ 的软标签？（$(0.419, 0.326, 0.254)$——与温度卡同款数字）
2. 学生从 $(1,1,1)$ 挪到 $(1.5,1,0.5)$：KL 变化？（$0.0205 \to 0.0040$——降 5 倍）
3. $\tau^2$ 前缀补什么？（$\partial(z/\tau)$ 链式因子——让 KD 项与 CE 同尺度可按 $\alpha$ 混合）
4. 软标签比硬标签多传了什么？（$\binom{K}{2}$ 对类间相似关系——暗知识）
