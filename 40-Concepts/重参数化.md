# 重参数化技巧 Reparameterization

## 1. 定义（直觉 → 形式）

**直觉**：从 $z \sim \mathcal{N}(\mu_\phi, \sigma_\phi^2)$ 采样，梯度没法穿过"随机"这个操作传回 $\mu_\phi, \sigma_\phi$。**把随机性搬到旁边**：写成 $z = \mu_\phi + \sigma_\phi \odot \epsilon,\ \epsilon \sim \mathcal{N}(0, I)$——随机性来自外部的 $\epsilon$，$\mu, \sigma$ 变成普通可导函数的一部分。

**形式**：
$$z \sim q_\phi(z \mid x) \quad\Longrightarrow\quad z = g_\phi(\epsilon; x),\ \epsilon \sim p(\epsilon)$$
$$\mathbb{E}_{z \sim q_\phi}[f(z)] = \mathbb{E}_{\epsilon \sim p(\epsilon)}[f(g_\phi(\epsilon; x))]$$
右式的期望分布与 $\phi$ 无关，梯度可以穿过 $g_\phi$ 直达参数。

## 2. 教程：为什么必须搬、搬了之后梯度长什么样（全程手算）

**第 1 步：直面"梯度穿不过采样"。** 想算 $\nabla_\mu \mathbb{E}_{z\sim\mathcal{N}(\mu, 1)}[z^2]$。朴素写法：采样 $z_1,\dots,z_N$ 求平均梯度 $\frac{1}{N}\sum z_i^2$——**但对这个平均数求 $\mu$ 的导数时，$z_i$ 像常数一样纹丝不动**（采样操作没有导数）。梯度=0？错！真值明明随 $\mu$ 变（$\mathbb{E}[z^2]=\mu^2+1$，导数 $2\mu$）。**梯度信息藏在"分布的参数"里，而采样把这条路切断了。**

**第 2 步：两种暴力解法都不好用。** ①有限差分（扰动 $\mu$ 重采样对拍）：每参数两次前向，维度大时灾难；②score function（REINFORCE，[[40-Concepts/RL中的log导数技巧]]）：$\nabla_\mu\mathbb{E}[f] = \mathbb{E}[f(z)\nabla_\mu\log q(z)]$——数学正确但**方差极大**（梯度估计像掷骰子），VAE 这种深链上训练不稳。

**第 3 步：重参数化手算（同一道题）。** $z = \mu + \epsilon,\ \epsilon\sim\mathcal{N}(0,1)$：
$$\mathbb{E}_\epsilon[(\mu+\epsilon)^2] = \mu^2 + \underbrace{2\mu\,\mathbb{E}[\epsilon]}_{=0} + \underbrace{\mathbb{E}[\epsilon^2]}_{=1} = \mu^2 + 1$$
对 $\mu$ 求导：$2\mu$——**每个 Monte Carlo 样本 $(\mu+\epsilon_i)^2$ 都是 $\mu$ 的可导函数**，梯度 $2(\mu+\epsilon_i)$，平均后精确估计 $\mathbb{E}[2\mu+2\epsilon]=2\mu$ ✓。随机性全在 $\epsilon$ 里（与参数无关），确定性通路 $g_\phi$ 上梯度畅通。

**第 4 步：方差红利（为什么第 2 步的替代法被淘汰）。** 同样的样本量，重参数化估计的方差通常小几个数量级：score-function 法梯度样本= $f(z)\times(\text{评分函数})$（两个随机量相乘）；重参数化法梯度样本=$f'(g_\phi(\epsilon))\,\nabla_\phi g_\phi$（沿同一条确定路径的局部导数）。**这就是 VAE/扩散训练稳定的微观原因之一**。

**第 5 步：家族清单（哪些分布可搬）。** 位置-尺度族（高斯 $\mu+\sigma\epsilon$、拉普拉斯）、可逆变换（对数正态 $z=\exp(\mu+\sigma\epsilon)$）、Gumbel-Softmax（离散的连续松弛）、**Diffusion 式**：$x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$（[[30-Formulas/DDPM前向过程]] 的任意时刻一步采样）。**不可搬**：硬离散采样（VQ-VAE 用 straight-through 假装梯度，[[30-Formulas/VQ-VAE目标]]）。

## 3. 数学形式速查

- **等价改写**：$z$ 的分布分毫不差（同一分布的两种生成方式），变的只是梯度通路
- **反传链**：$\nabla_\phi \mathbb{E}[f] = \mathbb{E}[\nabla_\phi f(g_\phi(\epsilon))] \approx \frac{1}{N}\sum_i \nabla_\phi f(g_\phi(\epsilon_i))$
- **适用条件**：分布能写成"参数的确定函数+与参数无关的噪声"
- **与 score function 梯度对比**：后者通用（连离散都行）但方差大；重参数化受限（位置-尺度/可逆）但方差小——扩散模型训练能稳定收敛的原因之一

## 5. 常见误区

- **误区**：重参数化"改变了分布"——没有，$z$ 的分布分毫不差，只是生成方式的等价改写（§2 第 3 步验证过期望不变）
- **误区**：所有分布都能重参数化——离散分布不行（VQ-VAE 的 straight-through 是绕行方案）；连续分布也要能写成"确定函数+外噪声"形
- **误区**：VAE 里的 $\epsilon$ 与扩散里的 $\epsilon$ 是同一个东西——记号撞车：都是标准高斯噪声，但前者指编码噪声（采样 z），后者指扩散加噪的**回归目标**（网络学预测的就是它）
- **误区**：它只是"工程小技巧"——它决定了**哪类生成模型可训**（低方差梯度）；score-function 路线的模型族（如某些离散 VAE）训练难度的分水岭就在这

## 6. 自测

1. $\nabla_\sigma \mathbb{E}_{z\sim\mathcal{N}(\mu,\sigma^2)}[z^2]$ 用重参数化算？（$z=\mu+\sigma\epsilon$，$\mathbb{E}[(\mu+\sigma\epsilon)^2]=\mu^2+\sigma^2$ → $2\sigma$）
2. 为什么 score-function 法方差大？（梯度样本=函数值×评分函数两个随机量相乘；重参数化=同一路径的局部导数）
3. DDPM 的 $x_t$ 公式里哪部分是 $g$ 哪部分是 $\epsilon$？（$g(x_0,\bar\alpha_t)=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$——噪声作为输入参与确定函数）
4. 硬离散采样为什么不能搬？（$\text{argmax}$/掷骰选类别无"参数的确定函数"表示——输出对参数不连续）
