# 激活函数族（全谱）

## 1. 定义（直觉 → 形式）

**直觉**：没有非线性，一百层网络 = 一层线性网络（矩阵连乘还是矩阵）。激活函数就是**每一层末尾的"弯折器"**——把直线掰弯，让叠层产生表达力。选哪个弯法，就是这一族的历史。

**形式**：逐元素非线性 $\phi:\mathbb{R}\to\mathbb{R}$，插入线性变换之间：$h_{l+1} = \phi(W h_l + b)$。

## 2. 族谱时间线（弯折方式的演进）

| 世代 | 函数 | 公式 | 关键性质 | 地位 |
|---|---|---|---|---|
| 早期 | **sigmoid** | $\frac{1}{1+e^{-x}}$ | 两端饱和（梯度归零） | 详见 [[40-Concepts/sigmoid函数]]；隐藏层已被淘汰，出口/门控仍在 |
| 早期 | **tanh** | $\tanh(x) = 2\sigma(2x)-1$ | 零中心（−1,1）、两端饱和 | LSTM 门的标准件；零中心使梯度方向无偏，优于 sigmoid |
| 2011 | **ReLU** | $\max(0, x)$ | 不饱和（正区梯度恒 1）、计算廉价 | AlexNet 功臣，深度学习的"平民革命"——杀死了饱和问题 |
| 2016 | **softplus** | $\log(1+e^{x})$ | ReLU 的平滑版（处处可导） | Mamba 选择机制用（$\Delta t$ 恒正）；$\log\sigma(x) = -\mathrm{softplus}(-x)$ |
| 2017 | **Swish/SiLU** | $x \cdot \sigma(x)$ | 自门控：负区不硬归零（留小尾巴） | 平滑版 ReLU，SwiGLU 的"Swi" |
| 2018 | **GELU** | $x\,\Phi(x)$ | 概率门控：按"输入像正态哪一段"加权通过 | [[30-Formulas/GELU激活]]；BERT/GPT 系默认 |
| 现代 | **SwiGLU** | $\mathrm{Swish}(xW_1)\odot xW_2$ | 门控×双路投影 | [[30-Formulas/SwiGLU门控]]；LLaMA 起现代 FFN 标配 |

- **主线剧情 = 与"死区/饱和"作战**：sigmoid/tanh 两端压平 → 梯度消失 → ReLU 硬截断（但负区死区、原点不可导）→ softplus/Swish/GELU 逐代平滑化 → 最终收敛到"**门控线性**"思想（负区不是砍掉而是留门缝）
- tanh 与 sigmoid 的换算 $\tanh(x) = 2\sigma(2x) - 1$：同一条曲线的居中缩放版——讨论饱和性时二者同罪

## 3. 为什么需要这一族（机器学习视角）

- **表达力来源**：通用逼近定理——叠加+逐元素非线性可以逼近任意连续函数；纯线性叠层无论多深都坍缩成一层
- **梯度视角选型**：ReLU 正区梯度恒 1 = 深层网络梯度的"高速公路"；sigmoid 饱和区梯度 ≈ $\phi(1-\phi)$ ≤ 0.25 = 每层至少砍掉 3/4——二十层后信号所剩无几（这是深度网络早期训不动的核心原因之一）
- **门控视角（现代标准答案）**：Swish/GELU/SwiGLU 共享同一思想——**输出 = 线性主干 × 门**，门由输入自己决定开多大。MoE 路由（[[30-Formulas/MoE门控公式]]）与 LSTM 遗忘门是这个思想在"层间/时间维"的放大版
- **零中心性**：tanh 优于 sigmoid、且 bias 可补——梯度更新方向更少互相拉扯；ReLU 非零中心但有 BatchNorm/RMSNorm 兜底，现代网络已不敏感

## 4. 常见误区

- **误区**："新激活一定更好"—— SwiGLU 在 LLM FFN 位赢了，但 RL 策略头/门控位 sigmoid 仍不可替代；**位置决定选择，不逐代全面替代**
- **误区**：ReLU 的"死神经元"（负区恒 0）纯是缺陷——对稀疏激活有正贡献（每层只放行部分通路）；学习率过大才把它变成灾难
- **误区**：tanh 只是"另一个 sigmoid"——零中心带来更健康的梯度方向统计，LSTM 保留 tanh 不用 sigmoid 做状态候选是有讲究的
- **误区**：GELU/Swish 的平滑是"锦上添花"——平滑保证处处有梯度（含原点），在深网络+强正则下稳定性差异是实证显著的
