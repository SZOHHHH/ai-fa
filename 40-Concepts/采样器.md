# 采样器与数值积分器

## 1. 定义（直觉 → 形式）

**直觉**：模型训练好后，怎么"画出"一张图？两种思路：
- **随机采样器**：按反向 SDE 一步步走，每步注入新噪声（DDPM 祖先采样）
- **确定性积分器**：按概率流 ODE 走，无噪声（DDIM / FM 采样）

**形式**：把连续过程离散化为 $N$ 步，每步 $t_i \to t_{i+1}$：
- **欧拉法**（ODE 基础款）：$x_{t+\Delta t} \approx x_t + \Delta t \cdot v(x_t, t)$
- **祖先采样**（DDPM 式）：$x_{t-1} \sim p_\theta(x_{t-1} \mid x_t)$，每步重采样高斯
- **Heun 二阶**（EDM 主推）：欧拉预估 + 校正，同样步数误差低一阶

## 2. 数学形式

| 采样器 | 类型 | 每步算什么 | 步数敏感度 |
|---|---|---|---|
| 祖先采样（DDPM） | 随机 | 预测均值 + 注入噪声 $\sigma_t z$ | 高（50–1000 步） |
| DDIM | 确定性 | 沿 ODE 方向走，噪声项置零（$\eta=0$） | 低（10–50 步） |
| Euler（FM/Rectified Flow 常用） | 确定性 | 欧拉一步 | 中 |
| Heun / DPM-Solver | 确定性高阶 | 预估-校正 / 高阶项 | 低（10–20 步） |
| 朗之万 | 随机 | score 步 + 噪声步 | 极高 |

- **随机 vs 确定性的等价性**：同一模型可两用（SDE ↔ 概率流 ODE 边缘分布相同），随机版样本更多样、确定性版可逆可插值
- **步数-质量权衡**：这是"扩散采样慢"的来源，也是蒸馏线（Consistency Models、DMD）要消灭的对象

## 教程：欧拉三步走一条 ODE（手算全场）

**第 1 步：设定。** 概率流 ODE 最简单的教学版：$\frac{dx}{dt} = -x$（从 $t{=}0$ 的 $x_0$ 流向 $t{=}1$ 的 0——"一切流向原点"的退化流场），步长 $\Delta t = 1/3$，起点 $x = 1$。

**第 2 步：欧拉三步（每步=当前位置×斜率×步长）。**
$$x_1 = 1 + \tfrac{1}{3}(-1) = 0.667,\quad x_2 = 0.667 + \tfrac{1}{3}(-0.667) = 0.444,\quad x_3 = 0.444 + \tfrac{1}{3}(-0.444) = 0.296$$
真解是 $e^{-1}\approx 0.368$——欧拉偏低（0.296），**局部误差 $O(\Delta t^2)$ 累积成全局 $O(\Delta t)$**。

**第 3 步：Heun 校正（同预算提一阶）。** 每步先欧拉试探到 $\tilde x = x + \Delta t\, v(x)$，再用**两端斜率平均**走真步：$x_{new} = x + \frac{\Delta t}{2}(v(x)+v(\tilde x))$。第一步：$\tilde x = 0.667$，$v$ 平均 $= (-1 - 0.667)/2 = -0.833$，$x_1 = 1 - 0.278 = 0.722$（真解 $e^{-1/3}=0.717$——误差从 0.05 缩到 0.005，**一阶换二阶**）。EDM 选 Heun 的全部理由就是这条账。

**第 4 步：随机版长什么样（DDPM 祖先采样对照）。** $x_{t-1} = \underbrace{\mu_\theta(x_t)}_{\text{确定性均值}} + \sigma_t z$——前半=欧拉式沿场走，后半=注入新噪声；$\eta{=}0$（DDIM）砍掉后半就回到确定性 ODE 轨道。**同模型两种走法边缘分布相同**（SDE↔概率流 ODE），选择是工程口味：随机版样本更"活"、确定性版同 z 必同图（可复现/可插值）。

**第 5 步：为什么蒸馏要杀步数。** 一步欧拉 vs 一步 Heun 误差差一个量级——但 20 步 Heun 仍要 20 次网络前向；Consistency/DMD 蒸馏直接学"跳到终点"的映射，把 20 次压成 1 次。**采样器=免费午餐区**（不动模型只动走法），蒸馏=动模型的终极区。

## 4. 常见误区

- **误区**："采样慢 = 模型差"——是数值积分步数问题，与模型质量正交
- **误区**：确定性采样"丢多样性"——边缘分布相同，多样性源于初始噪声 $z$ 的不同
- **误区**：祖先采样的噪声项"可以随便去掉"——$\eta$ 控制随机性比例，DDIM 是 $\eta=0$ 特例不是"错误用法"

## 5. 自测

1. $\frac{dx}{dt}=-x$、$\Delta t=0.5$、$x_0=1$，欧拉两步后？（$x_1=0.5$；$x_2=0.25$——真解 $e^{-1}\approx0.37$，步子大误差猛）
2. Heun 每步要算几次网络前向？为什么还更划算？（2 次；误差阶从 $O(\Delta t)$ 到 $O(\Delta t^2)$——同精度下总前向次数更少）
3. DDIM 与祖先采样同模型，差别写在哪一项？（噪声注入项 $\eta\sigma_t z$：$\eta=0$ 确定性轨道）
4. 确定性采样为什么天然支持插值？（z 与图像一一对应——两个 z 的球面插值对应图像连续变形）
