# 贝尔曼方程

## 1. 定义（直觉 → 形式）

**直觉**："当前位置的价值 = 立刻拿到的奖励 + 下一位置价值（打折）"。递归定义价值——像房产估价：这房子值多少 = 租金 + 明年卖掉的价格。

**形式**：
$$V^\pi(s) = \mathbb{E}_{a \sim \pi}\!\left[ r(s, a) + \gamma\, \mathbb{E}_{s' \sim P}\left[ V^\pi(s') \right] \right]$$
**动作值版本**：
$$Q^\pi(s, a) = r(s, a) + \gamma\, \mathbb{E}_{s'}\!\left[ V^\pi(s') \right]$$
**优势函数**（对齐线的主角）：
$$A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)$$
——"这个动作比平均好多少"。正优势 → 加强，负优势 → 抑制。

## 2. 数学形式

- **最优版本**（规划视角）：$V^*(s) = \max_a [r + \gamma \mathbb{E} V^*(s')]$——Q-learning/DQN 的根
- **TD 误差**：$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$——贝尔曼方程的"残差"，GAE 的积木
- **贝尔曼算子**：压缩映射 → 值迭代收敛的依据
- **为什么 LLM 对齐不太用值函数**：回合制、奖励稀疏（只在结尾），$V$ 难学准——GRPO 干脆用组内均值当基线（去掉 critic）

## 教程：解一个自洽方程（+优势的平均必为零）

**第 1 步：写出自洽方程。** 玩具宇宙（[[40-Concepts/马尔可夫决策过程]] 教程）：$V^\pi(s_1) = 0.6\times[0+0.9\,V^\pi(s_1)] + 0.4\times[1+0.9\times0] = 0.54\,V^\pi(s_1) + 0.4$——**未知数出现在自己的定义里**（递归）。

**第 2 步：代数解出。** 移项：$V(1-0.54) = 0.4$ → $V = 0.4/0.46 = 0.870$。无穷条轨迹的期望被一个方程替代——这就是贝尔曼方程的全部威力。

**第 3 步：迭代视角（模型未知时的解法）。** $V_0 = 0 \to V_1 = 0.4 \to V_2 = 0.54\times0.4+0.4 = 0.616 \to V_3 = 0.733 \to V_4 = 0.796 \to V_5 = 0.830 \to \cdots \to 0.870$——每轮误差乘 0.54（压缩收敛），这就是策略评估的值迭代现场。

**第 4 步：Q 与优势。** $Q^\pi(a_{慢}) = 0+0.9\times0.870 = 0.783$；$Q^\pi(a_{赢}) = 1$。优势 $A(a_{慢}) = 0.783-0.870 = -0.087$、$A(a_{赢}) = +0.130$。

**第 5 步：优势的策略加权平均（PPO/GRPO 的命根）。** $\mathbb{E}_\pi[A] = 0.6\times(-0.087)+0.4\times(+0.130) = -0.052+0.052 = 0$——**精确为零**（$\mathbb{E}_\pi[Q] = V$ 的直接推论）：优势度量的是"相对平均"，好动作的正优势必然由坏动作的负优势对冲——这就是它能当基线差、让策略梯度只学"相对好坏"的原因。

## 4. 常见误区

- **误区**：$V$ 大 = 好状态——是"期望回报"大，不是"立刻奖励"大
- **误区**：优势 = 奖励——优势是**相对**基线的差，同一条轨迹换个基线优势完全不同
- **误区**：LLM 对齐里必须学 $V$——GRPO 证明可用组内基线替代（这是它出圈的原因）

## 5. 自测

1. 解 $V = 0.54V + 0.4$？（$V = 0.4/0.46 = 0.870$）
2. 优势的策略加权平均恒等于什么？为什么？（零——$\mathbb{E}_\pi[Q] = V$ 的推论：正负优势必然对冲）
3. $V_0=0$ 迭代第三次得多少？收敛速率？（$V_3 = 0.733$；每轮误差 ×0.54）
4. LLM 对齐为什么难用 $V$？（回合制+奖励稀疏（只在结尾）——$V$ 难学准，GRPO 用组内均值替代）
