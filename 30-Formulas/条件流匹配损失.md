# 条件流匹配损失

## 1. 标准形式（本库统一记号）

$$\mathcal{L}_{\text{FM}}(\theta) = \mathbb{E}_{t,\ x_0 \sim p_{\text{data}},\ z \sim p(z)}\!\left[ \left\| v_\theta\!\left( x_t,\ t \right) - u_t\!\left( x_t \mid x_0, z \right) \right\|_2^2 \right]$$

其中插值路径与条件速度场：
$$x_t = \alpha_t\, x_0 + \sigma_t\, z, \qquad u_t = \alpha_t'\, x_0 + \sigma_t'\, z, \qquad t \in [0, 1]$$
- $\alpha_t, \sigma_t$：调度函数（如线性 $\alpha_t = 1-t,\ \sigma_t = t$）
- $\alpha_t' , \sigma_t'$：它们对时间的导数
- $v_\theta$：学习的速度场网络；$u_t(x_t \mid x_0, z)$：沿单条样本路径的条件速度（可算！）

**关键定理**：最小化上式 ⇔ 最小化边缘速度场的匹配 $\|v_\theta - u_t(x_t)\|^2$——用可算的条件目标训练出不可算的边缘目标，采样用 $dx/dt = v_\theta$ 积分。

## 2. 表示对照表

| 表示名 | 公式核心 | 出处 | 说明 |
|---|---|---|---|
| 一般条件插值（本库标准） | $x_t = \alpha_t x_0 + \sigma_t z$ | Lipman et al. 2022；Albergo & Vanden-Eijnden | 统一框架 |
| 线性插值 | $x_t = (1-t)x_0 + t z$，$u_t = z - x_0$ | Rectified Flow Liu et al. 2022 | 最简单：恒速直线 |
| OT 路径 | $\alpha_t = 1-t,\ \sigma_t = t(1-t)\sigma_{\min}$ | Lipman 2022 (OT-CFM) | 近似最优传输，轨迹更直 |
| 扩散插值 | $\alpha_t = \sqrt{\bar\alpha_t},\ \sigma_t = \sqrt{1-\bar\alpha_t}$ | FM 论文对照节 | 与 DDPM 逐步公式**逐点相同** |
| score/噪声参数化 | $v_\theta \approx u_t = \sigma_t s + \alpha_t' \ldots$ | FM↔扩散换算 | 预测速度 vs 预测噪声/score 的换算表 |

**符号统一立法**：本库 FM 线以 $x_0$（数据）$\to z$（噪声）为**去噪方向**，$t: 0 \to 1$ 加噪（与 [[30-Formulas/DDPM前向过程]] 一致）。Rectified Flow 原文方向相反（$t:0\to1$ 噪声→数据），入库时已改写为本库标准，原文记法记录于此。

## 2b. 与扩散的形式对偶（本库重点解读）

| | 扩散 | 流匹配 |
|---|---|---|
| 预测量 | $\epsilon_\theta$ 或 $s_\theta$ | $v_\theta$ |
| 路径 | 固定高斯链 / SDE | 任意插值（可选直线） |
| 采样 | 祖先 / 概率流 ODE | 概率流 ODE（常 Euler） |
| 损失形式 | $\|\epsilon - \epsilon_\theta\|^2$ | $\|u_t - v_\theta\|^2$（同一骨架）|

## 教程：两条相反路径的交叉打架（CFM 定理现场）

**第 1 步：单条路径的完整手算。** 线性插值 $\alpha_t = 1-t,\ \sigma_t = t$；抽到数据 $x_0 = 2$、噪声 $z = 1$：路径 $x_t = (1-t)\cdot2 + t\cdot1 = 2 - t$；条件速度 $u_t = \alpha_t' x_0 + \sigma_t' z = -2 + 1 = -1$——**恒速直线**。抽 $t = 0.5$：考题 = 在 $(x_t, t) = (1.5,\ 0.5)$ 处，回归 $\|v_\theta(1.5, 0.5) - (-1)\|^2$。**条件目标闭式可算**——这就是 CFM 的全部训练。

**第 2 步：两条路径打架。** 另抽一对 $(x_0, z) = (0, 2)$：路径 $x_t = 2t$（0→2），速度 $u = +2$；第三对 $(x_0, z) = (2, 0)$：路径 $x_t = 2 - 2t$（2→0），速度 $u = -2$——**两条路径在同一段线（0 到 2）上完全重叠、方向相反**。在 $x = 1$（双方都在 $t = 0.5$ 经过）：一个目标 $+2$、一个目标 $-2$。

**第 3 步：边缘场是什么。** 边缘速度 $u_t(x) = \mathbb{E}[u_t \mid x_t = x]$——两条路径等权时 $x=1$ 处的边缘目标 $= \frac{2+(-2)}{2} = 0$：**推力互相抵消**（这正是 [[20-Algorithms/矩形流]] "轨迹弯、不敢大步"的病根数字版）。但边缘目标要按 $p(x_t = x)$ 加权平均——**不可直接计算**（不知道边缘分布）。

**第 4 步：CFM 定理救场。** 定理：回归**可算的条件目标**（每步只看一条路径，目标 ±2 明确无歧义）在期望意义下 = 回归**不可算的边缘目标**——网络学到的正是那个"打架后的平均场"。训练用条件、采样用边缘——**免费的数学**。

**第 5 步：读法。** 打架是常态（随机耦合天然交叉）——消除打架 = 让路径不重叠 = reflow（用自己生成的端点对重新耦合）；或换 OT 路径（最小化交叉的耦合）——FM 系的改进全在"治理打架"上做文章。

## 3. 直觉解释

- 给每对（数据 $x_0$，噪声 $z$）画一条从 $x_0$ 到 $z$ 的路径，网络学"任意点在这条路径上的速度方向"
- 无数条路径叠加后，$v_\theta$ 收敛到**边缘场**——把整个数据分布平滑搬运到噪声分布
- **直线路径的好处**：轨迹直 → 采样步数少、少弯路；Rectified Flow 的 reflow 迭代让轨迹更直
- `#loss/regression`：又是平方误差——与 DDPM 同族，只是"预测量"从噪声换成速度

## 6. 自测

1. $(x_0,z) = (2,1)$ 线性插值：$x_{0.5}$ 与 $u$？（$1.5$；$u = -2+1 = -1$ 恒速直线）
2. 路径 $(0,2)$ 与 $(2,0)$ 在 $x=1$ 处各要什么速度？（$+2$ 与 $-2$——方向相反打架，边缘目标 0）
3. CFM 定理说了什么？（回归条件目标（可算）= 期望意义回归边缘目标（不可算）——训练采样各用一半）
4. 打架怎么治？（reflow 重新耦合 / OT 路径——FM 系改进的公共主题）
