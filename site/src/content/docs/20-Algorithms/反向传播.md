# 反向传播（Backpropagation）

## 1. 定义

**非数学语言**：训练一切神经网络的核心引擎。前向一趟算出损失并**记下途中每一步的中间值**；然后从损失出发，沿计算路径**反向**逐层追问"每个参数对这次误差负多大责任"，把责任（梯度）一路分摊回每个权重。它不是学习算法本身——它只是高效算梯度的簿记术，真正"学习"发生在梯度下降拿这些梯度去更新参数时（见 [梯度下降与优化器谱系](/ai-fa/explore/20-Algorithms/梯度下降与优化器谱系)）。

**数学语言**：[梯度](/ai-fa/explore/40-Concepts/梯度) 上**链式法则的动态规划实现**。对 $$L$$ 层网络记 $$z_l = W_l h_{l-1} + b_l,\; h_l = \phi(z_l)$$，定义误差信号 $$\delta_l = \nabla_{z_l} \mathcal{L}$$，则：
$$\delta_L = \nabla_{a}\mathcal{L} \odot \phi'(z_L), \qquad \delta_l = (W_{l+1}^\top \delta_{l+1}) \odot \phi'(z_l)$$
$$\nabla_{W_l}\mathcal{L} = \delta_l\, h_{l-1}^\top, \qquad \nabla_{b_l}\mathcal{L} = \delta_l$$

## 3. 教程：一行数字走完前向+反向（手算全过程）

**网络**：1-1-1 三层（输入 $$x$$ → 隐层 → 输出），权重 $$w_1 = 0.5$$（输入→隐）、$$w_2 = 0.3$$（隐→出），激活 $$\phi(z) = z^2$$（选它因为导数好算：$$\phi'(z) = 2z$$），损失 $$L = (y - t)^2$$（$$t$$ 是目标）。代入 $$x = 2,\; t = 1$$。

**第 1 步：前向（记中间值！）。**
$$z_1 = w_1 x = 1.0 \;\Rightarrow\; h = \phi(z_1) = 1.0$$
$$z_2 = w_2 h = 0.3 \;\Rightarrow\; y = \phi(z_2) = 0.09$$
$$L = (y - t)^2 = (0.09 - 1)^2 \approx 0.828$$
纸面上记下四个数：$$z_1{=}1.0,\ h{=}1.0,\ z_2{=}0.3,\ y{=}0.09$$——**反向全部要用**，这就是"前向记中间值"的含义。

**第 2 步：反向第一段（损失→输出）。** 链式拆开：
$$\frac{\partial L}{\partial y} = 2(y-t) = -1.82, \qquad \frac{\partial y}{\partial z_2} = 2z_2 = 0.6$$
$$\delta_2 = \frac{\partial L}{\partial z_2} = -1.82 \times 0.6 = -1.092$$

**第 3 步：反向第二段（输出→隐层）。** 权重 $$w_2$$ 的责任 = "误差信号 × 这条线传来什么"：
$$\frac{\partial L}{\partial w_2} = \delta_2 \cdot h = -1.092 \times 1.0 = -1.092$$
误差信号传回隐层：$$\frac{\partial z_2}{\partial h} = w_2 = 0.3$$，$$\frac{\partial h}{\partial z_1} = 2z_1 = 2$$：
$$\delta_1 = \delta_2 \times w_2 \times 2z_1 = -1.092 \times 0.3 \times 2 = -0.655$$
$$\frac{\partial L}{\partial w_1} = \delta_1 \cdot x = -0.655 \times 2 = -1.31$$

**第 4 步：验证（数值梯度）。** 把 $$w_1$$ 加 $$\epsilon=0.001$$ 重算前向：$$L(w_1{+}\epsilon) - L(w_1{-}\epsilon) \approx -1.31 \times 2\epsilon$$（代入可验，误差 $$<10^{-6}$$）——解析梯度正确。**这步（梯度检验）是所有自实现 BP 的第一道测试**。

**第 5 步：读懂两个结构规律。**
- **$$\nabla_W = \delta\, h^\top$$**：权重的梯度 = 下游误差信号 × 本权重**传过的输入**——"责任×流量"。梯度没有流的输入位（$$h$$ 恒 0，如死 ReLU）梯度恒 0
- **$$\delta_l = (W^\top \delta_{l+1})\odot\phi'$$**：误差反传=**转置乘**（信号沿原路退回）+ 逐元素乘激活斜率（斜率小=这条路窄）。sigmoid 饱和区斜率 $$\le 0.25$$ → 每层至少砍 3/4——**梯度消失的第一现场**（[ReLU](/ai-fa/explore/40-Concepts/ReLU) 登场的理由）

## 4. 为什么高效：把成本从 O(N·前向) 压到 O(1·前向)

| 方法 | 原理 | 成本 |
|---|---|---|
| 有限差分 | 每个参数扰动 $$\pm\epsilon$$ 各跑一次前向 | $$O(N)$$ 次前向（N=参数量，亿万级不可行） |
| 符号微分 | 整个表达式化简后求导 | 表达式膨胀，不可用 |
| **反向传播（反向自动微分）** | 从损失出发一次走完，**沿途每个中间梯度被所有下游路径共享复用** | **一次前向+一次反向 ≈ 2-3× 前向** |

动态规划直觉：$$h_1$$ 影响 $$h_2$$ 和 $$h_3$$ 两条路、再汇聚到 $$L$$——朴素法沿两条路各算一遍 $$h_1$$ 的贡献；BP 先把两条路的"汇率"（$$\delta$$）算好，$$h_1$$ 的梯度=一次乘法。**中间结果复用是全部魔法**——代价是前向必须记住中间值（显存大头，训练比推理费显存的原因）。

## 5. 两大天敌与对策

- **梯度消失**：连乘因子绝对值 <1（sigmoid 饱和区 ≤0.25、tanh 两端）→ 二十层后信号所剩无几。对策三条线：激活换 [ReLU](/ai-fa/explore/40-Concepts/ReLU)（正区恒 1）、结构加 [残差连接](/ai-fa/explore/30-Formulas/残差连接)（恒等直通绕过连乘）、分布用 [批归一化](/ai-fa/explore/30-Formulas/批归一化)/[层归一化](/ai-fa/explore/30-Formulas/层归一化)（把信号留在非饱和区）
- **梯度爆炸**：因子 >1 连乘发散（RNN 最常见）。标准药=**梯度裁剪**（全局范数超过阈值就整体缩放），见 [RNN](/ai-fa/explore/20-Algorithms/RNN) §8
- 序列网络版本=BPTT；截断 BPTT（TBPTT）只反传 k 步，牺牲长程换稳定（世界模型系训练常用）

## 8. 常见误区

- **误区**：BP=梯度下降——BP **算**梯度（簿记术），梯度下降**用**梯度（更新规则）；两者常连用但概念独立
- **误区**：反向传播是"神经网络专属"——它是微分的通用算法；PyTorch 对任意可导函数（物理仿真、渲染器）都能 backward
- **误区**：训练费显存因为模型大——主要是**前向中间值要留着给反向用**（激活显存）；混合精度/梯度检查点都是在管理这笔账
- **误区**：梯度消失时 loss 不降——loss 可能正常降（近层学得好），死的是**远层**的学习信号；症状是"深了不如浅了"

## 9. 自测

1. 为什么前向必须缓存中间值？（$$\nabla_W=\delta h^\top$$ 要用 $$h$$、$$\delta_l$$ 要用 $$z_l$$——丢中间值就得重算，成本翻倍）
2. 1-1-1 例子里若 $$h$$ 恒为 0，$$w_2$$ 的梯度是多少？（0——没有流量，责任为零；死 ReLU 的机制）
3. 转置 $$W^\top$$ 在反传里做什么？（把误差信号沿原路退回上一层各单元）
4. 梯度检验为什么只在测试期用？（每个参数两次前向，训练时成本是天文数字）

**一句话总结**：前向算"错了多少"，反向算"该怪谁"——中间值的复用把责任分摊的成本压到常数倍前向，深度学习整个产业就跑在这一点簿记术上。
