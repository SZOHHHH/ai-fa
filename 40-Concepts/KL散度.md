# KL 散度 KL Divergence

## 1. 定义（直觉 → 形式）

**直觉**：用分布 $Q$ 冒充分布 $P$ 时"平均多付的信息代价"。KL 越大，两个分布差异越大。**不对称**：用错误模型近似真实分布的代价，不等于反过来。

**形式**：
$$D_{\mathrm{KL}}(P \,\|\, Q) = \mathbb{E}_{x \sim P}\!\left[ \log \frac{P(x)}{Q(x)} \right] = \int p(x) \log \frac{p(x)}{q(x)}\, dx \ \ge 0$$
等号成立当且仅当 $P = Q$。

**本库标准记号**：$D_{\mathrm{KL}}(P \| Q)$，读作"P 相对 Q 的 KL"。方向约定：被近似的真分布在竖线**左**边。

## 2. 数学形式

- **不对称**：$D_{\mathrm{KL}}(P\|Q) \neq D_{\mathrm{KL}}(Q\|P)$
  - 前向 KL $D_{\mathrm{KL}}(P\|Q)$：质量覆盖（Q 被迫覆盖 P 的所有模式）→ "均值搜索"
  - 反向 KL $D_{\mathrm{KL}}(Q\|P)$：模式坍缩（Q 集中在 P 的单一众数）→ GAN 早期坍缩、VAE 的选择
- **与交叉熵**：$D_{\mathrm{KL}}(P\|Q) = H(P, Q) - H(P)$，当 $H(P)$ 固定时最小化 KL = 最小化交叉熵（[[30-Formulas/交叉熵]]）= 分类损失
- **与 ELBO**：见 [[30-Formulas/ELBO目标]]—— $\log p(x) = \text{ELBO} + D_{\mathrm{KL}}(q \| p_\theta)$，所以最大化 ELBO = 最小化近似后验与真后验的差距
- **两个高斯的 KL 有闭式解**（扩散论文反复使用）

## 教程：手算两个伯努利的 KL（并亲眼看不对称）

**第 1 步：设定。** 真 $P=(0.9, 0.1)$（事件 A 九一开），近似 $Q=(0.5, 0.5)$（五五开）：
$$D_{\mathrm{KL}}(P\|Q) = \sum_x P(x)\log\frac{P(x)}{Q(x)} = 0.9\log\frac{0.9}{0.5} + 0.1\log\frac{0.1}{0.5}$$

**第 2 步：逐项代入。** $0.9\log 1.8 = 0.9\times0.588 = 0.529$；$0.1\log 0.2 = 0.1\times(-1.609) = -0.161$；合计 $\approx 0.368$ **nat**（换 bit 除以 $\log 2$：$\approx 0.53$ bit——"平均每次抽样多付 0.53 bit 的信息"）。

**第 3 步：反方向算——不对称现形。** $D_{\mathrm{KL}}(Q\|P) = 0.5\log\frac{0.5}{0.9} + 0.5\log\frac{0.5}{0.1} = 0.5\times(-0.588) + 0.5\times1.609 \approx 0.511$——**同两个分布，方向一换数值就变**（0.368 vs 0.511）。语义：前者"$Q$ 冒充 $P$ 的代价"（按 $P$ 的世界抽样），后者按 $Q$ 的世界抽样。

**第 4 步：两高斯闭式（KL 家族最重要的公式）。** 一维：
$$D_{\mathrm{KL}}\big(\mathcal{N}(\mu_1,\sigma_1^2)\,\|\,\mathcal{N}(\mu_2,\sigma_2^2)\big) = \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac{1}{2}$$
代入 $\mathcal{N}(1.5, 2)\|\mathcal{N}(1, 1)$：$\log\frac{1}{\sqrt2} + \frac{2+0.25}{2} - 0.5 = -0.347+1.125-0.5 = 0.278$（与 [[40-Concepts/ELBO]] §2 第 6 步的 gap 手算同一道题——**ELBO 的 gap 就是这个公式**）。VAE 的 KL 正则项=它的对角特例（[[20-Algorithms/变分自编码器]] §3 第 4 步）。

**第 5 步：方向选错的后果（模式坍缩/覆盖）。** 最小化前向 KL（Q 覆盖 P 的所有支撑，P 为零处 Q 必须为零否则 ∞）→ Q 被"摊薄"；反向 KL（Q 为零处 P 无所谓）→ Q 可以只蹲一个峰。**VAE 用反向（生成集中于众数附近）、RLHF 的 KL 惩罚用反向（策略别跑太远）——方向不是口味是数学后果**。

## 4. 常见误区

- **误区**：KL 是"距离"——不是！不对称、也不满足三角不等式
- **误区**：KL ≥ 0 恒成立，但"很小"不代表形状像（可以在不同区域各有偏差）
- **误区**：$P$ 支撑集外 $Q$ 为零时 KL = ∞——这是前向 KL 覆盖性质的形式根源

## 5. 自测

1. $P=Q$ 时 KL=？（0——且仅此为零）
2. $P=(0.9,0.1)$、$Q=(0.9,0.1)$ 的 KL 与 $Q=(0.99, 0.01)$ 的 KL 哪个大？（后者——Q 在 P 的低概率区放更少质量，第二项 $0.1\log\frac{0.1}{0.01}\approx0.23$ 变大）
3. 为什么前向 KL 会"摊薄"、反向 KL 会"坍缩"？（各自 ∞ 的触发区不同：前向 KL 在 P 有质 Q 无质处爆，反向反之）
4. 交叉熵损失与 KL 的关系？（$\mathrm{KL}(P\|Q)=H(P,Q)-H(P)$；标签 P 固定时二者梯度等价）
