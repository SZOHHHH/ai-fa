# 扩散条件去噪

## 1. 标准形式

$$\mathcal{L}_{\text{cond}} = \mathbb{E}_{t, x_0, \epsilon, c}\!\left[ \left\| \epsilon - \epsilon_\theta(x_t, t, c) \right\|_2^2 \right], \qquad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$$

与 [[30-Formulas/DDPM训练目标]] 唯一的差别：网络多收一路条件 $c$（动作/文本/上一帧）——**去噪的方向由条件导航**。

**条件进入网络的两种主流通道**：
- **拼接（concat）**：$c$ 变成额外通道与 $x_t$ 堆叠——$x_t \in \mathbb{R}^{H\times W\times 3}$ 变 $\mathbb{R}^{H\times W\times(3+d_c)}$（低维强结构条件走此路）
- **交叉注意力（cross-attention）**：$c$ 编码成键值对、在网络中层被"查询"——文生图（SD 系）标准做法，条件长度不受限

## 2. 表示对照表

| 表示名 | 条件 c 是什么 | 通道 | 出处 | 说明 |
|---|---|---|---|---|
| 文生图 | 文本嵌入 | cross-attn | SD 系 | 词级细粒度控制 |
| DIAMOND | 游戏动作 $a_t$（帧级） | concat | [[10-Papers/09-世界模型与JEPA/Diffusion for World Modeling- Visual Details Matter in Atari（DIAMOND）]] | 扩散世界模型下一帧预测 |
| Diffusion Forcing | 全历史帧 + 逐帧噪声级 | 序列化 | [[10-Papers/09-世界模型与JEPA/Diffusion Forcing- Next-token Prediction Meets Full-Sequence Diffusion（Diffusion Forcing）]] | 每 token 独立噪声级（[[30-Formulas/逐token独立噪声]]） |
| 视频扩散 | 首帧/文本 | 混合 | 各家 | 首帧锚定 + 文本导航 |

## 教程：动作怎么改变去噪方向（一维手算）

**第 1 步：无条件的预测。** 网络对当前 $x_t$ 输出 $\epsilon_\theta(x_t, t, \varnothing) = 0.5$——"平均来看噪声大概长这样"。

**第 2 步：喂进动作。** 拼接通道给 $c = a_t$（如"按右"）：网络输出 $\epsilon_\theta(x_t, t, a_t) = 0.3$——**知道要往右，噪声的"最优猜测"变了 0.2**。这 0.2 就是动作对未来的信息（条件 score 与无条件 score 之差——[[30-Formulas/无分类器引导（CFG）]] 放大的正是它）。

**第 3 步：给世界模型加引导。** $\hat\epsilon = \epsilon_\varnothing + w(\epsilon_{a_t} - \epsilon_\varnothing)$，取 $w = 2$：$\hat\epsilon = 0.5 + 2\times(0.3-0.5) = 0.1$——**沿"动作信息"方向放大**：预测帧更贴合动作后果，代价与文生图同款（多样性下降）。

**第 4 步：DIAMOND 的完整用法。** 交互式生成循环：$x_{t+1} \sim p_\theta(\cdot \mid x_t, a_t)$（条件去噪 20~35 步）→ agent 看 $x_{t+1}$ 选 $a_{t+1}$ → 再生成——**去噪网络就是环境本身**，策略训练（RL）可在纯生成的环境里闭环进行。

**第 5 步：与自回归预测下一 token 的本质差别。** 自回归/MSE 预测"最可能的下一帧"（多模态未来被平均 → 模糊）；条件扩散预测"下一帧的分布"（先采样 ε 再反解）——**敌人可能左可能右的多模态未来不被平均掉**（与 [[20-Algorithms/MDN-RNN]] 同一动机，两条技术路线）。

## 3. 直觉解释

- **条件的角色 = 导航**：无条件去噪学会"什么是合理画面"；条件告诉它"往哪个合理区域去"
- concat 适合低维强结构条件（动作、上一帧）；cross-attn 适合高维语言条件（文本 token 序列）
- 世界模型语境：$\epsilon_\theta$ 编码了 $p(x_{t+1} \mid x_t, a_t)$ 的全部动态——像素级细节保留（DIAMOND 论证细节决定 agent 表现，E1"像素保真"命题的生成派镜像）

## 6. 自测

1. 与无条件 DDPM 训练目标差在哪？（网络多一路输入 $c$——损失形式一字不差）
2. concat 与 cross-attn 各适合什么条件？（低维强结构（动作/帧）vs 高维序列（文本））
3. 教程中 $w=2$ 的引导输出？（$0.5+2\times(0.3-0.5) = 0.1$——动作方向被放大）
4. 世界模型语境下 $\epsilon_\theta$ 学到了什么？（$p(x_{t+1}\mid x_t, a_t)$ 的条件动态——可作可交互环境）
