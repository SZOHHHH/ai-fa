# 研究矩阵规范（第五类实体）

> [!purpose] 目的
> 把"科研 = 维度组合"的洞察工具化：矩阵的格 = 论文占位；空白格 = 潜在研究方向。服务于**寻找有 ICML 级潜力的研究 idea**。

## 1. 实体定义

`60-Matrices/` 目录，frontmatter：
```yaml
---
type: matrix
title: 生成模型加速矩阵
axes: { 行: [骨干模型], 列: [加速机制], 切片: [训练范式] }
status: active
updated: 2026-08-17
---
```

正文四节：
1. **轴定义**：每个维度轴的取值与判据（什么算"蒸馏"、什么算"一致性"）
2. **矩阵表**：格内填论文链接（wikilink），空白格显式留空
3. **格评估**（每格一行）：四维打分 + 死格判据
4. **矩阵洞察**：规律总结（哪类组合繁荣/哪类荒芜、为什么）

## 2. 格评估框架（四维打分，1-5 分）

> [!warning] 占位层收录政策（B12 立法，2026-08-18）
> **背景教训**：OPD 方向曾因只看库内论文而误判为空格（实际 5 篇占位者都不在库内，矩阵显示空格实已被占）。根因：收录标准只认 S/A 级范式论文，**从不收录 B/C 级占位小论文**——但它们正是格评估的关键情报。
> **新规**：
> 1. **两层收录制**：奠基层（S/A/B 主干论文，原有标准不变）+ **占位层**（热门矩阵格的占位者，即使方法论上只是增量）
> 2. 占位层卡可简化（七节压缩为五节：贡献/方法/公式/关系/影响），但必须带 `layer: 占位` frontmatter 字段
> 3. **格评估前置条件**：评估某机会格前，必须检索近 12 个月该格及近邻格的 arXiv 占位者（近邻词：组合/混合/gated/unify/aware/adaptive）；已入库的占位者在矩阵表中显式标 🚩
> 4. 机会格结论必须引用占位层证据，禁止仅凭矩阵空白下结论

| 维度 | 问的问题 | 高分特征 |
|---|---|---|
| **痛点** | 这个组合有真实性能/成本问题吗 | 有明确 benchmark 落后或应用瓶颈 |
| **可行性** | 数学上走得通吗 | 轨迹/目标函数可定义，有先例可借 |
| **novelty** | 相邻格的现有方法直接搬过来够不够 | 格间存在本质差异，需新定理/新机制 |
| **顶会潜力** | 12 个月内能凑齐"一个格+一个定理+两个实验域"吗 | 有干净的数学切入 + 可跑的实验管线 |

**死格判据**（为什么空着，三选一）：
- 🚫 **结构死格**：组合在数学上无意义（例：SSM×KV量化——SSM 无 KV cache，量化对象不存在）
- 😴 **无痛点死格**：组合可行但没人在乎（例：3×3 MNIST×MoE——问题太小）
- 🌱 **机会格**：走得通+有痛点+无人占——**这是要找的目标**，但必须再过"顶会潜力"一关：确认 make sense（数学故事完整）且 novelty 够（不是把邻格方法换个名字）

> ⚠️ 用户洞察写进规范：**空白 ≠ 机会**。机会格的标准 = MFD 论文的模式：一个格 + 一个定理（均值速度充分性）+ 两个实验域（4D 占据预测 + 文生图）。

## 5. 更新流程

新增论文 → 若落在已建矩阵的某格 → 更新矩阵表 + 重估该格；若开新格 → 在矩阵页记录"新占格"日志。矩阵与 Canvas 联动：每矩阵可生成一张 Canvas 视图（格=节点、行列=分区）。
