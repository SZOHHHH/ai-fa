# 策略梯度定理

## 1. 定义（直觉 → 形式）

**直觉**：想要"总奖励高的动作出现得更多"，直接对 $$J(\pi_\theta)$$ 求梯度。问题：轨迹里充满采样操作，梯度怎么传？答案：log 导数技巧把采样拆掉，梯度 = "**奖励 × 提高该动作对数概率的方向**"。

**形式**：
$$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\!\left[ \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, G_t \right]$$
- $$G_t = \sum_{k \ge t} \gamma^{k-t} r_k$$：从 $$t$$ 起的回报（return）
- $$\nabla_\theta \log \pi_\theta$$：策略的 log 梯度（[RL中的log导数技巧](/ai-fa/explore/40-Concepts/RL中的log导数技巧)）
- **读法**：奖励高 → 拉高这些动作的概率；奖励低 → 压低

## 2. 数学形式

- **方差问题与基线**：$$G_t$$ 换成 $$G_t - b(s_t)$$ 仍无偏（$$b$$ 任意），方差骤降——$$b$$ 通常是 [贝尔曼方程](/ai-fa/explore/40-Concepts/贝尔曼方程) 的值函数 $$V$$
- **优势形式**：$$\nabla J = \mathbb{E}[\nabla \log\pi \cdot A_t]$$，$$A_t = G_t - V(s_t)$$（比平均好多少）
- **批评公式三兄弟**：REINFORCE（原始）→ 带基线（方差减）→ Actor-Critic（$$V$$ 网络在线学）
- **本库记号**：$$\pi_\theta$$ 策略、$$V_\pi(s)$$ 值、$$A_\pi(s,a)$$ 优势（见 [记号规范（统一符号表）](/ai-fa/explore/00-Meta/记号规范) §3）

## 教程：两个样本同向（定理的现场验证）

**第 1 步：初始策略与各量。** softmax logits $$z=(0,0)$$ → $$\pi = (0.5, 0.5)$$（宇宙见 [马尔可夫决策过程](/ai-fa/explore/40-Concepts/马尔可夫决策过程)）。此策略下 $$V^\pi = 0.5/(0.1+0.9\times0.5) = 0.909$$；$$Q(a_{慢}) = 0.9\times0.909 = 0.818$$、$$Q(a_{赢}) = 1$$。

**第 2 步：直接微分（有模型时的答案）。** $$J(p) = p/(0.1+0.9p)$$，$$\frac{dJ}{dp}\big|_{0.5} = \frac{0.1}{0.55^2} = 0.331$$；softmax 链 $$\frac{dp}{dz_{赢}} = p(1-p) = 0.25$$ → $$\nabla_{z_{赢}}J = 0.331\times0.25 = 0.0826$$——待会儿用定理复现这个数。

**第 3 步：定理路线的两个样本。** $$\nabla J = \mathbb{E}[(G-b)\nabla\log\pi]$$，基线 $$b = V^\pi = 0.909$$：
- 抽到 $$a_{赢}$$（$$G = 1$$）：贡献 $$(1-0.909)\times\underbrace{(1-\pi_{赢})}_{=0.5} = +0.0455$$
- 抽到 $$a_{慢}$$（$$G = 0.818$$）：贡献 $$(0.818-0.909)\times\underbrace{(-\pi_{赢})}_{=-0.5} = (-0.091)\times(-0.5) = +0.0455$$
**两个样本的贡献一模一样**——赢样本直接拉高 $$\pi_{赢}$$，慢样本通过压低 $$\pi_{慢}$$ 间接拉高 $$\pi_{赢}$$（softmax 的此消彼长）：无论抽到谁，更新方向都指向"多选赢"。

**第 4 步：对上答案。** 沿轨迹每次访问 $$s_1$$ 都有一份这样的贡献，折扣访问和 $$= \sum_t (0.9\times0.5)^t = 1/0.55 = 1.818$$；总梯度 $$= 0.0455\times1.818 = 0.0827 \approx 0.0826$$ ✓ **定理与直接微分殊途同归**——而这全程只用了采样，没碰环境模型。

**第 5 步：走一步。** lr $$= 0.5$$：$$z_{赢} \mathrel{+}= 0.041$$ → $$\pi(a_{赢}) = \sigma(0.083) \approx 0.521$$——策略正确地向赢移动。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [REINFORCE目标](/ai-fa/explore/30-Formulas/REINFORCE目标) | 最简策略梯度 |
| [PPO裁剪目标](/ai-fa/explore/30-Formulas/PPO裁剪目标) | 重要性采样修正后的策略梯度（现代 RLHF 底座） |
| [GRPO目标](/ai-fa/explore/30-Formulas/GRPO目标) | 组内相对优势的策略梯度 |
| RLHF | 奖励模型替代人类打分，策略梯度照用 |

**B2 线的总纲**：PPO/GRPO 都是这个定理的"稳定化变体"，DPO 则是把它的最优解闭式反推出来的产物——一条线从这出发。

## 4. 常见误区

- **误区**：梯度对奖励求导——**不对**！环境（奖励）是黑盒，梯度只穿过 $$\log \pi$$
- **误区**：$$G_t$$ 是单个轨迹的真实回报——正是它方差大的根源，才需要基线/GAE/批评家
- **误区**："策略梯度无偏所以好"——无偏但方差大，稳定化是整条技术演进线的主旋律

## 5. 自测

1. $$\pi=(0.5,0.5)$$、$$b = 0.909$$：抽到 $$a_{赢}$$（$$G{=}1$$）的样本贡献？（$$(1-0.909)\times0.5 = +0.0455$$）
2. 抽到 $$a_{慢}$$（$$G{=}0.818$$）的贡献为何也是 $$+0.0455$$？（负优势 × 负梯度分量——压慢即抬赢（softmax 此消彼长））
3. 梯度对奖励求导吗？（**不**——环境是黑盒，梯度只穿过 $$\log\pi$$）
4. "无偏但方差大"催生了什么？（baseline → critic → GAE → 信赖域 → 裁剪——整条稳定化演进线）
