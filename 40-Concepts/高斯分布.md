# 高斯分布 Gaussian Distribution

## 1. 定义（直觉 → 形式）

**直觉**：钟形曲线。自然界大量现象（测量误差、噪声）近似服从它；中心极限定理保证了多个独立小扰动叠加趋近高斯。它是"最无信息"的连续分布——只知道均值和方差时的最佳猜测。

**形式**（一维）：
$$p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left( -\frac{(x-\mu)^2}{2\sigma^2} \right)$$
多维标准形式（本库标准记号）：$x \sim \mathcal{N}(\mu, \Sigma)$，各向同性时 $\Sigma = \sigma^2 I$。

## 2. 数学形式

**本库最重要的四条性质**：

1. **线性变换仍高斯**：$x \sim \mathcal{N}(\mu, \Sigma) \Rightarrow Ax + b \sim \mathcal{N}(A\mu + b,\ A\Sigma A^\top)$
2. **两高斯相加仍高斯**：$x + y \sim \mathcal{N}(\mu_x + \mu_y,\ \Sigma_x + \Sigma_y)$（独立时）
3. **条件分布是高斯**：高斯联合 → 给定一部分，另一部分的条件分布仍是高斯（DDPM 后验可算出闭式解的根源）
4. **重参数化友好**：$x = \mu + \sigma \odot \epsilon,\ \epsilon \sim \mathcal{N}(0, I)$——见 [[40-Concepts/重参数化]]

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [[30-Formulas/DDPM前向过程]] | 每一步加高斯噪声，任意时刻 $x_t$ 服从闭式高斯（性质 1+2） |
| [[30-Formulas/DDPM后验分布]] | 反向一步也是高斯（性质 3），所以训练目标能解出来 |
| 所有扩散/流模型 | 噪声源 $z \sim \mathcal{N}(0, I)$ 是生成的起点 |
| VAE | 先验与后验都设为高斯 |
| 初始化 | 网络权重高斯初始化 |

## 4. 常见误区

- **误区**：$\mathcal{N}(0, I)$ 的 $I$ 是单位矩阵（各向同性），不是数字 1
- **误区**：高斯的"标准差 $\sigma$"与 [[40-Concepts/Score函数]]（score）无关，纯记号撞车
- **误区**：多维高斯密度里的 $\exp$ 前系数含 $(2\pi)^{-d/2}|\Sigma|^{-1/2}$，推导时漏掉会错
