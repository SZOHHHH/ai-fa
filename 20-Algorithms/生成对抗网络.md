# 生成对抗网络 GAN

## 1. 定义

**非数学语言**：造假者（生成器）与鉴定师（判别器）互相博弈：假货越造越真，鉴定越来越难，直到鉴定师只能瞎猜——此时假货已与真品分布无异。

**数学语言**：$\min_G \max_D V(D, G)$——判别器最大化区分真假的能力，生成器最小化被识别率。均衡点 $p_G = p_{\text{data}}$，等价于最小化 JS 散度。

## 教程：一轮对抗的手算（博弈现场）

**第 1 步：设定。** 判别器 D 对真样本输出 $D(x) = 0.9$（很确信是真）、对生成样本 $D(G(z)) = 0.7$（也偏真——还没学会抓假）。

**第 2 步：判别器一轮。** D 的目标 $\max \log D(x) + \log(1-D(G(z)))$：真样本项 $\log 0.9 = -0.105$、假样本项 $\log(1-0.7) = \log 0.3 = -1.204$——假样本项贡献了 92% 的损失：**D 的学习信号集中在"抓假"上**。

**第 3 步：生成器一轮（非饱和 trick）。** 原版目标 $\min\log(1-D(G(z)))$ 的梯度 $\propto \frac{-1}{1-D}$：训练早期 G 很烂、D 轻松识破（$D(G(z))\approx0$）——此时 $\frac{1}{1-D}\approx1$，**梯度几乎为零：G 最需要学习的时候偏偏没信号**（饱和区）。**非饱和版**换 $\max\log D(G(z))$：梯度 $\propto \frac{1}{D}$——$D(G(z)) = 0.05$ 时梯度 ×20、$D = 0.7$ 时 ×1.43：**越骗不过，信号越强**。一个符号之差，GAN 可训性的分水岭。

**第 4 步：博弈的平衡点。** 理论终点：$D^*(x) = \frac{p_{data}(x)}{p_{data}(x)+p_g(x)}$（真假各半处）；$p_g \to p_{data}$ 时 D 处处 0.5、G 梯度消失——**纳什均衡**。实践中两网互相追逐，训练不稳定（对照扩散：纯回归无博弈——稳定性之源，[[30-Formulas/GAN目标]] 与 [[30-Formulas/DDPM训练目标]] 的 loss 标签差即此）。

**第 5 步：读法。** GAN 的两大遗产：对抗训练思想（判别器=可学习的损失函数）与模式坍缩教训（生成器只产几张"安全牌"骗 D——多样性死的病根），后者直接推动了扩散的回归式替代。

## 自测

1. 判别器的学习信号集中在哪？（假样本项（本例 92% 损失）——抓假）
2. 非饱和 trick 修了什么？（原版在 $D(G(z))\approx0$（最需要学）时梯度饱和消失；$-\log D$ 此时信号最强）
3. 博弈终点是什么？（$D$ 处处 0.5、$p_g \to p_{data}$——纳什均衡）
4. GAN 两大遗产？（对抗训练思想（可学习损失）+ 模式坍缩教训（多样性死的病根→催生扩散回归式））
