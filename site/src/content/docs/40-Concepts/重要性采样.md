# 重要性采样

## 1. 定义（直觉 → 形式）

**直觉**：想算 $$p$$ 下的期望，但样本只能从 $$q$$ 抽。**给样本重新配权重**：$$p$$ 里常见而 $$q$$ 里罕见的样本"加权"，反之"减权"——期望照样算对。

**形式**：
$$\mathbb{E}_{x \sim p}[f(x)] = \mathbb{E}_{x \sim q}\!\left[ \frac{p(x)}{q(x)}\, f(x) \right]$$
- $$p(x)/q(x)$$：**重要性比率**（RL 里就写 ratio $$\rho_t(\theta)$$）
- 无偏，但 $$p, q$$ 差异大时方差爆炸（罕见样本权重巨大）

## 2. 数学形式

- **RL 用法（off-policy）**：数据由旧策略 $$\pi_{\text{old}}$$ 收集，更新新 $$\theta$$：
$$\nabla J(\theta) = \mathbb{E}_{a \sim \pi_{\text{old}}}\!\left[ \frac{\pi_\theta(a\mid s)}{\pi_{\text{old}}(a\mid s)}\, \nabla_\theta \log \pi_\theta(a \mid s)\, A \right] = \mathbb{E}\!\left[ \nabla_\theta \rho_t(\theta)\, A \right]$$
- **同策略 vs 离策略**：PPO 系是"近邻离策略"——比率接近 1 时安全，远离就裁剪
- **比率失配灾难**：$$q$$ 的支撑不含 $$p$$ 的区域 → 比率无定义/爆炸；策略更新步子太大 → 同样问题
- **与 KL 的联动**：约束 $$\pi_\theta$$ 别离 $$\pi_{\text{old}}$$ 太远 = 约束比率别太大 = 控制方差

## 教程：修正、方差与支撑灾难（三连手算）

**第 1 步：设定。** 目标分布 $$p = (0.8,\ 0.2)$$（想算它的期望），采样分布 $$q = (0.5,\ 0.5)$$（只能从它抽）；被估函数 $$f = (1,\ 0)$$（指示函数"抽到动作 1"）。

**第 2 步：直接算错多少。** $$\mathbb{E}_p[f] = 0.8$$；不修正直接用 $$q$$ 的样本：$$\mathbb{E}_q[f] = 0.5$$——**差 0.3**。

**第 3 步：加权修正。** $$\mathbb{E}_q\big[\tfrac{p}{q}f\big] = 0.5\times\tfrac{0.8}{0.5}\times1 + 0.5\times\tfrac{0.2}{0.5}\times0 = 0.8$$ ✓ **无偏复原**——分布没变，是权重把"q 里太少见的 p 常客"补回身价。

**第 4 步：方差的代价。** 原方差 $$\mathrm{Var}_p[f] = 0.8\times0.2 = 0.16$$；修正后 $$\mathrm{Var}_q[\rho f] = \mathbb{E}_q[\rho^2 f^2]-0.64 = 0.5\times1.6^2\times1-0.64 = 0.64$$——**4 倍方差**（单样本估计摆幅 sd 0.8，与被估量本身同量级！）。比率离 1 越远越贵，平方级恶化。

**第 5 步：支撑灾难。** 若 $$q(a_1) = 0$$（旧策略从不选动作 1）：$$\rho(a_1)$$ 无定义，且无论采多少样本都见不到 $$a_1$$——**永远学不到 $$p$$ 认为重要的事**。RL 对应：旧策略没试过的动作新策略学不到（off-policy 的探索债）；防御 = 保持两分布接近（TRPO 的 KL 约束 / PPO 的裁剪，都在防比率走远）。

## 4. 常见误区

- **误区**：重要性采样"修正了分布"——分布没变，是**加权**让期望算对
- **误区**：裁剪的比率梯度为零 = 没学习——只对越界样本停梯度，区间内照常学（这正是 PPO 的设计）
- **误区**：比率大好——比率是修正系数不是目标，接近 1 才健康

## 5. 自测

1. $$p = (0.8,0.2)$$、$$q = (0.5,0.5)$$、$$f = (1,0)$$：$$\mathbb{E}_q[\rho f]$$？（$$0.5\times1.6\times1 = 0.8 = \mathbb{E}_p[f]$$ ✓）
2. 方差涨几倍？（$$0.16 \to 0.64$$，4 倍——比率的平方进了二阶矩）
3. 支撑灾难在 RL 里对应什么？（旧策略零概率的动作永远学不到——off-policy 的探索债）
4. 为什么"比率接近 1 才健康"？（无偏性不依赖比率大小，但方差随 $$|\rho-1|$$ 平方级恶化）
