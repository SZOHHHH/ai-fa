# 序列架构演进矩阵

> [!purpose] 目标
> 序列建模架构（Transformer 及其挑战者）的全景占位图。核心问题：**下一步的架构制高点在哪**——评估见 [[00-Meta/研究矩阵规范]] §2。

## 1. 轴定义

| 轴 | 取值 | 判据 |
|---|---|---|
| **机制**（怎么算 token 间依赖） | 全注意力、线性注意力、循环/状态、混合（block 交替）、卷积 | 计算图中信息流动的方式 |
| **效率技术**（怎么省） | IO 感知（显存复用）、KV 压缩（MQA/GQA/MLA）、位置编码、归一化/激活、缩放律 | 作用对象不是"依赖怎么算"而是"算得多贵/多稳" |
| **状态** | 无状态（并行训练/推理）、有状态（推理 O(1)） | 推理时是否携带跨步状态 |

## 3. 格评估（四维：痛点/可行性/novelty/顶会潜力）

| 格 | 评估 | 结论 |
|---|---|---|
| 线性注意力×缩放律 | 4/4/4/4 | 🌱 仍开放（未见 Chinchilla 级系统占位），但 B15 发现周边急速升温：[[10-Papers/01-架构演进/Parallelizing Linear Transformers with the Delta Rule over Sequence Length（DeltaNet并行）]]（训练并行化，Qwen3-Next/Kimi Linear 的底座）+ [[10-Papers/01-架构演进/Gated DeltaNet-2- Decoupling Erase and Write in Linear Attention（GDN2）]]（2026-05，擦写解耦，报称超 KDA/Mamba-3）——**混合配方（少数全注意力+多数线性）已成生产标配**，缩放律格的"数据"正在被这些工作顺手产出，抢发风险中高 |
| 线性注意力×IO 感知 | 5/5/3/4 | 🚩 **已被占（B15）**：[[10-Papers/01-架构演进/Parallelizing Linear Transformers with the Delta Rule over Sequence Length（DeltaNet并行）]]（chunk-wise parallel scan，吞吐近 GLA）——FlashAttention 级内核+对偶理论仍有深水区但工程位已占 |
| 混合架构×KV 压缩 | 4/3/3/3 | Jamba 等生产模型已占，学术增量在"混合比例与 KV 置放的联合理论"——问题真实但常被当作调参 |
| SSM×KV 压缩 | — | 🚫 结构死格：SSM 推理无 KV cache，压缩对象不存在（反之 Transformer 也不会做"状态压缩"，各有各的省法） |
| 卷积×长依赖 | 2/5/2/2 | 😴 无痛点死格：卷积全局依赖弱是结构性缺陷，Hyena 类混合已试，纯卷积方向无顶会增量 |

## 4. 矩阵洞察

1. **"对偶化"是架构线的母题**：注意力↔SSM（Mamba-2 SSD）、KV 压缩↔潜空间（MLA）——同一个数学对象的两套坐标，**做"翻译"的论文（含转换定理）= B 级模式**
2. **效率技术沿"作用层级"内卷**：内核级（FlashAttention）→ 结构级（MQA/MLA）→ 表示级（RoPE 的外推）——每层饱和后向上一层迁移；当前位置：结构级接近饱和，表示级（位置表示理论）仍薄
3. **混合架构是"两个矩阵的乘积"**：它同时活在架构矩阵与推理成本矩阵——跨矩阵格子往往是新论文的出生地（与 [[60-Matrices/生成模型加速矩阵]] 的 SSM×加速机制同理）
