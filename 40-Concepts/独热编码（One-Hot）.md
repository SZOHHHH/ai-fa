# 独热编码（One-Hot）

## 1. 定义（直觉 → 形式）

**直觉**：把"第几类"翻译成"一排灯，只亮一盏"。类别 3（共 6 类）不是数字 `3`，而是向量 `(0,0,0,1,0,0)`——第三盏灯亮、其余全灭。**一个位置 = 一个类别**，互斥且穷尽。

**形式**：$K$ 类中的第 $y$ 类编码为 $e_y \in \{0,1\}^K$，其中 $(e_y)_i = \mathcal{I}[i = y]$（只有第 $y$ 位是 1）。

- 记号 $e_y$ 与 [[40-Concepts/概率分布]] 的**独热分布**（categorical 分布的退化情形）完全同构：作为"编码"用时强调向量表示，作为"分布"用时强调概率含义（概率 1 全押在第 y 类）。

## 2. 三个身份（为什么它无处不在）

| 身份 | 用法 | 库内出现处 |
|---|---|---|
| **标签表示** | 分类监督的硬标签 y | [[30-Formulas/交叉熵]]：one-hot CE = $-\log q_y$（NLL） |
| **动作空间** | 离散动作（按键）的向量表示 | [[40-Concepts/逆动力学（IDM）]]：Atari 18 维按键；BC/DPO 同款动作头 |
| **离散采样** | categorical 采样的结果形态 | 从 softmax 分布采样 → one-hot 向量 |

- **身份切换的本质**：one-hot 向量 = 概率分布的极端点。softmax 输出软分布、训练用软目标（soft-CE）；环境执行时 argmax/采样回 one-hot——**软硬切换发生在网络出口处**。

## 3. 关键性质

- **维数 = 类数 K**：天然随词表/动作数线性增长——大词表下 one-hot 矩阵乘 = **查表（embedding）**，这是 embedding 层存在的理由（稀疏 one-hot × 稠密矩阵 = 取出对应行）
- **任意两个 one-hot 的欧氏距离恒为 $\sqrt 2$**：所有类别"等距"——没有结构、没有相似度信息（"猫"和"狗"与"猫"和"汽车"一样远）。**这正是要学 embedding 的动机**：把等距的稀疏点搬进有几何结构的稠密空间
- **与 CE 的天然配合**：$p = e_y$ 时交叉熵塌缩成单顶点 $-\log q_y$——所以"分类训练"的通用形态就是 **one-hot 标签 + softmax 出口 + CE 损失** 三件套

## 4. 常见误区

- **误区**：one-hot 是"数值上合理的类别编号"——用整数 1/2/3 直接当回归目标会引入假距离结构（3 离 1 比 2 远），one-hot 正是为消灭这种假结构
- **误区**：one-hot 输出=确定性—— IDM/策略头输出的是**概率向量**（多盏灯按概率半亮），argmax 投影才变 one-hot；多模态后验（多种按键都行）恰恰住在软输出里
- **误区**：维数灾难是缺点——配合线性层等价于查表，计算并不爆炸，爆炸的是**语义贫乏**
