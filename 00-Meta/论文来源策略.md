# 论文来源策略（三级降级方案）

> [!purpose] 目的
> 全库论文获取的统一流程：优先 arXiv，降级官网/其他注册库，全部失败才文字标注。每个 PDF 落盘前必须过 EOF 完整性校验。

## 0. 通用校验（所有来源适用）

```bash
# 落盘后必须验证（尾部 1000 字节内找 %%EOF）
tail -c 1000 "文件.pdf" | tr -cd '[:print:]' | grep -c "%%EOF"
```
注：EOF 标记可能在最后 1000 字节内的任意位置（曾出现 tail -c 300 漏检的误判案例——窗口给足）。

## 1. 三级降级流程

### 第一级：arXiv（默认，~95% 论文覆盖）
- ID 必须先经 API 核实标题（**禁止凭记忆直接下载**——已发生 9 次错误 ID 事故）
- 标题核实 API：`http://export.arxiv.org/api/query?id_list=<ID>`
- 标题搜索 API（ID 未知时）：`?search_query=ti:"<完整标题>"`
- 下载：`https://arxiv.org/pdf/<ID>`（必须 `-L` 跟随 301）

### 第二级：官方 CDN / 官网直链
适用于**从未提交 arXiv** 的论文（公司报告、早期论文）。已验证可用：

| 论文 | 直链 | 状态 |
|---|---|---|
| GPT-1（2018） | `cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf` | ✅ 已下载 |
| Anthropic 论文 | `www.anthropic.com/research/*`（部分提供 PDF） | 待用 |
| DeepSeek 报告 | 官方 GitHub `deepseek-ai/*` releases | 备用 |
| Sora 技术报告 | openai.com/research/video-generation-models-as-world-simulators | B6 用 |

**注意**：DeepSeek-V3（2412.19437）、R1 等技术报告**其实都在 arXiv**——"技术报告不上 arXiv"是误解，先查再降级。

### 第三级：其他注册库
- **OpenReview**（`openreview.net`）：会议录用版；部分论文只有此处
- **Semantic Scholar API**（`api.semanticscholar.org/graph/v1/paper/search`）：元数据 + openAccessPdf 字段（注意限流 429）
- **Papers with Code**：代码+论文索引

### 兜底：文字标注（无任何公开 PDF 时）
论文卡照常建立，frontmatter 加字段：
```yaml
pdf: none
source_note: "仅存于官网付费墙/内部，引用 URL"
```

## 2. 特殊类型处理

| 类型 | 策略 |
|---|---|
| 纯网页报告（无 PDF） | 卡片照建，`source_note` 给 URL，正文注明"网页报告" |
| 博客/工程文章（如 Karpathy 博客） | 不入论文网络（type: paper），可作为概念页参考来源 |
| 同名多版本论文（v1/v2 差异大） | 默认最新版；若 v1 有独立价值（如 DDPM 的 NeurIPS 版）在卡片 aliases 注明 |
