# 重参数化技巧 Reparameterization

## 1. 定义（直觉 → 形式）

**直觉**：从 $z \sim \mathcal{N}(\mu_\phi, \sigma_\phi^2)$ 采样，梯度没法穿过"随机"这个操作传回 $\mu_\phi, \sigma_\phi$。**把随机性搬到旁边**：写成 $z = \mu_\phi + \sigma_\phi \odot \epsilon,\ \epsilon \sim \mathcal{N}(0, I)$——随机性来自外部的 $\epsilon$，$\mu, \sigma$ 变成普通可导函数的一部分。

**形式**：
$$z \sim q_\phi(z \mid x) \quad\Longrightarrow\quad z = g_\phi(\epsilon; x),\ \epsilon \sim p(\epsilon)$$
$$\mathbb{E}_{z \sim q_\phi}[f(z)] = \mathbb{E}_{\epsilon \sim p(\epsilon)}[f(g_\phi(\epsilon; x))]$$
右式的期望与 $\phi$ 无关，梯度可以穿过 $g_\phi$ 直达参数。

## 2. 数学形式

- **适用条件**：位置-尺度族（高斯 $z = \mu + \sigma\epsilon$）或可逆变换（对数正态等）
- **反向传播链**：$\nabla_\phi \mathbb{E}[f] = \mathbb{E}[\nabla_\phi f(g_\phi(\epsilon))] \approx \frac{1}{N}\sum \nabla_\phi f(g_\phi(\epsilon_i))$
- **与 score function 梯度对比**：REINFORCE/score-function 梯度（RL 用）方差大；重参数化梯度方差小——扩散模型训练能稳定收敛的原因之一
- DDPM 的 $x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1-\bar\alpha_t}\, \epsilon$ 正是重参数化形式

## 4. 常见误区

- **误区**：重参数化"改变了分布"——没有，$z$ 的分布分毫不差，只是生成方式的等价改写
- **误区**：所有分布都能重参数化——离散分布不行（VQ-VAE 的 straight-through 是绕行方案）
- **误区**：VAE 里的 $\epsilon$ 与扩散里的 $\epsilon$ 是同一个东西——记号撞车：都是标准高斯噪声，但前者指编码噪声，后者指扩散加噪目标
