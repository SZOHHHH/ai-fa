# 世界模型矩阵

> [!purpose] 目标
> 世界模型（智能体对环境的内部模拟器）设计空间。核心问题：**环境的知识从什么信号、压进什么表示**。评估见 [[00-Meta/研究矩阵规范]] §2。

## 1. 轴定义

| 轴 | 取值 | 判据 |
|---|---|---|
| **信号** | 像素重建（生成式）、特征预测（判别式/JEPA）、奖励驱动（RL 内部模型）、隐式（交互数据本身） | 世界知识从哪来 |
| **表示** | 显式像素空间、潜在状态空间（离散 token/连续 z）、混合（外挂生成头） | 模型输出住在哪 |
| **交互** | 纯离线视频、游戏控制（RL）、可操作（动作条件） | 环境是否可被干预 |

## 4. 矩阵洞察

1. **重建 vs 预测的取舍是本矩阵的"score vs FM"**：像素重建（信息全但浪费容量学无关细节）vs 特征预测（抽象但可能丢关键动态）——**与扩散（像素域）vs FM（速度场域）的选择同构**：表示域的选择先于目标函数的选择
2. **世界模型矩阵是所有矩阵的"汇"**：生成侧（[[60-Matrices/生成模型加速矩阵]]）、RL 侧（[[60-Matrices/RL稳定化矩阵]]）、多模态侧（[[60-Matrices/多模态对齐矩阵]]）的成熟技术都在此汇聚（视频生成器=世界模拟器）——**机会格多为"跨矩阵组合"**，单矩阵内空间已窄
3. 用户 3 个月周期的适配性：本矩阵机会格（JEPA×生成头）实验成本中等（开源权重+小规模生成头），**理论密度高**（两阶段信息瓶颈可写定理）——符合"一个格+一个定理+两个实验域"模板
