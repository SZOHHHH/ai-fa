# 贝叶斯公式

## 1. 定义（直觉 → 形式）

**直觉**：**看到新证据后更新信念**。先有先验判断，来了新信息，按比例修正成后验。医生看病：先知道疾病发病率（先验），再看检查结果（证据），修正出患病概率（后验）。

**形式**：
$$p(z \mid x) = \frac{p(x \mid z)\, p(z)}{p(x)}$$
- $$p(z)$$：先验（没看数据前的信念）
- $$p(x \mid z)$$：似然（假设 $$z$$ 成立时看到 $$x$$ 的概率）
- $$p(z \mid x)$$：后验（看完 $$x$$ 后的信念）
- $$p(x)$$：证据（全概率 $$= \int p(x \mid z) p(z) dz$$，归一化常数）

## 2. 数学形式

- **后验 ∝ 似然 × 先验**（比例形式最常用，忽略 $$p(x)$$）
- **全概率公式**：$$p(x) = \sum_z p(x \mid z) p(z)$$——分母常常算不了（积分高维爆炸），这是 [ELBO](/ai-fa/explore/40-Concepts/ELBO) / MCMC / VAE 存在的根本原因
- **链式应用**（扩散反向推导用）：
$$q(x_{t-1} \mid x_t, x_0) = \frac{q(x_t \mid x_{t-1}, x_0)\, q(x_{t-1}\mid x_0)}{q(x_t \mid x_0)}$$
——DDPM 后验闭式解的出发点（利用马尔可夫性质 $$q(x_t\mid x_{t-1},x_0) = q(x_t \mid x_{t-1})$$）

## 教程：先验×证据→后验的拔河（手算全程）

**接 [条件概率](/ai-fa/explore/40-Concepts/条件概率) 的疾病题**（发病率 1%、灵敏度 90%、假阳 5%，已算出 $$P(D\mid+)\approx15.4\%$$）——贝叶斯公式给出同一答案的**代数形态**：

**第 1 步：写比例形式。** $$\text{后验} \propto \text{似然}\times\text{先验}$$：$$P(D\mid +) \propto 0.90\times0.01 = 0.009$$；$$P(\neg D\mid +) \propto 0.05\times0.99 = 0.0495$$。

**第 2 步：归一化（分母=全概率）。** $$\displaystyle P(D\mid+) = \frac{0.009}{0.009+0.0495} = \frac{0.009}{0.0585}\approx 15.4\%$$ ✓——与人数法一致；**贝叶斯公式=条件概率的换向器+全概率的归一化器**。

**第 3 步：读出拔河结构。** 后验 odds = 先验 odds × 似然比：$$\frac{P(D\mid+)}{P(\neg D\mid+)} = \underbrace{\frac{1}{99}}_{\text{先验 odds}} \times \underbrace{\frac{0.9}{0.05}=18}_{\text{似然比}} \approx 0.18$$——**证据强（18 倍）但先验太弱（1:99），拔河只把信念从 1% 拉到 15.4%**。再测一次独立阳性：odds 变 $$0.18\times18\approx3.28$$ → 概率 $$\approx 77\%$$——**贝叶斯更新可以串联，证据一条条来**。

**第 4 步：为什么机器学习离不开它。** 生成模型的核心量 $$p_\theta(z\mid x)$$（后验）分母 $$p_\theta(x)=\int p_\theta(x\mid z)p(z)dz$$ 要对**所有 z** 积分——神经元网络当似然时积不出来（[ELBO](/ai-fa/explore/40-Concepts/ELBO) 存在的理由）；而 DDPM 反向推导恰好因为**高斯的条件仍是高斯**，能走通这条链（[DDPM后验分布](/ai-fa/explore/30-Formulas/DDPM后验分布)）。

## 3. 为什么 AI 需要它

| 出现场景                     | 用法                                     |
| ------------------------ | -------------------------------------- |
| [DDPM后验分布](/ai-fa/explore/30-Formulas/DDPM后验分布) | 推导反向转移 $$q(x_{t-1}\mid x_t, x_0)$$ 的核心工具 |
| [ELBO](/ai-fa/explore/40-Concepts/ELBO)     | 后验 $$p_\theta(z\mid x)$$ 不可算 → 抬下界       |
| 朴素贝叶斯分类器                 | 直接套公式                                  |
| RL / 对齐                  | 贝叶斯视角的信念更新（如后验采样探索）                    |

## 4. 常见误区

- **误区**：后验是"更新后的概率"，不是"更准的先验"——它关于**同一事件**但**条件变了**
- **误区**：$$p(x)$$ 可以扔——只在不求归一化值时可行；要比较后验大小必须算或用采样绕过
- **误区**：先验随便选——敏感问题上先验强则后验被先验绑架（贝叶斯的哲学争议）

## 5. 自测

1. 先验 odds 1:1（发病率 50%）时同一证据把信念推到哪？（odds $$=1\times18$$ → $$\approx94.7\%$$——**同证据，先验决定起点**）
2. 后验∝似然×先验，比例式何时够用、何时必须算分母？（只比较相对大小时够；要概率值/采样归一时必须）
3. L2 正则是哪个贝叶斯角色的化身？（先验=高斯先验的 MAP——频率派的正则与贝叶斯的先验是一枚硬币）
4. 贝叶斯串联更新中"证据独立"为什么重要？（似然比可直接相乘；相关证据重复计数会过度自信）
