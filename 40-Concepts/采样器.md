# 采样器与数值积分器

## 1. 定义（直觉 → 形式）

**直觉**：模型训练好后，怎么"画出"一张图？两种思路：
- **随机采样器**：按反向 SDE 一步步走，每步注入新噪声（DDPM 祖先采样）
- **确定性积分器**：按概率流 ODE 走，无噪声（DDIM / FM 采样）

**形式**：把连续过程离散化为 $N$ 步，每步 $t_i \to t_{i+1}$：
- **欧拉法**（ODE 基础款）：$x_{t+\Delta t} \approx x_t + \Delta t \cdot v(x_t, t)$
- **祖先采样**（DDPM 式）：$x_{t-1} \sim p_\theta(x_{t-1} \mid x_t)$，每步重采样高斯
- **Heun 二阶**（EDM 主推）：欧拉预估 + 校正，同样步数误差低一阶

## 2. 数学形式

| 采样器 | 类型 | 每步算什么 | 步数敏感度 |
|---|---|---|---|
| 祖先采样（DDPM） | 随机 | 预测均值 + 注入噪声 $\sigma_t z$ | 高（50–1000 步） |
| DDIM | 确定性 | 沿 ODE 方向走，噪声项置零（$\eta=0$） | 低（10–50 步） |
| Euler（FM/Rectified Flow 常用） | 确定性 | 欧拉一步 | 中 |
| Heun / DPM-Solver | 确定性高阶 | 预估-校正 / 高阶项 | 低（10–20 步） |
| 朗之万 | 随机 | score 步 + 噪声步 | 极高 |

- **随机 vs 确定性的等价性**：同一模型可两用（SDE ↔ 概率流 ODE 边缘分布相同），随机版样本更多样、确定性版可逆可插值
- **步数-质量权衡**：这是"扩散采样慢"的来源，也是蒸馏线（Consistency Models、DMD）要消灭的对象

## 4. 常见误区

- **误区**："采样慢 = 模型差"——是数值积分步数问题，与模型质量正交
- **误区**：确定性采样"丢多样性"——边缘分布相同，多样性源于初始噪声 $z$ 的不同
- **误区**：祖先采样的噪声项"可以随便去掉"——$\eta$ 控制随机性比例，DDIM 是 $\eta=0$ 特例不是"错误用法"
