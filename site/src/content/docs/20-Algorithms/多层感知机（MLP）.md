# 多层感知机（MLP）

## 1. 定义

**非数学语言**：最朴素的神经网络——一排排"神经元"，**每一排都与上一排全连接**，信息从输入直通输出（前馈、不回头）。它是所有现代架构的积木：Transformer 的 FFN、CNN 的收尾分类头、扩散模型的去噪器主体，内核都是 MLP。

**数学语言**：$$L$$ 层全连接变换的堆叠：
$$h_l = \phi(W_l h_{l-1} + b_l), \quad l = 1,\dots,L, \qquad h_0 = x$$
$$W_l \in \mathbb{R}^{d_l \times d_{l-1}}$$，$$\phi$$ 为逐元素激活（[ReLU](/ai-fa/explore/40-Concepts/ReLU) 系）。

## 2. 本命论文群

| 论文 | 引入/发展了什么 | 年份 |

| Rumelhart, Hinton & Williams（未建卡） | BP 训练多层感知机——XOR 问题随深度消解 | 1986 |
| Hornik（未建卡） | 万能逼近定理：一个隐藏层即可逼近任意连续函数 | 1989 |

## 3. 教程：从一个神经元到一个网络

**第 1 步：一个神经元=一次加权打分。** 输入 $$x=(x_1,\dots,x_d)$$，权重 $$w$$，偏置 $$b$$，输出 $$a = \phi(w^\top x + b)$$。直觉：$$w$$ 是"你重视哪些输入"的打分表，$$b$$ 是"及格线"，$$\phi$$ 决定"过线了怎么反应"。

**第 2 步：手算一个 2-3-1 网络。** 输入 $$x=(1, 0)$$，第一层：
$$W_1 = \begin{bmatrix} 0.5 & -0.2 \\ 0.1 & 0.8 \\ -0.3 & 0.6 \end{bmatrix},\; b_1 = \begin{bmatrix} 0\\ 0\\ 0 \end{bmatrix} \Rightarrow z_1 = W_1 x = \begin{bmatrix} 0.5\\ 0.1\\ -0.3 \end{bmatrix} \xrightarrow{\text{ReLU}} h_1 = \begin{bmatrix} 0.5\\ 0.1\\ 0 \end{bmatrix}$$
（第三个神经元收到负分 → 死区归零——[ReLU](/ai-fa/explore/40-Concepts/ReLU) 的稀疏性现场。）第二层 $$w_2 = (1, -2, 0.5)$$：$$y = 1\times0.5 + (-2)\times0.1 + 0.5\times0 = 0.3$$。**整网就是"矩阵乘→弯一下"的重复**。

**第 3 步：XOR——为什么需要隐藏层。** 异或 $$(0,0)\to0,\,(1,1)\to0,\,(1,0)\to1$$：任何一条直线都无法把两个 1 类从两个 0 类里分出来（**线性不可分**）。加一个隐藏层：先由两个神经元各自学"或非""与非"两张线性切分，第二层组合它们——**深一层的本质=学出新的表示，让输出层重新变得线性可分**。这是"深度"的第一性价值。

**第 4 步：万能逼近定理的正确读法。** "一个足够宽的隐藏层可以逼近任意连续函数"——但**没说这个隐藏层容易被学出来**（宽度可能指数大）。实践定理（经验规律）：**同容量下，深而窄胜过浅而宽**——折点组合的复用效率（同 [CNN](/ai-fa/explore/20-Algorithms/CNN) §3 感受野叠加的逻辑：深度买组合爆炸）。

**第 5 步：参数量与全连接的代价。** 层间参数 $$= d_l \times d_{l-1} + d_l$$。$$d=1000\to1000$$ 的一层=百万参数；图像 224×224×3 直接拉平进 MLP=150528 维输入——第一层就要 1.5 亿参数。**MLP 不知道"局部"与"共享"**，这正是 CNN（权重共享）与注意力（动态加权）各自登场的理由。

## 4. 核心公式速查

| 件 | 公式 | 记忆点 |
|---|---|---|
| 层变换 | $$h_l = \phi(W_l h_{l-1}+b_l)$$ | 矩阵乘→弯一下 |
| 参数量/层 | $$d_l d_{l-1} + d_l$$ | 全连接=参数大户 |
| 万能逼近 | $$\exists W: \|f(x)-W_2\phi(W_1x)\|<\epsilon$$ | 存在≠可学（见 §3 第 4 步） |
| 训练 | [反向传播](/ai-fa/explore/20-Algorithms/反向传播) + [梯度下降与优化器谱系](/ai-fa/explore/20-Algorithms/梯度下降与优化器谱系) | 全库通用引擎 |

## 8. 常见误区

- **误区**："感知机"=MLP——感知机是**单层**的（1958）；MLP 是多层堆叠（多隐藏层）。XOR 危机打倒的是前者
- **误区**：万能逼近定理保证能学好——只保证**存在**这样的权重，不保证梯度下降找得到、也不保证宽度合理
- **误区**：MLP 是"旧时代产物"——Transformer 里参数量最大的 FFN 就是两层 MLP（[Transformer](/ai-fa/explore/20-Algorithms/Transformer)）；扩散模型去噪器的中间块也以 MLP/全连接为主
- **误区**：层数越多越好——没残差/归一化的深 MLP 会梯度消失（[反向传播](/ai-fa/explore/20-Algorithms/反向传播) §5）；"深而窄>浅而宽"的前提是训练信号能到达

## 9. 自测

1. 为什么没有激活函数时 $$L$$ 层 MLP 等价于一层？（矩阵连乘 $$W_L\cdots W_1$$ 仍是矩阵）
2. 2-3-1 网络共几个参数？（$$2{\times}3{+}3 + 3{\times}1{+}1 = 13$$）
3. 隐藏层对 XOR 做了什么？（学新表示：把线性不可分变成对输出层线性可分）
4. 为什么图像不直接拉平进 MLP？（参数爆炸+丢掉局部/平移结构——全连接对这些先验一无所知）

**一句话总结**：MLP 是"加权打分+弯一下"的堆叠塔——表达能力来自深度组合，效率短板（全连接参数大户）催生了 CNN 与注意力，但它自己始终是每个现代架构里那块最粗的积木（FFN）。
