# 均方根归一化 RMSNorm

## 1. 标准形式

$$\mathrm{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{j=1}^{d} x_j^2 + \epsilon}} \odot g$$
只除以**均方根**（root mean square），不减均值；缩放用单一可学向量 $$g$$（没有平移 $$\beta$$）。

## 2. 教程：与 LN 并排手算（看省了什么、剩什么）

**第 1 步：同一向量两种归一。** $$x = (1, 3)$$（[层归一化](/ai-fa/explore/30-Formulas/层归一化) §2 同款数字）：
- **LN**：$$\mu=2,\ \sigma=1$$ → $$(-1, +1)$$
- **RMSNorm**：$$\mathrm{RMS} = \sqrt{\frac{1^2+3^2}{2}} = \sqrt{5} \approx 2.24$$ → $$(0.45,\ 1.34)$$

**第 2 步：差异读法。** LN 输出**强制零均值**；RMSNorm 输出只是**尺度归一**（原点未动：1 和 3 的相对结构保留，整体缩小到 RMS=1）。若输入本来就零中心（如 LN 之后的层、或 ReLU 后再归一场景），两者几乎重合——**"均值项到底干不干活"的实验答案：大多数训练动态里不关键**（Zhang & Sennrich 2019 的消融结论）。

**第 3 步：省两样东西。** ①减均值（一次减法+统计 $$\mu$$）；②平移参数 $$\beta$$（参数省 $$d$$ 个）。收益：每层快约 10-15%（**在千层 LLM 里累积成可观算力**）——LLaMA 全系选择它的全部理由：**质量不损、速度白赚**。

**第 4 步：数值稳定注意。** 全零向量 $$\mathrm{RMS}=0$$ → 除零，靠 $$\epsilon$$ 兜底（公式里藏在根号内）；这也是所有归一化层的标准防御。

## 4. 直觉解释

- **"归一化的最小必要动作"**：对训练稳定性真正关键的是**尺度**（防止逐层放大/萎缩爆炸），中心化是可有可无的装饰——RMSNorm 用消融证明了这个"最小集"
- 与 [选择机制](/ai-fa/explore/30-Formulas/选择机制)（Mamba 用 softplus 保恒正）同属"按需裁剪激活/归一化件"的现代简约风
