# 期望 Expectation

## 1. 定义（直觉 → 形式）

**直觉**：期望 = 无限次重复实验后的平均值。掷骰子的期望是 3.5——你永远掷不出 3.5，但掷一万次的平均会非常接近它。

**形式**：
$$\mathbb{E}[f(x)] = \int f(x)\, p(x)\, dx \quad\text{(连续)},  \qquad \mathbb{E}[f(x)] = \sum_i f(x_i)\, P(x_i) \quad\text{(离散)}$$

**本库标准记号**：必须写明采样分布下标：$$\mathbb{E}_{x \sim p}[\cdot]$$ 或 $$\mathbb{E}_{t, x_0, \epsilon}[\cdot]$$（多变量时）。批内经验平均记 $$\hat{\mathbb{E}}[\cdot]$$（训练时用有限 batch 估计真期望）。

## 2. 数学形式

关键运算规则：
- **线性**：$$\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]$$
- **条件期望**：$$\mathbb{E}[X \mid Y=y]$$：已知 $$Y$$ 时 $$X$$ 的平均
- **塔性质（全期望公式）**：$$\mathbb{E}[\mathbb{E}[X \mid Y]] = \mathbb{E}[X]$$（对分布建模推导极其重要）
- **蒙特卡洛估计**：$$\mathbb{E}_{x\sim p}[f(x)] \approx \frac{1}{N}\sum_{i=1}^N f(x_i),\ x_i \sim p$$——深度学习损失函数的底层来源

## 教程：从骰子到损失函数（三步手算）

**第 1 步：骰子的期望=3.5，算给你看。** $$\mathbb{E}[x]=\sum_{k=1}^{6} k\cdot\frac{1}{6}=\frac{1+2+3+4+5+6}{6}=\frac{21}{6}=3.5$$。注意 3.5 **掷不出来**——期望是分布的属性，不是"最可能的结果"（那叫众数）。

**第 2 步：蒙特卡洛——用样本平均逼近它。** 掷 4 次得 $$(2, 6, 4, 6)$$：$$\hat{\mathbb{E}} = \frac{2+6+4+6}{4}=4.5$$——偏差 1；掷 1000 次，平均大概率落在 3.4-3.6（大数定律）。**训练循环的每个 `loss = mean(batch_losses)` 就是这个式子**：batch=从数据分布采的样本，$$\hat{\mathbb{E}}$$ 无偏（$$\mathbb{E}[\hat{\mathbb{E}}]=\mathbb{E}[f]$$）但方差 $$\propto 1/N$$——batch 越大方差越小，这就是 batch size 的统计学意义。

**第 3 步：塔性质——分层平均的"先内后外"。** 骰子分两厂生产：A 厂（70% 骰子）均值 3.4、B 厂（30%）均值 3.7：
$$\mathbb{E}[x] = \mathbb{E}_{厂}[\mathbb{E}[x\mid 厂]] = 0.7\times3.4 + 0.3\times3.7 = 2.38+1.11 = 3.49$$
**"先在每个子世界里平均，再按子世界权重平均"= 直接平均**。变分下界、EM、RL 策略评估里的"E over E"全部是这个动作——遇到嵌套期望不再慌。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| 几乎所有训练损失 | $$\mathcal{L}(\theta) = \mathbb{E}_{\text{数据}}[\ell(\theta)]$$，实践中用 batch 近似 |
| [DDPM训练目标](/ai-fa/explore/30-Formulas/DDPM训练目标) | $$\mathbb{E}_{t, x_0, \epsilon}$$：随机抽时刻、数据、噪声三者求平均 |
| [条件流匹配损失](/ai-fa/explore/30-Formulas/条件流匹配损失) | $$\mathbb{E}_{t, x_0, z}$$：同样结构 |
| RL | 策略的目标 $$J(\theta) = \mathbb{E}_{\pi_\theta}[r]$$ |

**训练的本质**：用 batch 平均 $$\hat{\mathbb{E}}$$ 近似真期望 $$\mathbb{E}$$，梯度下降把近似最小化。

## 4. 常见误区

- **误区**："期望就是平均"——平均是期望的**估计**，期望是分布的**属性**
- **误区**：期望存在不等于能算出来——高维积分没有解析解，只能蒙特卡洛
- **误区**：$$\mathbb{E}[f(g(x))] \neq f(\mathbb{E}[g(x)])$$（非线性不可交换，Jensen 不等式的来源）

## 5. 自测

1. $$\mathbb{E}[2x+1]$$（骰子）=？（$$2\times3.5+1=8$$——线性性）
2. $$\mathbb{E}[x^2]$$（骰子）=？（$$\frac{1+4+9+16+25+36}{6}=\frac{91}{6}\approx15.17$$——**≠** $$\mathbb{E}[x]^2=12.25$$，差值恰是方差）
3. batch 损失平均为何无偏？方差与 batch 大小的关系？（样本独立同分布→$$\hat{\mathbb{E}}$$ 期望=真期望；方差 $$\propto 1/N$$）
4. 塔性质什么时候用？（联合分布难算但"给定条件后的期望"好算时——先条件内平均再对条件平均）
