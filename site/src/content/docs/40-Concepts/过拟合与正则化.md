# 过拟合与正则化

## 1. 定义（直觉 → 形式）

**直觉**：**背答案 vs 学方法**。训练分 99、考试 60——模型把训练集的噪声细节当成了规律背了下来。正则化=一切"故意让训练变难一点，换取考试变好"的手段：限制容量、加噪声、早收手。

**形式**：泛化误差分解（对随机训练集取期望）：
$$\mathbb{E}\big[(\hat y - y)^2\big] = \underbrace{\text{Bias}^2}_{\text{欠拟合：方法不对}} + \underbrace{\text{Variance}}_{\text{过拟合：对训练集太敏感}} + \underbrace{\sigma^2}_{\text{数据本身的噪声，无解}}$$
正则化的统一形式：
$$\min_\theta \; \mathcal{L}_{\text{train}}(\theta) + \lambda\, \mathcal{R}(\theta)$$
$$\lambda$$ 大=训练损失让位于"规矩"；$$\lambda\to\infty$$=只讲规矩不会做题（欠拟合）。

## 2. 教程：五个武器库逐个拆

**第 1 步：先会诊断。** 数据划分：**训练/验证/测试 = 做题册/模拟卷/高考**。训练误差降、验证误差降→还能学（欠拟合区）；训练误差继续降、验证误差**回升**→过拟合起点，此刻的模型是最佳点。**测试集一生只能看一次**（看完再回去改模型=作弊，高考不能反复考）。学习曲线（双误差 vs 训练量/模型大小）是诊断图。

**第 2 步：L2 正则（权重衰减）——把权重按倒。** 罚项 $$\mathcal{R}=\|\theta\|_2^2$$。几何：损失碗+圆形罚→解被拉向原点附近。**贝叶斯读法**：L2=高斯先验的 MAP（[贝叶斯公式](/ai-fa/explore/40-Concepts/贝叶斯公式) 的延伸）。效果=权重整体变小→函数更平滑→对输入扰动不敏感。岭回归（$$X^\top X+\lambda I$$）顺带治特征共线（[线性模型（回归与分类）](/ai-fa/explore/40-Concepts/线性模型（回归与分类）) §2）。

**第 3 步：L1 正则——稀疏选特征。** 罚项 $$\mathcal{R}=\|\theta\|_1$$。几何：菱形罚的角在坐标轴上→解恰好落在轴上=部分权重**精确为 0**——自动特征选择（LASSO）。**L2 均匀压缩、L1 定点清除**。

**第 4 步：Dropout——每步随机关一批灯。** 训练时每步随机以 $$p$$（常 0.1-0.5）把一部分单元置零，测试时不关（权重按 $$(1-p)$$ 缩放或训练时已除）。机制：①单个单元不能过度依赖特定伙伴（**冗余表征**被迫形成）；②等价于训练指数多个子网络的集成。现代 LLM 注意力上的 dropout 概念同源。注意与 [ReLU](/ai-fa/explore/40-Concepts/ReLU) 稀疏的区别：ReLU"输入决定谁沉默"，dropout"骰子决定谁沉默"。

**第 5 步：早停+数据增强——免费的午餐。** 早停：验证误差回升就停（把"训多久"当超参）。数据增强：一图变多图（翻转/裁剪/加噪）——**最便宜的正则**，直接增大有效数据量。现代扩展：Mixup（两图加权叠加）、masked 预训练（[自监督掩码重建](/ai-fa/explore/30-Formulas/自监督掩码重建)——"遮住再猜"本身就是一种数据增强+正则）。

**第 6 步：深度学习特有的隐式正则。** SGD 噪声偏好平坦极小值（泛化好）、早停与 warmup 调度、参数量>数据量却不过拟合的"双下降"现象——深度学习的正则不都在罚项里，很多藏在**训练过程**中（[梯度下降与优化器谱系](/ai-fa/explore/20-Algorithms/梯度下降与优化器谱系) §7 的 SGD 泛化红利）。

## 4. 常见误区

- **误区**：过拟合=模型太大——**容量×数据量×训练时长**三要素共同决定；小模型也能过拟合（训练太久），大模型在大量数据+早停下可以不过拟合（现代 LLM 的日常）
- **误区**：验证集=测试集——验证集可反复看（调参用），测试集只能看一次；反复用测试集调参=把测试集变成了验证集（信息泄漏）
- **误区**：正则越强越好——$$\lambda$$ 过大进入欠拟合区（训练误差也下不来）；目标是**验证误差的谷底**，不是"最大正则"
- **误区**：dropout 测试也要关灯——测试全开+权重缩放（inverted dropout 已在训练时处理）；测试时随机会让预测不可复现

## 5. 自测

1. 训练 0.02 / 验证 0.34 / 测试 0.33：什么病？开什么药？（严重过拟合；增强+dropout+衰减+早停，或加数据）
2. L1 与 L2 的解的几何差异？（菱形角→轴上稀疏解 vs 圆→均匀缩小的稠密解）
3. 为什么说 SGD 噪声是"免费的正则"？（跳出尖锐极小值，停在平坦盆地——平坦=对扰动不敏感=泛化好）
4. 双下降是什么？（参数量增大→测试误差先降后升再降；第二个下降段=过参数化后训练过程本身的正则效应）
