# 线性模型（回归与分类）

## 1. 定义（直觉 → 形式）

**直觉**：机器学习的第 0 课——**用一条直线（超平面）拟 合数据**。回归版画一条线穿过点（线性回归）；分类版用一条线切开两类（逻辑回归）。别小看它：逻辑回归去掉中间的 sigmoid 就成了线性回归；把"线性打分器"换成网络、把"sigmoid" 换成 softmax，就走到了现代分类器的门口。

**形式**：
$$\text{线性回归：}\; \hat y = w^\top x + b \qquad \text{逻辑回归：}\; p(y{=}1\mid x) = \sigma(w^\top x + b) \qquad \text{softmax 回归：}\; p(y{=}k\mid x) = \frac{e^{w_k^\top x}}{\sum_j e^{w_j^\top x}}$$

## 2. 教程：三个问题一条线

**第 1 步：线性回归——画线预测房价。** 数据：面积 $x$ 与房价 $y$。模型 $\hat y = wx + b$。损失选**平方和**（[[30-Formulas/均方误差（MSE）]]）：
$$L(w,b) = \frac{1}{n}\sum_i (w x_i + b - y_i)^2$$
这是 $w, b$ 的**凸函数**（碗形）——只有一个谷底，梯度下降（[[20-Algorithms/梯度下降与优化器谱系]]）必达。手算梯度：
$$\frac{\partial L}{\partial w} = \frac{2}{n}\sum_i x_i(\hat y_i - y_i), \qquad \frac{\partial L}{\partial b} = \frac{2}{n}\sum_i (\hat y_i - y_i)$$
（[[20-Algorithms/反向传播]] §3 的 $\delta\cdot h^\top$ 在一维的形态——误差×输入。）

**第 2 步：最小二乘的闭式解。** 小样本时不用迭代，一步到位（$X$ 为含 1 列的设计矩阵）：
$$w^\star = (X^\top X)^{-1} X^\top y$$
**存在性前提**：$X^\top X$ 可逆——**特征列线性无关**（列满秩）。特征共线（如"面积"与"卧室数"高度相关）时 $X^\top X$ 病态/奇异——这正是岭回归（$+\lambda I$ 正则，[[40-Concepts/过拟合与正则化]]）登场的经典场景。

**第 3 步：逻辑回归——把回归掰弯成分类。** 直接用 $\hat y = w^\top x$ 做 0/1 分类的问题：输出 7.3 是什么意思？多 0.01 又算多确信？**套一层 sigmoid**（[[40-Concepts/sigmoid函数]]）把打分压进 (0,1) 当概率读：
$$p = \sigma(z), \quad z = w^\top x + b \;\; \Longleftrightarrow \;\; \log\frac{p}{1-p} = z$$
第二式是"对数几率（logit）"视角：**线性模型其实一直在学"对数几率"**——这是逻辑回归与 [[40-Concepts/Bradley-Terry模型]]/[[30-Formulas/DPO损失]] 一脉相承的原因（都在学打分差的 sigmoid）。

**第 4 步：逻辑回归为什么不用 MSE。** 损失选**负对数似然**（=二分类 [[30-Formulas/交叉熵]]）：
$$L = -\frac{1}{n}\sum_i \big[y_i \log p_i + (1-y_i)\log(1-p_i)\big]$$
梯度有一个极简结局（代入园求导）：
$$\frac{\partial L}{\partial w} = \frac{1}{n}\sum_i (p_i - y_i)\, x_i$$
**梯度=误差×输入**，与线性回归形式完全一致，且无饱和拖累。若硬用 MSE：$p$ 被压到 0/1 附近时 MSE 梯度被 $\sigma'$（≤0.25）再压一层——错得离谱时梯度反而趋零，学不动（[[40-Concepts/激活函数族]] 的饱和教训在损失函数上的翻版）。交叉熵+sigmoid 的配对是**数学上的绝配**（详见 [[40-Concepts/最大似然估计（MLE）]] §3）。

**第 5 步：softmax 回归=多类推广。** K 类各学一个打分 $w_k$，softmax 归一化成分布；损失=多类交叉熵。**这就是现代网络分类头的精确形态**：把 $w^\top x$ 换成 50 层网络的输出，头本身一个字都不用改。

## 3. 数学性质速查

- **凸性**：线性/逻辑回归+MSE/交叉熵=凸问题——**全局最优唯一**，无调参玄学（神经网络的"不可复现"在这里不存在）
- **MLE 出身**：MSE=高斯噪声假设的 MLE；交叉熵=伯努利/多项 MLE（[[40-Concepts/最大似然估计（MLE）]] §3 统一表）
- **可解释性之王**：系数正负=特征方向性影响—— Kaggle 表格数据时代"先跑一个逻辑回归基线"的行业惯例
- **线性边界**：决策面 $w^\top x + b = 0$ 是超平面；XOR 不可分（[[20-Algorithms/多层感知机（MLP）]] §3 第 3 步）

## 5. 常见误区

- **误区**：逻辑回归是"回归算法"——名字里的回归是历史遗留（它学的是对数几率的**回归**），用途是**分类**
- **误区**：线性模型=弱的模型——在"特征已经很有信息量"的表格任务上，正则化线性模型常年吊打深度网络（Kaggle 结构化数据的老经验）
- **误区**：系数大=特征重要——量纲没标准化时毫无意义（面积以 m² 还是 km² 计，系数差百万倍）；先做特征标准化再读系数
- **误区**：MSE 也能训逻辑回归只是慢——不只是慢：错得离谱时梯度反而消失（§2 第 4 步），是**病态**不是低效

## 6. 自测

1. 逻辑回归与线性回归的梯度为何形式相同？（$\hat y - y$ 乘 $x$——MSE+恒等 与 交叉熵+sigmoid 的共同"绝配"结局）
2. 为什么特征共线时闭式解失效？（$X^\top X$ 奇异；岭回归加 $\lambda I$ 救回）
3. softmax 回归与神经网络的分类头差在哪？（只差"打分器"是 $w^\top x$ 还是深网络——头本身完全相同）
4. 决策边界的几何形状？（超平面 $w^\top x+b=0$；$w$ 是它的法向量）
