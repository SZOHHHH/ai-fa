# 概率分布 Probability Distribution

## 1. 定义（直觉 → 形式）

**直觉**：概率分布描述"随机抽取一个值时，各种可能结果各有多大的可能性"。就像一个抽奖箱——分布就是箱子里各种奖券的比例说明书。

**形式**：对连续变量 $$x$$，分布由概率密度函数 $$p(x)$$ 描述，满足：
$$p(x) \ge 0, \quad \int p(x)\, dx = 1$$
单个点的"概率"为零，只有区间有意义：$$P(x \in [a,b]) = \int_a^b p(x)\, dx$$。

## 2. 数学形式

- 离散：概率质量函数 $$P(x = x_i)$$，各点概率之和为 1
- 连续：密度函数 $$p(x)$$
- 累积分布：$$F(x) = \int_{-\infty}^{x} p(s)\, ds$$

**记号速查**（本库标准）：$$x \sim p$$ 表示"$$x$$ 服从分布 $$p$$"；$$p_\theta$$ 表示由参数 $$\theta$$ 定义/神经网络诱导的分布。

## 教程：手算三个分布（从数字上手）

**第 1 步：离散——骰子。** $$P(x{=}k)=1/6,\ k=1..6$$：六点各 $$1/6$$，求和 $$6\times\frac{1}{6}=1$$ ✓（归一化是分布的第一身份）。检验自己：把"$$P(偶数)=1/6+1/6+1/6=0.5$$"算一遍——**离散分布对"事件"求和**。

**第 2 步：连续——均匀分布 $$U(0,2)$$。** 密度 $$p(x)=0.5$$（$$0\le x\le 2$$）。注意两件事：①$$\int_0^2 0.5\,dx = 1$$ ✓；②$$P(x=1)=0$$（单点测度为零）而 $$p(1)=0.5>0$$——**密度不是概率**，区间才有概率：$$P(x\in[0,1])=\int_0^1 0.5\,dx=0.5$$。均匀分布的密度为何是 0.5？长度 2 均摊概率 1——"单位长度的概率质量"。

**第 3 步：密度可以大于 1。** $$U(0, 0.5)$$ 的密度是 $$p(x)=2$$——在长 0.5 的区间上密度 2，积分 $$0.5\times2=1$$ ✓。这是"密度 vs 概率"最锋利的反直觉：密度是**每单位长度的概率浓度**，浓度当然可以超 1。

**第 4 步：经验分布=你手里的 histogram。** batch 里的样本 $$\{x_i\}_{i=1}^N$$ 定义经验分布 $$\hat p(x)=\frac{1}{N}\sum_i \delta(x-x_i)$$——训练的蒙特卡洛估计（[期望](/ai-fa/explore/40-Concepts/期望) §2）全部建立在对它求和上。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [扩散模型](/ai-fa/explore/20-Algorithms/扩散模型) | 前向过程把数据分布 $$p_{\text{data}}$$ 逐步变成噪声分布 $$\mathcal{N}(0, I)$$；生成 = 反向 |
| [生成对抗网络](/ai-fa/explore/20-Algorithms/生成对抗网络) | 生成器造分布，判别器比较真分布与假分布 |
| [流匹配](/ai-fa/explore/20-Algorithms/流匹配) | 学习把源分布搬运到目标分布的速度场 |
| RL（对齐线） | 策略 $$\pi(a\mid s)$$ 本身就是动作的条件分布 |

**核心统一视角**：所有生成模型的本质都是"把简单分布（高斯噪声）变换成复杂数据分布"——区别只在变换方式。

## 4. 常见误区

- **误区**：密度 $$p(x)$$ 可以大于 1（是"密度"不是"概率"）
- **误区**：$$p(x)$$ 大 ≠ 容易采样；采样需要专门方法（见 [采样器](/ai-fa/explore/40-Concepts/采样器)）
- **误区**：两个分布"差多少"没有唯一定义——KL 散度和 [Wasserstein距离](/ai-fa/explore/40-Concepts/Wasserstein距离) 给出不同答案，这直接导致 GAN 与 VAE 的分野

## 5. 自测

1. $$U(0,3)$$ 的密度？$$P(x\in[1,2])$$？（$$1/3$$；$$1/3$$）
2. 骰子的 $$P(x\le 2)$$？（$$2/6=1/3$$）
3. 为什么 $$P(x=1)=0$$ 但 $$p(1)$$ 可以是 2？（密度≠概率——区间测度零 vs 单位长度浓度）
4. 经验分布与真实分布的关系？（大数定律：N→∞ 时 $$\hat p\to p$$——训练集"代表"总体的数学根据）
