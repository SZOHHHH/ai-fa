# 选择机制（Mamba 选择性）

## 1. 标准形式

$$\Delta t = \mathrm{softplus}(\mathrm{Linear}(x_t)) \;\Longrightarrow\; \bar A_t = e^{-\Delta t\, A},\quad \bar B_t = \Delta t\, B\, x_t \quad(\text{时变参数})$$

- **一切让参数看输入**：$$\Delta, B, C$$ 从固定变成 $$x_t$$ 的函数——LTI（线性时不变）系统变成时变系统
- softplus 保证 $$\Delta t > 0$$（衰减指数必须有定义且方向正确，[激活函数族](/ai-fa/explore/40-Concepts/激活函数族) §恒正需求行）
- 这是 Mamba 相对 S4 的**唯一核心改动**——却带来"看内容决定记什么忘什么"的能力

## 教程：重要 token 与不重要 token 的两种待遇（两档手算）

**第 1 步：Δ 的身份。** $$\Delta t$$ 是"这一步的时间跨度"：$$\bar A_t = e^{-\Delta t\, A}$$（取 $$A = 1$$）——**Δ 大 → ā 小 → 旧记忆清得多；Δ 小 → ā 接近 1 → 原样传递**。

**第 2 步：重要 token（开大门、倒垃圾）。** 输入是个关键词，网络给 $$\Delta t = 0.693$$：$$\bar A_t = e^{-0.693} = 0.5$$——旧状态砍半；写入强度 $$\bar B_t \approx \Delta t\, B\, x_t = 0.693\times B\, x_t$$（一阶近似）——**新信息大笔写入**。这一步在做的事：腾出记忆空间、装进重点。

**第 3 步：不重要 token（关小门、传家宝）。** 填充词，$$\Delta t = 0.1$$：$$\bar A_t = e^{-0.1} = 0.905$$——旧状态九成保留；$$\bar B_t \approx 0.1\, B\, x_t$$——只写一点点。这一步几乎只传递不更新：**宝贵的记忆不为噪音让位**。

**第 4 步：数值对照。** 设旧状态 $$h = 1.0$$、$$B x_t = 1.0$$：重要步后 $$h' = 0.5\times1.0 + 0.693 = 1.193$$（大换血）；不重要步后 $$h' = 0.905\times1.0 + 0.1 = 1.005$$（近乎原样）——**同一个状态，两种命运，全由内容决定**。

**第 5 步：代价与补偿。** 时变参数打破卷积形式（[状态空间模型方程](/ai-fa/explore/30-Formulas/状态空间模型方程) 第 3 步的并行性失效）——Mamba 用并行扫描（selective scan，仿射复合的结合律还在）+ 硬件感知（状态驻留 SRAM、核融合）补回来；端到端仍是线性复杂度且推理吞吐 5× 于 Transformer（原文数字）。

## 3. 直觉解释

- **选择性 = 内容寻址的遗忘**：注意力记住一切（代价平方）；固定 SSM 均匀遗忘（代价丢信息）；选择性 SSM **按内容定遗忘率**——两难的中庸解
- 为什么 Δ 一个参数就够：它同时控制"忘多少（ā）"与"记多少（b̄∝Δ）"——**一钮双控**，物理学里"时间步长"的本义
- 与 LSTM 门控的血缘：输入门/遗忘门手工设计逐元素 sigmoid；选择机制用结构化指数（$$e^{-\Delta A}$$）保证稳定（谱范数 ≤1，天然不爆炸）
- "选择性"的能力实证：复制任务（只记目标 token）、归纳头（找前文匹配）——固定 S4 做不好的正需要"跳过无关内容"

## 6. 自测

1. $$\Delta t = 0.693$$、$$A = 1$$：$$\bar A_t$$？（$$e^{-0.693} = 0.5$$——旧记忆砍半=大换血档）
2. 不重要 token 的待遇？（$$\Delta t$$ 小 → $$\bar A\to1$$ 只传不写——宝贵记忆不为噪音让位）
3. Δ 为什么一钮双控？（同时进 $$\bar A = e^{-\Delta A}$$（忘多少）与 $$\bar B \propto \Delta$$（记多少））
4. 卷积性失去后靠什么并行？（并行扫描（仿射复合结合律）+ 硬件感知 SRAM 驻留）
