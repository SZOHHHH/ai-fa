# 多模态对齐矩阵

> [!purpose] 目标
> 视觉-语言（及语音-语言）对齐的设计空间。核心问题：**两个模态的表示在哪里相遇**。评估见 [[00-Meta/研究矩阵规范]] §2。

## 1. 轴定义

| 轴 | 取值 | 判据 |
|---|---|---|
| **接口** | 对比接口（各自编码再拉近）、投影接口（编码器→LLM）、生成接口（自回归统一解码）、冻结组合 | 模态边界处放什么模块 |
| **对齐目标** | 对比（InfoNCE）、匹配（ITM/MLM）、生成（条件 LM 损失）、早期融合（联合训练从头对齐） | 优化什么损失 |
| **融合深度** | 接口级、深对齐（中层交互）、完全早期融合 | 表示流在多深处混合 |

## 3. 格评估（四维）

| 格 | 评估 | 结论 |
|---|---|---|
| 对比 × InfoNCE | 3/5/2/2 | CLIP 已收束，纯对比改进无空间 |
| **投影 × 生成 × 理论** | 4/4/**4/4** | 🌱 半机会格：投影接口（BLIP-2/LLaVA）是主流但"投影层的信息瓶颈分析"（视觉 token 压缩率与下游推理能力的权衡）无定型理论——现象已多（token 数 vs 精度曲线），理论未占。风险：偏实证分析，需数学故事补强 |
| 生成 × 统一解码 | 4/5/3/3 | Chameleon 已占；训练稳定性（early fusion 的优化困难）是已知痛点但解法工程化 |
| **对比 × 早期融合** | 3/3/5/3 | 结构性困难：对比目标需要双塔，早期融合后无法成对——**半死格**（不是数学无意义，是目标函数不匹配），除非改单塔自对比（novelty 高但风险大） |
| **生成 × 视频（跨矩阵）** | 5/4/4/**5** | 🌱 与 [[60-Matrices/生成模型加速矩阵]] 的"视频×FM 加速"格同格（已在彼处评估）：视频 LLM（VideoPoet）+ FM 骨干 + 一步生成——**两矩阵共享的机会格，双倍证据链** |

## 4. 矩阵洞察

1. **接口的演化 = "谁冻结谁"的历史**：CLIP（双塔全训）→ BLIP-2（双冻结只训桥）→ LLaVA（轻投影）——**每一步都在减少可训练参数**，与 [[60-Matrices/模型压缩矩阵]] 的 PEFT 行同构（ Adapter/LoRA 之于 LLM = 投影层之于 VLM）
2. **对比↔生成的对偶**：对比拉近表示（判别式）、生成拟合联合分布（生成式）——与 [[60-Matrices/生成模型加速矩阵]] 的 score 匹配↔FM 同构：**判别-生成对偶第二次出现**，做"对偶翻译"（对比目标的生成式等价）是 B 级模板
3. **视频是本矩阵的下一个主战场**：图像侧已饱和（CLIP→LLaVA 收束），视频侧三个格同时空缺（视频对比/视频投影加速/视频生成加速）——且与架构线（DiT）、生成加速线交叉，**"视频"是 2026-27 的交叉热点坐标**
