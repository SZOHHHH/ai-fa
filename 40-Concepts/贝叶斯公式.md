# 贝叶斯公式

## 1. 定义（直觉 → 形式）

**直觉**：**看到新证据后更新信念**。先有先验判断，来了新信息，按比例修正成后验。医生看病：先知道疾病发病率（先验），再看检查结果（证据），修正出患病概率（后验）。

**形式**：
$$p(z \mid x) = \frac{p(x \mid z)\, p(z)}{p(x)}$$
- $p(z)$：先验（没看数据前的信念）
- $p(x \mid z)$：似然（假设 $z$ 成立时看到 $x$ 的概率）
- $p(z \mid x)$：后验（看完 $x$ 后的信念）
- $p(x)$：证据（全概率 $= \int p(x \mid z) p(z) dz$，归一化常数）

## 2. 数学形式

- **后验 ∝ 似然 × 先验**（比例形式最常用，忽略 $p(x)$）
- **全概率公式**：$p(x) = \sum_z p(x \mid z) p(z)$——分母常常算不了（积分高维爆炸），这是 [[40-Concepts/ELBO]] / MCMC / VAE 存在的根本原因
- **链式应用**（扩散反向推导用）：
$$q(x_{t-1} \mid x_t, x_0) = \frac{q(x_t \mid x_{t-1}, x_0)\, q(x_{t-1}\mid x_0)}{q(x_t \mid x_0)}$$
——DDPM 后验闭式解的出发点（利用马尔可夫性质 $q(x_t\mid x_{t-1},x_0) = q(x_t \mid x_{t-1})$）

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [[30-Formulas/DDPM后验分布]] | 推导反向转移 $q(x_{t-1}\mid x_t, x_0)$ 的核心工具 |
| [[40-Concepts/ELBO]] | 后验 $p_\theta(z\mid x)$ 不可算 → 抬下界 |
| 朴素贝叶斯分类器 | 直接套公式 |
| RL / 对齐 | 贝叶斯视角的信念更新（如后验采样探索） |

## 4. 常见误区

- **误区**：后验是"更新后的概率"，不是"更准的先验"——它关于**同一事件**但**条件变了**
- **误区**：$p(x)$ 可以扔——只在不求归一化值时可行；要比较后验大小必须算或用采样绕过
- **误区**：先验随便选——敏感问题上先验强则后验被先验绑架（贝叶斯的哲学争议）
