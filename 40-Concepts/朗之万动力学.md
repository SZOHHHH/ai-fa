# 朗之万动力学 Langevin Dynamics

## 1. 定义（直觉 → 形式）

**直觉**：只用 [[40-Concepts/Score函数]] 就能采样的迭代法：每步"沿 score 方向走一小步 + 抖一点随机噪声"。score 指路，噪声防陷死。步长够小时收敛到目标分布。

**形式**：
$$x_{k+1} = x_k + \frac{\eta}{2}\, \nabla_x \log p(x_k) + \sqrt{\eta}\, \epsilon_k, \qquad \epsilon_k \sim \mathcal{N}(0, I)$$

**退火版**：$p$ 用加噪版 $p_{\sigma_i}$（$\sigma$ 从大到小），每级跑若干步——解决"低密度区 score 不准"的问题，是 SMLD 的采样器。

## 2. 数学形式

- **为什么必须有噪声项**：纯梯度走会塌到众数点，噪声维持分布形状
- **与 MCMC 的关系**：它是 MH 的特例（步长小时接受率≈1）
- **缺陷**：慢（步数极多）、对步长/噪声级敏感——被 SDE 连续化与 [[40-Concepts/采样器]] 家族取代
- **物理出身**：分子动力学中的朗之万方程：$m\ddot x = -\nabla U - \gamma \dot x + \sqrt{2\gamma}\, w$——生成模型用的是过阻尼极限

## 教程：退火两级采样（呼应 DSM 卡的同一宇宙）

**第 1 步：大 σ 级（粗定位）。** 数据点在 2 附近；当前 $x_1 = 4$（还在远处）。用 $\sigma = 2$ 级的 score（大尺度场平滑）：$s = -(x - 2)/\sigma^2 = -(4-2)/4 = -0.5$，$\eta = 0.5$：$x \leftarrow 4 + 0.25\times(-0.5) + \sqrt{0.5}\times(\text{抽 } 0.3) = 4 - 0.125 + 0.212 = 4.087$——一步小挪（大 σ 时坡缓），几十步后进入 2 的邻域。

**第 2 步：小 σ 级（精修）。** 换 $\sigma = 0.5$ 级（=[[30-Formulas/DSM目标]] 教程的宇宙）：score 变陡 $s = -(x-2)/0.25$——在 $x = 2.4$ 处 $s = -1.6$，同样步长挪 $-0.4$/步：快速贴近 2，噪声 $\sqrt\eta\,\epsilon$ 维持分布宽度（不塌成单点）。

**第 3 步：为什么要换挡。** 单用小 σ：从 4 出发时小 σ 场在远处几乎是平的（高斯尾部），走到 2 要天荒地老；单用大 σ：定位粗、终值糊——**大尺度管方向、小尺度管精度**，这就是 SMLD 的 L 档噪声链与"退火"的名字来源。

**第 4 步：连续化归宿。** 档位无限加密 = SDE（[[40-Concepts/随机微分方程（SDE）]]）——朗之万是它的离散骨架；在 Score-SDE 采样器里它还有个编制内岗位：predictor-corrector 的 **corrector**（ODE 走一步、朗之万修一步）。

## 4. 常见误区

- **误区**：朗之万 = SDE 反向——朗之万是 SDE 的一种特定形式（向平稳分布收敛），反向 SDE 是时间倒流
- **误区**：噪声项可以扔掉——扔了就不是分布采样而是众数搜索
- **误区**：步长大点更快——超过稳定性阈值直接发散

## 5. 自测

1. 更新式的三项各是什么？（score 步（方向）+ $\sqrt\eta\,\epsilon$ 噪声（防塌缩）+ 步长 $\eta$）
2. 大 σ 与小 σ 级各管什么？（方向（远处粗定位）/ 精度（邻域精修）——退火的换挡逻辑）
3. 去掉噪声项会怎样？（变成众数搜索——所有样本塌到一点，分布形状丢失）
4. 它在 Score-SDE 采样器里的岗位？（predictor-corrector 的 corrector——ODE 预测、朗之万校正）
