# 知识蒸馏 Knowledge Distillation

## 1. 定义（直觉 → 形式）

**直觉**：大模型（教师）不仅告诉学生"答案是猫"，还告诉它"我觉得 80% 是猫、15% 是狗、5% 是卡车"——**软标签携带的类间相似信息**远多于正确答案一个比特。学生学这些"暗知识"（dark knowledge），小身体装下大格局。

**形式**（Hinton KD 损失）：
$$\mathcal{L}_{\text{KD}} = \tau^2\, D_{\mathrm{KL}}\!\left( \mathrm{softmax}(z_T/\tau)\ \Big\|\ \mathrm{softmax}(z_S/\tau) \right)$$
- $z_T, z_S$：教师/学生的 logits
- $\tau$：温度——升高后分布软化，类间相对关系显形（$\tau\to\infty$ 时 ≈ 按 logits 差排序）
- 总损失通常 $= \alpha\,\mathcal{L}_{\text{KD}} + (1-\alpha)\,\mathcal{L}_{\text{CE}}$（软硬标签混合）

## 2. 数学形式

- **为什么软标签好**：硬标签是 one-hot（信息量 $\log K$ 比特里只用了 1），软标签含**负类间的结构**（猫狗相近、猫卡车无关）——梯度信号更丰富、方差更小
- **温度的数学**：$\tau$ 放大 logits 差异的相对重要性；KL 两分布随 $\tau$ 同步软化，$\tau^2$ 系数补偿梯度尺度
- **与 [[40-Concepts/KL散度]]**：KD 就是"学生分布拟合教师分布"的 KL 最小化
- **蒸馏的三种对象**：logits 蒸馏（KD）/ 特征蒸馏（中间层匹配，TinyBERT）/ 轨迹蒸馏（扩散模型步数压缩，见 [[20-Algorithms/一致性模型]]）——**同一思想在三个层面复用**

## 4. 常见误区

- **误区**：蒸馏只是"训练一个小模型"——核心是**教师信号的复用**（无教师直接训小模型效果差得多）
- **误区**：温度越高越好——过高分布过平，信息被稀释；通常 2–10
- **误区**：蒸馏与量化等价——蒸馏改**参数/结构**，量化改**数值精度**，正交可组合（QLoRA 上蒸馏很常见）
