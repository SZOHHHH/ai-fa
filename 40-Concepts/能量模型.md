# 能量模型 Energy-Based Model

## 1. 定义（直觉 → 形式）

**直觉**：给每个"世界状态"打一个能量分，能量低 = 被模型认可。概率 = 能量的玻尔兹曼指数化 + 归一化。像地形图：谷底（低能量）是数据聚集处，模型学的就是这片地形。

**形式**：
$$p_\theta(x) = \frac{1}{Z_\theta} \exp\!\left( -E_\theta(x) \right), \qquad Z_\theta = \int \exp(-E_\theta(x))\, dx$$
- $E_\theta(x)$：能量函数（神经网络，输出标量）
- $Z_\theta$：**配分函数**——全空间积分，高维下无法计算（EBM 最大的坑）

## 2. 数学形式

- **与 Score 的关系**（绕开 $Z$ 的钥匙）：
$$\nabla_x \log p_\theta(x) = -\nabla_x E_\theta(x)$$
$Z$ 与 $x$ 无关，求梯度时被消掉——所以学 [[40-Concepts/Score函数]] 不用管配分函数！
- **训练的三条路**：对比散度（Hinton RBM 时代）、MCMC 负采样、噪声对比估计 NCE——全都在"回避算 $Z$"上做文章
- **与判别式建模对比**：EBM 是"打分器"不是"生成器"——直到朗之万/SDE 采样把它变成生成模型

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [[40-Concepts/Score函数]] | score = 负能量梯度，score-based 生成的理论桥 |
| Boltzmann 机 / RBM | 深度学习史前史（2006 复兴的主角） |
| [[20-Algorithms/Score-Based生成模型]] | "score 网络 = 能量模型的梯度场" |
| 联合嵌入预测架构 JEPA（线 9 待建页）（线 9） | LeCun 世界模型的能量视角：预测的能量最低点 = 正确未来 |
| 联合能量模型 JEM、对比学习 InfoNCE | 判别器转生成 |

**历史脉络**：EBM（打分难采样）→ score matching（只学梯度，绕开 $Z$）→ 朗之万采样（score 可采样）→ SDE（连续时间统一）——一条从 1980s 统计物理直通 2021 Score-SDE 的长线。

## 4. 常见误区

- **误区**：能量小 = 概率小——**反了**！能量低（负得越多）概率越高（玻尔兹曼分布）
- **误区**：可以"归一化"能量网络——$Z$ 依赖 $\theta$ 且是全空间积分，训练中每步都变
- **误区**：score 学得好就能算 $p(x)$——不能，$Z$ 依然未知（只有相对概率可用）
