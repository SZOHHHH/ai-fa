# 马尔可夫链 Markov Chain

## 1. 定义（直觉 → 形式）

**直觉**：**忘性很好的随机游走**——下一步去哪只取决于现在在哪，与"怎么来的"无关。像棋盘上的棋子：只看当前格子和骰子，不管历史路径。

**形式**（马尔可夫性质）：
$$p(x_t \mid x_0, x_1, \dots, x_{t-1}) = p(x_t \mid x_{t-1})$$
一整条链的联合分布可以分解为初始分布 × 逐步转移：
$$p(x_0, x_1, \dots, x_T) = p(x_0) \prod_{t=1}^{T} p(x_t \mid x_{t-1})$$

## 2. 数学形式

- **转移核**：$p(x_t \mid x_{t-1})$ 决定全部动力学
- **条件独立链式简化**：任何联合概率都能拆成局部转移的乘积——这是 DDPM 训练目标能逐项拆开的根本原因
- **平稳分布**：若 $\pi(x) = \int p(x \mid x') \pi(x')\, dx'$，则 $\pi$ 是平稳分布，链走再久分布不变
- **时间参数**：离散步 $t = 0, 1, \dots, T$ 或连续时间 $t \in [0, 1]$（连续版本由 [[40-Concepts/随机微分方程（SDE）|随机微分方程]] 描述）

## 教程：手算一条两态链（转移、平稳、稳态验证）

**第 1 步：设定转移矩阵。** 天气两态（晴/雨）：
$$P = \begin{bmatrix} 0.8 & 0.2 \\ 0.4 & 0.6 \end{bmatrix}\quad（行=今天，列=明天；晴天明天 80% 仍晴）$$

**第 2 步：走两步看分布演化。** 今天 $(1, 0)$（必晴）：明天 $(0.8, 0.2)$；后天 $= (0.8,0.2)P = (0.8\times0.8+0.2\times0.4,\ 0.8\times0.2+0.2\times0.6) = (0.72, 0.28)$——**行向量右乘转移矩阵=前进一步**（矩阵连乘=走 T 步，DDPM 前向任意时刻分布就是这么叠出来的）。

**第 3 步：求平稳分布（解不动点方程）。** $\pi = \pi P$，即 $\pi_{晴} = 0.8\pi_{晴}+0.4\pi_{雨}$ 且 $\pi_{晴}+\pi_{雨}=1$：$0.2\pi_{晴}=0.4\pi_{雨}\Rightarrow\pi_{晴}=2\pi_{雨}\Rightarrow \pi=(2/3,\ 1/3)$。
**验证**：$(2/3, 1/3)P = \left(\tfrac{2}{3}\times0.8+\tfrac{1}{3}\times0.4,\ \tfrac{2}{3}\times0.2+\tfrac{1}{3}\times0.6\right) = \left(\tfrac{1.6+0.4}{3},\ \tfrac{0.4+0.6}{3}\right) = (2/3,\ 1/3)$ ✓——**再怎么转移分布都不变**。

**第 4 步：收敛读法。** 第 2 步的 $(0.72, 0.28)$ 已在滑向 $(0.667, 0.333)$；无论今天晴雨，走多了都逼近同一 $\pi$（不可约+非周期的条件下**初始被遗忘**）。DDPM 前向链的"平稳分布"= 纯噪声 $\mathcal{N}(0,I)$（无论 $x_0$ 是猫是狗，$t{=}T$ 时统统变成同一个噪声分布）——**生成=从 $\pi$ 反着走回 $x_0$**。

**第 5 步：联合分布链式分解（为什么训练能拆步）。** $p(x_0, x_1, x_2) = p(x_0)\,p(x_1\mid x_0)\,p(x_2\mid x_1)$——马尔可夫性质把 $T$ 维联合拆成 $T$ 个**局部**转移；变分下界随之拆成逐项（[[30-Formulas/DDPM训练目标]] 的推导起点）。没有这条性质，每一步都要看全历史，损失无从拆解。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| [[30-Formulas/DDPM前向过程]] | 加噪过程是马尔可夫链：$x_t$ 只依赖 $x_{t-1}$ |
| [[30-Formulas/DDPM后验分布]] | 反向去噪也是马尔可夫链，学习每一步的转移 |
| [[30-Formulas/Score-SDE前向过程]] | 连续时间极限下马尔可夫链变成 SDE |
| RL（对齐线） | MDP 本质是马尔可夫链 + 决策 + 奖励 |
| MCMC | 用马尔可夫链构造目标分布的采样器 |

**为什么生成模型偏爱马尔可夫**：一步只依赖一步 → 训练损失可以按步拆解 → 每步都是简单的局部回归/匹配问题。

## 4. 常见误区

- **误区**：马尔可夫 = 没有记忆。准确说是**只保留当前状态**所需的信息，当前状态可浓缩历史
- **误区**：DDPM 的反向链不是"倒放前向链"——前向转移已知，反向转移未知，需要学
- **误区**：马尔可夫性质是**假设**不是定理，真实数据生成过程不一定满足

## 5. 自测

1. 转移矩阵 $P=\begin{bmatrix}0.9&0.1\\0.1&0.9\end{bmatrix}$ 的平稳分布？（对称 → $(0.5, 0.5)$）
2. "分布前进一格"用矩阵怎么写？（行向量右乘 P：$\mu_{t+1} = \mu_t P$）
3. 为什么 DDPM 前向的 $t{=}T$ 分布与 $x_0$ 无关？（链收敛到唯一平稳分布 $\mathcal{N}(0,I)$——初始被遗忘）
4. 马尔可夫性质换来什么、付出什么？（换：联合可链式分解、训练可逐项拆；付：历史信息必须能压缩进当前状态——假设不一定真）
