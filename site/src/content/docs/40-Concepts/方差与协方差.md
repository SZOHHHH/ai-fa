# 方差与协方差

## 1. 定义（直觉 → 形式）

**直觉**：期望告诉你"平均水平"，**方差告诉你"离平均水平有多散"**——押注稳定性只看期望会上大当（期望赚 10% 可能一半时间亏光）。协方差=两个变量的"联动性"：你涨我也涨（正）、你涨我跌（负）、各走各的（≈0）。

**形式**：
$$\mathrm{Var}(X) = \mathbb{E}\big[(X-\mu)^2\big] = \mathbb{E}[X^2] - \mu^2 \qquad \mathrm{Cov}(X,Y) = \mathbb{E}\big[(X-\mu_X)(Y-\mu_Y)\big] = \mathbb{E}[XY] - \mu_X\mu_Y$$
标准差 $$\sigma=\sqrt{\mathrm{Var}}$$（回原量纲）；相关系数 $$=\mathrm{Cov}/(\sigma_X\sigma_Y)$$（压到 [−1,1]、去量纲）。

## 2. 教程：手算与三个关键直觉

**第 1 步：手算方差。** 数据 $$x=(2, 4, 6)$$：均值 $$\mu=4$$；离差 $$(-2, 0, 2)$$；$$\mathrm{Var}=(4+0+4)/3 \approx 2.67$$，$$\sigma\approx1.63$$——"典型偏离约 1.6 个单位"。

**第 2 步：手算协方差。** $$x=(2,4,6)$$，$$y=(10, 4, -2)$$（x 大时 y 小——肉眼看负相关）：$$\mathrm{Cov}=\mathbb{E}[xy]-\mathbb{E}x\,\mathbb{E}y = (20+16-12)/3 - 4\cdot4 = 8-16 = -8$$。负号坐实"反向联动"。相关系数 $$=-8/(1.63\times 5.66)\approx-0.87$$。

**第 3 步：协方差矩阵——把散布装进一个矩阵。** $$d$$ 维随机向量的全部两两协方差：
$$\Sigma = \begin{bmatrix} \mathrm{Var}(X_1) & \mathrm{Cov}(X_1,X_2)\\ \mathrm{Cov}(X_2,X_1) & \mathrm{Var}(X_2) \end{bmatrix}\;(\text{对称、半正定})$$
**读法**：对角线=各维自己的散布；非对角=联动。它的**特征向量方向=数据真正"摊开"的方向**（[特征值与特征向量](/ai-fa/explore/40-Concepts/特征值与特征向量) §2 PCA 的入口）——正态分布 $$\mathcal{N}(\mu,\Sigma)$$ 的椭圆等高线主轴就是 $$\Sigma$$ 的特征方向（[高斯分布](/ai-fa/explore/40-Concepts/高斯分布)）。

**第 4 步：为什么机器学习处处是它。**
- **数据预处理**：特征标准化（每维除以自己的 $$\sigma$$）——否则大量纲特征绑架距离/梯度（[过拟合与正则化](/ai-fa/explore/40-Concepts/过拟合与正则化) 的特征量纲教训）
- **批归一化**：mini-batch 内把每维拉回均值 0 方差 1——训练稳定性的核心操作（[批归一化](/ai-fa/explore/30-Formulas/批归一化)）
- **VICReg**：显式罚"表征方差别塌"（每维方差≥1 的 hinge）——防表征坍缩（[VICReg三正则](/ai-fa/explore/30-Formulas/VICReg三正则)）
- **偏差-方差分解**：泛化误差的方差项=模型对训练集抽样的敏感度（[过拟合与正则化](/ai-fa/explore/40-Concepts/过拟合与正则化) §1 的公式）
- **ELBO/变分**：后验近似的 $$\Sigma$$ 是要学的参数（对角高斯编码器输出的 logvar 就是 $$\log\sigma^2$$，[重参数化](/ai-fa/explore/40-Concepts/重参数化) 的输入）

## 3. 数学性质速查

- $$\mathrm{Var}(aX+b) = a^2\mathrm{Var}(X)$$（平移不改散布、缩放平方进方差）
- $$\mathrm{Var}(X+Y) = \mathrm{Var}X + \mathrm{Var}Y + 2\,\mathrm{Cov}(X,Y)$$——**独立才允许方差直接相加**（Cov=0 是前提）
- $$\mathrm{Var}\big[\sum X_i\big] = \sum\mathrm{Var}X_i + \sum_{i\neq j}\mathrm{Cov}$$：正联动放大波动（选股全买同一行业）、负联动抵消（这就是"均值-方差组合"的数学）
- 半正定性：$$\mathrm{Cov}$$ 矩阵的任何线性组合方差≥0——$$\Sigma$$ 永不"负"
- Cov=0 ⇏ 独立（只能说不**线性**联动；经典反例 $$Y=X^2$$ 对称分布下 Cov=0 但强相关）

## 4. 常见误区

- **误区**：方差小=风险小——方差对称惩罚上下波动；若你只怕下行，要看下半方差/分位数（金融的视角修正）
- **误区**：Cov=0=没关系——只是无线性关系（§3 反例）；且样本 Cov 本身噪声大
- **误区**：标准差和方差随便换着用——优化目标里二者梯度差 $$\frac{1}{2\sigma}$$ 倍；量纲感完全不同
- **误区**：批归一化"就是把数据标准化"——是对**每层激活**逐 mini-batch 动态做，且带可学的缩放平移；训练/推理行为不同（滑动平均），见 [批归一化](/ai-fa/explore/30-Formulas/批归一化)

## 5. 自测

1. $$X$$ 服从 $$\mathrm{Var}=9$$，$$3X+2$$ 的方差？（$$9\times9=81$$——斜率平方进方差）
2. 两个独立信号相加，方差怎么变？（相加——Cov=0 时；联动时加 2Cov 项）
3. 协方差矩阵的特征方向画出来是什么？（数据散布椭圆的主轴——PCA 主成分）
4. 为什么 VICReg 要"手动保方差"？（对比学习/蒸馏的表征坍缩=方差塌缩到 0——一切向量挤成一点，相似度全失效）
