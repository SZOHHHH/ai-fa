# 梯度惩罚 vs 谱归一化（Lipschitz 约束的两条路线）

## 1. 标准形式（一句话对照）

$$\text{GP（损失侧软约束）：}\ \lambda\,(\|\nabla_{\hat x} D\|_2 - 1)^2 \quad\text{vs}\quad \text{SN（权重侧硬归一）：}\ W \leftarrow W/\sigma(W)$$

## 2. 教程：同一道题（约束判别器 1-Lipschitz）的两种解法

**第 1 步：题目本身。** WGAN 的理论要求判别器 1-Lipschitz（[Lipschitz连续](/ai-fa/explore/40-Concepts/Lipschitz连续)）——这是**同一个数学命题**，两条路线从不同侧逼近：

**第 2 步：GP 的解法（在函数值上约束）。** "我在前线（真假插值带）装测速仪，超速就罚款"——罚项推着梯度范数向 1，但**没有物理强制**（λ 有限时永远有残余违规）。
- 优点：不对网络结构做任何事（任意判别器可用）、约束在最相关的区域
- 代价：每步多一次对输入求梯度（罚项的梯度=二阶信息）；λ 需调（默认 10 民间通用）

**第 3 步：SN 的解法（在参数上约束）。** "每层放大器出厂就限幅"——$$W/\sigma(W)$$ 后每层谱范数恰 1，**复合网络 Lipschitz ≤1 是结构保证**（无需罚、无残余违规）。
- 优点：硬保证、一步幂迭代极便宜、训练更稳（SNGAN 在 ImageNet 级的成名战）
- 代价：**容量被削**（网络想学"更陡"的表达被物理禁止）；只有上界控制（每层 ≤1 的连乘可能远小于 1，判别器可能过平）

**第 4 步：一个类比记住。** 限速：**GP=测速罚款**（司机尽量守规但可侥幸），**SN=发动机限速器**（物理上开不快但动力也封顶）。**软约束买容量、硬约束买确定**——工程学的永恒交易在 GAN 稳定化上的实例。

**第 5 步：现代去向。** 谱归一化思想外溢到别处：Transformer/扩散模型里对权重或注意力矩阵做谱控制（防爆炸/防对抗脆弱）；GP 在 diffusion 判别器、正则化流里偶用。**两条路线都没死，但 SN 的"参数侧硬约束"思想传播更远**（幂迭代是通用工具）。

## 3. 全维对照表

| 维度 | 梯度惩罚 GP | 谱归一化 SN |
|---|---|---|
| 约束位置 | 损失（插值点梯度范数） | 权重（除以最大奇异值） |
| 硬/软 | 软（残余违规存在） | **硬**（结构保证） |
| 每步成本 | 输入梯度反传（较贵） | 一次幂迭代（便宜） |
| 容量影响 | 小（只在罚方向折衷） | 大（放大率物理封顶） |
| 超参 | λ（罚强度） | 无（或一个缩放 γ） |
| 判别器类型限制 | 无 | 无（逐层可插） |
| 代表 | WGAN-GP 2017 | SNGAN 2018 |

## 4. 直觉解释

- 两者都在回答"怎么让判别器别变成无限陡的作弊器"——W 距离的良定义取决于它
- **选型经验**：要稳要快选 SN；判别器结构复杂/要求容量选 GP；实践中"都试试"仍是常态
