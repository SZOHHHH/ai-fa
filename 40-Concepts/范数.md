# 范数 Norm

## 1. 定义（直觉 → 形式）

**直觉**：向量的"长度"。范数给每个向量一个非负数值，衡量它有多大。

**形式**：
$$\|x\|_2 = \sqrt{\textstyle\sum_i x_i^2} \quad\text{(L2, 欧氏距离)},  \qquad \|x\|_1 = \textstyle\sum_i |x_i|, \qquad \|x\|_\infty = \max_i |x_i|$$

**损失函数中的标准写法**（本库规范）：
$$\|v_\theta(x_t,t) - u_t(x_t)\|_2^2$$
读作"预测速度场与目标速度场的**平方欧氏距离**"。平方是为了求导方便（$(x^2)' = 2x$ 不带根号）。

## 2. 数学形式

- **范数公理**：非负、齐次、三角不等式
- **L2 平方 = 内积**：$\|a\|_2^2 = a^\top a$
- **梯度简洁**：$\nabla_a \|a\|_2^2 = 2a$——回归损失的骨架
- **为什么不用 L1**：L2 可导处处、对应高斯噪声假设（MLE 视角：最小化 MSE ↔ 假设噪声高斯）；L1 对应拉普拉斯噪声，梯度不连续

## 教程：一个向量算四种范数（并看正则的形状差异）

**第 1 步：手算。** $x = (3, -4)$：
- $\|x\|_2 = \sqrt{9+16} = 5$（勾股定理——欧氏长度）
- $\|x\|_1 = 3+4 = 7$（曼哈顿距离——横平竖直走）
- $\|x\|_\infty = \max(3,4) = 4$（只看最大分量）
- $\|x\|_2^2 = 25$（损失函数常写平方——省根号、梯度线性 $2x$）

**第 2 步：三个数的身份差异。** 5 < 7：**L2 惩罚"分散的大"更轻、L1 更重**——这正是 L1 稀疏/L2 平滑的分歧起点（把 (7,0) 与 (3.5,3.5) 代入：L2 都是 7 与 ~4.9，L1 都是 7——**L2 偏爱均衡、L1 无偏好**，于是 L1 敢把不重要的分量推到精确零）。

**第 3 步：梯度对比（优化器视角）。** $\nabla\|x\|_2^2 = 2x$（方向=自身，线性温和）；$\nabla\|x\|_1 = \mathrm{sign}(x)$（**等值反方向、处处同力度**——不管分量多大都推固定步，小分量被一把推过零→稀疏）。谱范数（矩阵版，[[30-Formulas/谱归一化]]）=最大拉伸率，GAN 稳定化的量尺。

**第 4 步：读论文的默认规则。** 论文写 $\|\cdot\|$ 无下标=几乎总是 L2；$\|\cdot\|_2^2$=平方 L2（损失形态）；$\|\nabla_x D\|_2$（[[30-Formulas/梯度惩罚]]）=梯度向量的 L2 范数。

## 4. 常见误区

- **误区**：$\|a - b\|_2^2$ 与 $\|a\| - \|b\|$ 混淆——前者是"差再平方"，含义完全不同
- **误区**：MSE"惩罚大误差更重"是因为平方，范数本身不惩罚，平方才惩罚
- **误区**：论文写 $\|\cdot\|$ 不带下标时默认 L2，但读论文要留意（偶有 L1）

## 5. 自测

1. $x=(1, -2, 2)$ 的四种范数？（L2=3；L1=5；L∞=2；L2²=9）
2. 为什么 L1 正则产生稀疏解而 L2 不？（sign 梯度等值力推小分量过零 vs $2x$ 力度随分量缩小——零点附近 L2 推力趋零、L1 仍推）
3. 损失写平方 L2 的两个理由？（省根号求导简洁；梯度线性 $2x$ 数值温和）
4. 谱范数与向量范数的区别？（作用对象是矩阵=最大奇异值；向量范数是"长度"）
