# 扩散模型 Diffusion Models

## 1. 定义

**非数学语言**：学习"把一张图逐渐加噪到纯噪声"的逆过程。训练时反复加噪再学着猜噪声；生成时从纯噪声出发一步步去噪，图像像从雾里显影。

**数学语言**：定义前向马尔可夫链 $$q(x_t \mid x_{t-1})$$ 逐步加噪（$$t: 0 \to T$$，数据 → $$\mathcal{N}(0,I)$$），学习反向链 $$p_\theta(x_{t-1}\mid x_t)$$ 使轨迹回到数据分布。等价视角：训练 denoising score matching，采样跑反向 SDE 或概率流 ODE。

## 教程：训练循环与采样循环全程（玩具宇宙导览）

**第 1 步：训练循环（三行代码）。** 循环：①抽 $$(t, x_0, \epsilon)$$ 三元组；②闭式造题 $$x_t = \sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$$；③回归 $$\|\epsilon-\epsilon_\theta(x_t,t)\|^2$$——完整数字 walkthrough 见 [DDPM训练目标](/ai-fa/explore/30-Formulas/DDPM训练目标) 教程（$$x_2 = 2.056$$、loss 0.01、纯回归无博弈）。

**第 2 步：采样循环（从噪声雕回数据）。** 从 $$x_T\sim\mathcal{N}(0,I)$$ 出发，每步：网络猜 $$\epsilon_\theta$$ → 反解 $$\hat{x}_0$$ → 折中出 $$x_{t-1}$$——反向一步的完整手算见 [反向SDE](/ai-fa/explore/30-Formulas/反向SDE) 教程（μ=2.019、抽 z 得 2.060）；确定性版（DDIM）见 [DDIM更新规则](/ai-fa/explore/30-Formulas/DDIM更新规则)（η 旋钮两端 2.040 vs N(2.019, 0.0819²)）。

**第 3 步：两条升级线。** ①少步化：DDIM 10-50 步 → 蒸馏到 1-4 步（[一致性模型](/ai-fa/explore/20-Algorithms/一致性模型)）；②条件化：拼通道/交叉注意力（[扩散条件去噪](/ai-fa/explore/30-Formulas/扩散条件去噪)）+ 引导外推（[无分类器引导（CFG）](/ai-fa/explore/30-Formulas/无分类器引导（CFG）)：w=3 时 ε̂=1.8 越过条件预测）。

**第 4 步：理论统一。** 离散链 ↔ 连续 SDE 是同一数学（[Score-SDE前向过程](/ai-fa/explore/30-Formulas/Score-SDE前向过程)：VP 欧拉 2.037 vs DDPM 2.036）；score 派与扩散派合流（[DSM目标](/ai-fa/explore/30-Formulas/DSM目标)：s=−ε/σ 换算）。

**第 5 步：读图。** 扩散 = 前向加噪（固定）+ 反向去噪（学习）+ 训练采样解耦（同一网络、DDIM/DDPM/ODE 随便换）——**所有现代图像/视频生成的发动机**。

## 自测

1. 训练循环抽哪三个随机量？（$$t$$ / $$x_0$$ / $$\epsilon$$——闭式一步造题，回归预测噪声）
2. 采样与训练为什么解耦？（同一 $$\epsilon_\theta$$，前向/DDIM/ODE 采样器随便换——非马尔可夫前向族）
3. CFG 的 w 旋钮调什么？（条件影响的外推倍数——w=1 忠实、w>1 贴合 prompt 但多样性降）
4. 扩散对 GAN 的本质优势？（纯回归无博弈——训练稳定性来源）
