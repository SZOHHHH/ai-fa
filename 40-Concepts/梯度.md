# 梯度 Gradient

## 1. 定义（直觉 → 形式）

**直觉**：多元函数的"最陡上升方向指示器"。站在山坡任意点，梯度指向最陡上坡方向，长度是坡度大小。**负梯度 = 最快下降方向**——梯度下降的根据。

**形式**：
$$\nabla_x f(x) = \left( \frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_d} \right)^\top$$

**本库规范**：$\nabla$ **必须带下标**说明对谁求导——$\nabla_x$（对变量）、$\nabla_\theta$（对参数）。论文省略下标是常见坑点。

## 2. 数学形式

- **链式法则**（反向传播的数学本质）：$\frac{\partial f}{\partial x} = \frac{\partial f}{\partial g} \frac{\partial g}{\partial x}$
- **方向导数**：$\nabla_x f \cdot v$ = 沿 $v$ 方向的变化率
- **关键区分**：$\nabla_\theta f$（参数梯度，训练用）vs $\nabla_x f$（输入梯度，[[40-Concepts/Score函数]]、指导采样用）——扩散模型两种都在用，别混
- **梯度下降**：$\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}(\theta)$

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| 所有训练 | 反向传播 = 链式法则的工程实现 |
| [[40-Concepts/Score函数]] | $\nabla_x \log p$：对输入的梯度 |
| classifier guidance | 分类器对 $x_t$ 的梯度引导采样方向 |
| RL 策略梯度 | $\nabla_\theta \log \pi_\theta$ |
| 归一化（RMSNorm 等，线 1） | 沿梯度方向缩放特征 |

## 4. 常见误区

- **误区**：梯度指向"最优方向"——只指向**局部最陡**，不保证全局
- **误区**：$\nabla_x \log p$ 的 $x$ 是数据样本不是参数；两个"梯度"在扩散论文里频繁切换，读时盯紧下标
- **误区**：高维下梯度几乎从不为零——鞍点远多于局部极值
