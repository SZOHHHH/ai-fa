# 位置编码 Positional Encoding

## 1. 定义（直觉 → 形式）

**直觉**：注意力对输入顺序"失忆"（集合运算，谁先谁后无所谓）——但语言顺序显然重要（"狗咬人"≠"人咬狗"）。位置编码 = 给每个 token 别上一枚"位置胸牌"，随词向量一起进模型。

**形式**（三代表记法）：
- **绝对正弦**（Transformer 原文）：$PE_{(pos, 2i)} = \sin(pos/10000^{2i/d})$，$PE_{(pos,2i+1)} = \cos(\ldots)$
- **可学习绝对**（GPT/BERT）：$x + p_{\text{pos}}$，$p$ 是可训练参数
- **RoPE 旋转位置编码**（本库标准重点）：
$$\tilde q_m = R_m q, \quad \tilde k_n = R_n k, \quad \langle \tilde q_m, \tilde k_n \rangle = q^\top R_{n-m}^\top k$$
$R_\theta$ 为二维旋转矩阵块——**注意力打分只依赖相对位移 $n - m$**

## 2. 数学形式

- **RoPE 的妙处**：绝对位置旋转 → 内积自动呈现相对性（旋转矩阵 $R_m^\top R_n = R_{n-m}$）
- **外推问题**：绝对编码训练长度 $L$、推理超过 $L$ 时胸牌"查无此人"；RoPE 天然连续但频率分布仍限制外推——催生 PI/NTK/YaRN（线 6）
- **复数视角**：RoPE = 把向量按维度两两组成复数、乘 $e^{im\theta}$
- **LLM 惯例**：$\theta_i = 10000^{-2i/d}$（基频 base，NTK 缩放调的就是这个 10000）

## 教程：RoPE 二维手算（亲眼看"绝对旋转→相对打分"）

**第 1 步：先确认"失忆症"。** 把"猫 追 球"乱序成"球 追 猫"喂无位置编码的注意力：每个词的向量没变 → 打分矩阵没变 → 输出**逐位相同**（只是位置对调）——**注意力是集合算子**，顺序必须外部注入。

**第 2 步：二维 RoPE 的最小手算。** 取一对维度当复平面，位置 $m$ 旋转角 $\theta_m = m\theta$。设 $q = (1, 0)$ 在位置 0（不转），$k = (1, 0)$ 在位置 2，$\theta = \pi/4$：
$$\tilde q_0 = (1, 0), \qquad \tilde k_2 = R_{2\times\pi/4}\,(1,0)^\top = (\cos\tfrac{\pi}{2},\ \sin\tfrac{\pi}{2}) = (0, 1)$$
$$\langle \tilde q_0, \tilde k_2\rangle = 1\times0 + 0\times1 = 0$$

**第 3 步：验证相对性。** 把两个都挪远 3 位（q 在位置 3、k 在位置 5，间距仍是 2）：$\tilde q_3 = R_{3\pi/4}(1,0)$，$\tilde k_5 = R_{5\pi/4}(1,0)$；内积 $= (R_{3\pi/4}q)^\top(R_{5\pi/4}k) = q^\top R_{5\pi/4-3\pi/4}k = q^\top R_{\pi/2}k = 0$——**间距不变打分不变**（旋转矩阵正交：$R_a^\top R_b = R_{b-a}$，[[40-Concepts/内积]] §2）。绝对编码、相对效果，两头便宜。

**第 4 步：打分随间距怎么变。** 同例间距 1 时：$q^\top R_{\pi/4}k = \cos\pi/4 = 0.71$；间距 0：$\cos 0 = 1$；间距 4：$\cos\pi = -1$——**RoPE 给注意力装上了"距离衰减的振荡波"**：近处正相关、远处振荡——这就是"位置感"的数学形态（$\theta_i$ 多频段叠加=不同波长的"距离尺"，高维每两维一对配不同频率）。

**第 5 步：外推为什么难（各频率的分工）。** 高频对（波长 2π）分辨相邻位置但几步外就震荡混叠；低频对（波长 10000）量程大但分辨不出近邻——**训练只见过 [0, L] 的相位**，推理超出后低频对进入未见区域 → 性能崩。PI/NTK/YaRN 三种"频率手术"（[[30-Formulas/RoPE上下文扩展（PI-NTK-YaRN）]]）都在重新分配这套波长。

## 4. 常见误区

- **误区**：注意力"知道"位置顺序——不知道！无位置编码时是纯集合运算
- **误区**：RoPE 是相对编码——实现上是**绝对旋转**，只是数学效果上打分呈相对性
- **误区**：位置编码只能加在输入层——RoPE 作用在每层 Q/K 上（V 不旋转）

## 5. 自测

1. 无位置编码时"猫追球"与"球追猫"的输出关系？（逐位相同——集合运算，顺序盲）
2. 教程例中 q、k 都挪远 3 位，打分变吗？（不变——RoPE 只依赖相对间距）
3. 高频/低频维度对各负责什么？（近邻分辨/长程量程——多尺度"距离尺"）
4. RoPE 作用在哪些矩阵上？（每层的 Q/K；V 不旋转——位置只影响"找谁"不影响"拿什么"）
