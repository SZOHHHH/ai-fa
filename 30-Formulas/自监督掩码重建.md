# 自监督掩码重建（MAE 式）

## 1. 标准形式

$$\mathcal{L} = \mathbb{E}_{x,\,m}\Big[\tfrac{1}{|m|}\sum_{i \in m} \big\| x_i - \hat x_i \big\|^2\Big] \qquad (\text{仅掩码位计损})$$

- $m$：随机掩码（MAE：75% patch 被遮）；$\hat x = D(E(x_{\bar m}))$——**编码器只见未遮部分，解码器重建全部**
- 自监督的万能模板：遮住一部分 → 猜——无标注数据全库皆可训

## 2. 表示对照表

| 变体 | 遮什么/猜什么 | 出处 | 说明 |
|---|---|---|---|
| MLM（文本） | 遮 15% token 猜词 | BERT | 语言版鼻祖 |
| **MAE（图像，本卡）** | 遮 75% patch 猜像素 | MAE（He et al. 2022，未单独建卡） | 高遮码率是关键 |
| MaskGIT | 双向 transformer 迭代解码（生成式） | [[10-Papers/02-生成建模与扩散/MaskGIT- A Masked Generative Image Transformer（MaskGIT）]] | 预训练→生成两用 |
| JEPA 对照 | 遮住猜**表征**不猜像素 | [[40-Concepts/JEPA联合嵌入预测架构]] | 抽象层不同 |

## 教程：400 个 patch 的一场考试（75% 遮码的账单）

**第 1 步：切与遮。** 400×400 图按 16² patch 切：$25\times25 = 625$ 块（MAE 论文 224² 是 196 块——此处凑整举例）。随机遮 75%：**469 块是考题、156 块是卷面**。

**第 2 步：编码器只读卷面。** 156 个可见 patch 过 ViT——**计算量降为全图的 25%**（MAE 提速的核心：掩码不进 encoder）；不遮的版本（BERT 式全进）要为 4 倍的 token 付全款。

**第 3 步：轻量解码器答考题。** 156 个编码向量 + 469 个可学 mask token（+ 位置编码）过**小解码器**（深度仅为 encoder 的 1/4）——输出全部 625 个 patch 的重建，但**损失只算被遮的 469 块**（可见块重建对了不算本事）。

**第 4 步：为什么敢遮 75%。** 图像冗余高（相邻 patch 高度相关）：遮 15% 时"插值"就能糊弄（任务太简单学不到语义）；75% 才逼模型理解全局结构（远处的信息也得用上）——**文本遮 15% 是因为语言信息密度高，多遮就不可恢复**。遮码率 = 任务难度旋钮，随模态冗余度调。

**第 5 步：与 JEPA 的分水岭。** 同样"遮住猜"：MAE 猜像素（损失里 90% 是纹理——容量花在细节）；JEPA 猜表征（纹理已被编码器抽象掉——容量全花结构，[[40-Concepts/JEPA联合嵌入预测架构]] 教程第 4 步的信息账）。**猜什么 = 学什么层**。

## 3. 直觉解释

- **完形填空的视觉版**：遮住的部分必须靠"对全局的理解"才能补——重建误差逼出语义表征
- 高遮码率的三重红利：编码器省算力（×4）、任务够难、防作弊（局部插值失效）
- 下游用法：预训练完**丢掉解码器**，编码器接任务头——解码器是脚手架（用完即拆）

## 6. 自测

1. 625 patch 遮 75%：考题与卷面各多少？（469 考题 / 156 卷面——编码器只读卷面（计算 ×0.25））
2. 损失算哪些位？（仅掩码位——可见块重建对了不算本事）
3. 图像敢遮 75% 而文本只 15%，为什么？（图像冗余高（插值可糊弄）/语言信息密度高（多遮不可恢复）——遮码率=难度旋钮）
4. 与 JEPA 的分水岭？（猜像素 vs 猜表征——容量花在细节还是结构）
