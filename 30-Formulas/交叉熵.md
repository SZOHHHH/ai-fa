# 交叉熵 Cross-Entropy

## 1. 标准形式

$$\mathrm{CE}(p,\,q) \;=\; -\sum_i p_i \log q_i \;=\; \mathcal{H}(p) + \mathrm{KL}(p\,\Vert\,q)$$

（离散情形；$p$ = 目标分布，$q$ = 预测分布。连续情形把求和换积分。）

**最重要的恒等式（本库高频使用）**：
$$\mathrm{CE}(p, q) - \mathrm{CE}(p, p) = \mathrm{KL}(p\Vert q)\ \Longrightarrow\ p\ \text{固定时}\ \min_q \mathrm{CE} \iff \min_q \mathrm{KL}$$

**目标为 one-hot 时**（$p = e_y$）：$\mathrm{CE} = -\log q_y$ = 负对数似然（NLL）——监督分类的标准损失，one-hot 的含义见 [[40-Concepts/独热编码（One-Hot）]]。

## 教程：同一个三分类问题手算三种形态

**第 1 步：one-hot CE（硬标签）。** 真类=猫（$p=(1,0,0)$），模型 $q=(0.7, 0.2, 0.1)$：
$$\mathrm{CE} = -\log 0.7 \approx 0.357$$
押对但不够足——损失正数逼它更足（$q\to1$ 时 CE→0）。若模型押反 $q=(0.1,0.2,0.7)$：$-\log 0.1 = 2.30$——**押错的代价是对数级的**（0.7→0.1，损失 6.4 倍）。

**第 2 步：soft-CE（蒸馏形态）。** 教师 $p=(0.7, 0.25, 0.05)$（猫为主、豹其次）：$\mathrm{CE} = -(0.7\log 0.7 + 0.25\log 0.25 + 0.05\log 0.05) \approx 0.7\times0.357+0.25\times1.386+0.05\times3.00 = 0.250+0.347+0.150 = 0.747$。学生完全对齐教师时这就是下限 $\mathcal{H}(p)=0.747$（=目标熵，**再好的学生也到不了零**——soft 目标自带地板）；学生只押 one-hot 猫 $(1,0,0)$：CE $= -(0\times\ldots + 0.25\log 0 + \ldots) = \infty$——**把教师 5% 相信的豹类压到零，无穷代价**。这就是蒸馏"必须保留软性"的数学强制（[[30-Formulas/蒸馏损失]]）。

**第 3 步：logits 全流程（网络实际形态）。** logits $z=(2, 1, 0)$ → softmax $q = (0.665, 0.245, 0.090)$（[[40-Concepts/softmax函数]] §教程同款）→ 真类猫：$\mathrm{CE}=-\log 0.665\approx0.408$。**从 z 到 CE 一条链**，梯度 $\partial \mathrm{CE}/\partial z = q - p = (-0.335, 0.245, 0.090)$—— famously simple：预测减真值（softmax+CE 的绝配结局，[[40-Concepts/线性模型（回归与分类）]] §2 第 4 步）。

**第 4 步：读出恒等式在说什么。** $\mathrm{CE}(p,q)=\mathcal{H}(p)+\mathrm{KL}(p\|q)$：第 2 步里地板 0.747=$\mathcal{H}(p)$（教师自己的不确定性，谁也改变不了），超出部分 0=KL（学生对教师的偏差）。**训练能消灭的只有 KL 那一块**——这就是"min CE ⇔ min KL"的字面意义。

## 2. 表示对照表

| 表示名               | 公式核心                                 | 出处                       | 说明            |
| ----------------- | ------------------------------------ | ------------------------ | ------------- |
| one-hot CE（NLL）   | $-\log q_y$                          | 分类学习通用                   | 硬标签           |
| **soft-CE（分布目标）** | $-\sum_i p_i \log q_i$，p 为分布         | 知识蒸馏（Hinton et al. 2015） | 软目标保留教师的不确定性  |
| logits + CE       | $-\log\mathrm{softmax}(z)_y$         | 神经网络分类头                  | 数值稳定实现        |
| 二分类特例             | $-[y\log\hat y+(1-y)\log(1-\hat y)]$ | 逻辑回归                     | [[40-Concepts/sigmoid函数]] + NLL |

## 3. 直觉解释

- **一个数，量"预测分布把概率押错了多少"**：按目标 p 加权，你的 q 在真实发生的事件上给了多少概率——押得越足 CE 越小，押错方向**对数级急剧惩罚**
- **数值例（50/50 目标）**：对齐 (0.5,0.5) → CE=log2≈0.69；偏左 (0.9,0.1) → ≈1.20；坍缩恒左 (1,0) → −0.5·log0 = **+∞**——只要目标对某类还有半点概率，把它压到零就是无穷代价
- **CE = KL + 目标熵**：p 冻结时目标熵是常数，最小化 CE 与最小化 KL 完全等价——"用 CE 训练 = 在做分布匹配"的理论根据
- 为什么是"交叉"熵：$\mathrm{CE}(p,q)$ 用 **q 的编码方案**去传 **p 的事件**，平均码长——q 越不懂 p，码长越长（信息论起源）

## 6. 自测

1. one-hot 真类、$q_y = 0.01$ 与 $q_y = 0.001$ 的 CE？（4.61 vs 6.91——对数级差，押错的悬崖）
2. soft 目标 $(0.5, 0.5)$ 下学生能到的 CE 最低值？（$\log 2 \approx 0.693$ = 目标熵地板）
3. softmax+CE 对某错误 logit 的梯度？（$q_j - 0 = q_j$——把押错的概率直接往下拉）
4. 蒸馏里用 one-hot 而非 soft 目标会怎样？（类间结构丢失；教师 5% 的类被学生压零 → CE 爆炸风险/信息浪费）

## 7. 与其他公式的关系

- ≡ 分解为 $\mathcal{H}(p)+\mathrm{KL}(p\Vert q)$：最小化 CE（p 固定）⇔ 最小化 [[40-Concepts/KL散度]]
- ↔ 对照 [[30-Formulas/DSM目标|DSM目标]]（回归侧用 MSE/ℓ2）——**分类目标用 CE、标量回归用 MSE** 的分工
- → 应用：决策保真蒸馏的读出项（soft-CE 对齐冻结头读出，读出-KL 引理的承重墙）
- ↔ 出身：[[40-Concepts/最大似然估计（MLE）]]（伯努利/多项 MLE）；回归侧对手 [[30-Formulas/均方误差（MSE）]]（高斯 MLE）
