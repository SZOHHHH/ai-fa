# NSFT（专家拆子专家：MoE 细粒度 PEFT）

## 1. 一句话贡献

把 MoE 微调粒度从"整专家"再往下一层：观察到**被激活的专家内部是稀疏的**（只有一小部分中间维通道对下游任务强响应），于是 NSFT 沿中间维把每个专家拆成结构化通道组（子专家），按"路由重要性×专家内激活显著性"选任务相关子专家做稀疏部分更新，再配学习率缩放+动态梯度缩放补偿被稀释的有效更新幅度——OLMoE/Ling-mini-2.0 上稳定胜 LoRA 与专家级稀疏微调，可训参数更少且通用能力保持。

## 2. 核心贡献

- **粒度之问**：PEFT 该在什么粒度上选参更新？LoRA 在预定义权重矩阵上、专家级稀疏微调整专家都太粗——专家内部激活稀疏给出"更细一层"的实证依据
- **子专家分解+选择**：专家沿中间维拆成通道组；选择信号=路由重要性（外层：这专家被多看重）×专家内激活显著性（内层：哪些通道真在干活）——两层稀疏相乘
- **优化补偿**：稀疏部分更新让有效更新幅度变小——学习率缩放+动态梯度缩放把幅度补回来（稀疏 PEFT 常被忽视的数值细节）
- 实证：OLMoE 与 Ling-mini-2.0，领域任务+通用基准双口径，胜代表性 PEFT/专家级稀疏基线

## 3. 方法概要

1. 观察期：统计下游任务激活时专家内中间通道响应分布→证实内部稀疏（小部分通道强响应）
2. 分解：每专家 $E_e$ 沿中间维切成结构化通道组 $\{E_e^{(1)},\dots,E_e^{(m)}\}$
3. 选择：外层路由重要性定专家权重、内层激活显著性定通道组，乘起来选任务相关子专家集
4. 训练：只更新选中子专家；学习率缩放+动态梯度缩放补偿稀疏化损失的有效步长
5. 评测：领域任务性能/可训参数量/通用能力保持三轴对照 LoRA 与专家级稀疏微调

## 4. 核心公式

子专家选择（两层稀疏相乘，概念式）：

`$\mathcal{S}=\{(e,j):\ \underbrace{g(x)_e}_{\text{路由重要性}}\times\underbrace{s_e(j)}_{\text{通道组显著性}}\ >\ \tau\},\qquad \Delta\theta=\{\Delta E_e^{(j)}\}_{(e,j)\in\mathcal{S}}$`

**直觉**：外层问"这专家在路由眼里值多少钱"，内层问"这专家内部哪段通道真在为任务放电"——两个都高才值得微调；更新面从"整专家的稠密矩阵"缩到"若干通道组"，参数账单按两层稀疏的交集结算。梯度/学习率缩放则是承认"只动一小块时同样的梯度走不远"，把步长按有效更新幅度放大回去。
