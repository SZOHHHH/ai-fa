# 残差连接

## 1. 标准形式

$$y = \mathcal{F}(x) + x$$

- $\mathcal{F}(x)$：残差分支（堆叠的卷积/注意力/FFN）
- $x$：恒等捷径——原样直通
- ResNet 块：$y = \mathcal{F}(x, W) + x$；维度不匹配时 $y = \mathcal{F}(x) + W_s x$（投影捷径）

## 教程：三层链上手算梯度（亲眼看"+1"救命）

**第 1 步：设定一个纯线性三块网络。** 每块 $f_i(x) = w_i x$（不含激活——最严酷的梯度连乘场景），$w_1=w_2=w_3=0.5$：
- **无残差**：$y = w_3w_2w_1 x = 0.125x$；$\dfrac{\partial y}{\partial x} = 0.125$——三层后梯度只剩 12.5%（三十层= $0.5^{30}\approx 10^{-9}$，**信号死刑**）。
- **有残差**：$y = x + w_3(x_2 + w_2(x_1 + w_1 x))$，逐层展开 $= x(1 + w_1 + w_1w_2 + w_1w_2w_3) + \ldots$；$\dfrac{\partial y}{\partial x} = 1 + w_1 + w_1w_2 + w_1w_2w_3 = 1 + 0.5 + 0.25 + 0.125 = 1.875$——**那个 +1 永远在场**，分支衰减再多，主干梯度不灭。

**第 2 步：读出两层含义。** ①反传视角：$\frac{\partial \mathcal{L}}{\partial x} = \frac{\partial \mathcal{L}}{\partial y}(1 + \frac{\partial\mathcal{F}}{\partial x})$——**"1"是恒等直达的梯度高速路**（与 [[20-Algorithms/LSTM]] 细胞状态同构：一个在层间、一个在时间步间）；②前向视角：网络学的是 $\mathcal{H}(x)-x$（增量/修正）——"保持现状"变成最容易学的解（$\mathcal{F}\to0$ 即恒等），深网络的"什么都不做"选项从不可能变成默认。

**第 3 步：退化问题的解法现场。** 2015 年前的未解之谜：56 层普通网络训练误差**高于**20 层（不是过拟合——是训不动）。残差版 152 层误差持续下降——"更深"终于等于"不差"。此后**所有**现代架构（Transformer/MoE/UNet/扩散去噪器）的每个块都嵌在 $x+\cdots$ 里。

**第 4 步：神经 ODE 彩蛋（加深理解）。** $x_{t+1} = x_t + \mathcal{F}(x_t)$ 正是 ODE $\frac{dx}{dt} = \mathcal{F}(x)$ 的**一步欧拉**（[[40-Concepts/采样器]] §教程同款格式）——层数=离散化步数，"无限深网络"=ODE 的连续极限（Neural ODE 的出发点，也是流模型与残差网络的血缘证明）。

## 3. 直觉解释

- **要学的只是"增量"**：网络不必从零学变换 $\mathcal{H}(x)$，只需学修正量 $\mathcal{F} = \mathcal{H} - x$——"默认不变，有意见再改"
- **梯度高速公路**：$\frac{\partial y}{\partial x} = \frac{\partial \mathcal{F}}{\partial x} + 1$——那个"+1"保证梯度至少原样回流，**深网络不消失**（百层/千层成为可能）
- **为什么深而不崩**：退化问题（degradation）的实证解——更深普通网络训练误差反而更高（2015 之前未解之谜），残差一举突破
- **Transformer 的结构胶水**：每个块都是"读改写"模式——注意力/FFN 永远嵌在 $x + \ldots$ 里——现代 LLM 的所有组件（MoE、adapter）都沿用此式接入

## 6. 自测

1. 三块 $w=0.5$ 的例子中，五层残差链的 $\partial y/\partial x$ 下限是多少？（≥1——连乘项全正时=1+0.5+0.25+0.125+0.0625+0.03125≈1.97；**下限**=1（分支全零时））
2. 残差让"恒等映射"变得多容易？（$\mathcal{F}\to0$ 即可——学零比学恒等容易得多，初始化偏置天然近零）
3. 投影捷径什么时候用？（维度变化处：通道数翻倍/下采样——$W_s x$ 线性对齐）
4. 残差块与 LSTM 状态线的共同思想？（恒等直通保梯度——空间维与时间维的同构）
