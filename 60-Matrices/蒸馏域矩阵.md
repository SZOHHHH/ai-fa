# 蒸馏域矩阵（On-Policy Distillation 家族）

> [!purpose] 目标
> LLM 蒸馏从"离线模仿教师轨迹"到"在线按 token 打分"的完整版图——**用户重点关注的 OPD 方向**。本矩阵同时打通 [[60-Matrices/模型压缩矩阵]]（知识×蒸馏格）与 [[60-Matrices/RL稳定化矩阵]]（GRPO 格）：OPD 是两者的交集地带。评估见 [[00-Meta/研究矩阵规范]] §2。

## 1. 轴定义

| 轴 | 取值 | 判据 |
|---|---|---|
| **数据策略**（轨迹从哪来） | 教师生成（off-policy SFT/SeqKD）、学生生成（on-policy）、混合 | 采样分布是谁的 |
| **散度/目标**（怎么比） | 前向 KL（teacher 分布下取期望）、反向 KL（student 分布下取期望）、JSD、GKD 混合系数 α、熵自适应 | 损失函数形式 |
| **奖励密度**（信号粒度） | 序列级（0/1 结果）、token 级（逐 token 奖励）、步级（推理步）、无（纯监督） | 每条轨迹给几个反馈点 |

## 4. 矩阵洞察

1. **OPD 的数学本质 = 用 teacher 的 log 概率差当 per-token reward**：`r_t = logπ_teacher(y_t) − logπ_student(y_t)`（反向 KL 的逐 token 项）——**这就是 RL 框架里的密集过程奖励**，与 PRM（[[10-Papers/07-推理模型/Let's Verify Step by Step（PRM）]]）只在"奖励来源"上不同（teacher 分布 vs 训练的评分器）。整个家族可以写成一条公式族：`A_t = −r_t^(teacher) + λ·r^(outcome)`（PRIME 是 λ=0 teacher-free 特例，OPD 是 λ=0 teacher 特例，**机会格就是中间的 λ>0**）
2. **"聚合替代锚定"第五次出现**：OPD 的优势基线是"student 自己的 log π"（self-anchored），GAE 用历史价值估计、GRPO 用组均值、MeanFlow 用时间平均——**锚的选择决定方差**，这条思想已经五线开花（生成/RL/MoE/偏好/蒸馏）
3. **跨矩阵关系**：本矩阵是 [[60-Matrices/RL稳定化矩阵]] 与 [[60-Matrices/模型压缩矩阵]] 的桥——"蒸馏损失族 #loss/distillation" 脊的 LLM 端（压缩矩阵管 LLM 蒸馏的旧时代，本矩阵管 on-policy 新时代）
