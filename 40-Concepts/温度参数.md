# 温度参数 Temperature

## 1. 定义（直觉 → 形式）

**直觉**：控制分布"尖还是平"的旋钮。温度低 → 集中于最优（贪婪）；温度高 → 更随机（探索）。统计物理里温度高粒子乱跳、温度低沉底——AI 借用同一隐喻。

**形式**：作用于 [[40-Concepts/softmax函数]] 的指数：
$$p_i = \frac{\exp(z_i / \tau)}{\sum_j \exp(z_j / \tau)}$$
- $\tau \to 0$：趋向 argmax（one-hot）
- $\tau = 1$：原始分布
- $\tau \to \infty$：趋向均匀

## 2. 数学形式

- **一处定义、三处使用**（本库统一辨析表）：

| 场景 | 符号 | 作用 | 出现处 |
|---|---|---|---|
| 采样温度 | $T$ | 生成多样性控制 | LLM 解码（top-p 配合） |
| 蒸馏温度 | $\tau$ | 软化教师分布暴露类间结构 | [[30-Formulas/蒸馏损失]] |
| 对齐 β 的倒数视角 | $1/\beta$ | RLHF 闭式解 = 参考策略×奖励指数重加权（玻尔兹曼形式） | [[30-Formulas/RLHF目标]] §2 |

- **物理同源**：softmax = 玻尔兹曼分布（能量→概率）；温度改变占据数分布——RLHF 闭式解、能量模型、蒸馏共享**同一数学骨架**（本库跨线大统一之一）
- β 越小（温度越高）→ 策略越愿意探索低奖励高熵行为

## 教程：一个 logits 看三种温度（手算）

**第 1 步：设定。** 三类 logits $z = (2,\ 1,\ 0)$（"猫"领先）。

**第 2 步：T=1（原始 softmax）。** $\exp z = (7.39,\ 2.72,\ 1.00)$，和 $=11.11$：$p = (0.665,\ 0.245,\ 0.090)$。

**第 3 步：T=0.5（低温，更尖）。** $z/T = (4,\ 2,\ 0)$：$\exp = (54.6,\ 7.39,\ 1)$，和 $=62.98$：$p = (0.867,\ 0.117,\ 0.016)$——差距拉大（0.665→0.867）。**T→0 极限**：$\exp(2/\tau)$ 与 $\exp(1/\tau)$ 的比值 $e^{1/\tau}\to\infty$，argmax 吃满 100%。

**第 4 步：T=2（高温，更平）。** $z/T = (1,\ 0.5,\ 0)$：$p = (0.506,\ 0.307,\ 0.186)$——趋近均匀。**三个基准点连起来**：τ→0 argmax / τ=1 原始 / τ→∞ 均匀——温度只是 logits 的**统一缩放**（除 τ 等价于放大或压平差距）。

**第 5 步：蒸馏温度的用法（为什么教师要发烧）。** 教师对"猫/狗/老虎"的硬标签只告诉你猫对；T=4 的软标签可能是 $(0.6, 0.3, 0.1)$——**类间结构（狗比老虎更像猫）只在软化后可见**，这是 [[30-Formulas/蒸馏损失]] 的暗知识来源。训练用 T 高、推理还原 T=1（双向温度，别只热不冷）。

## 4. 常见误区

- **误区**：三个"温度"是同一个东西——**数学同构、用途不同**：采样温度改变行为、蒸馏温度改变信号、β 影响最优解形状
- **误区**：温度只影响分布不影响期望——对**重加权的采样**期望也变（重要性采样修正）
- **误区**：T=0 等于贪心——是（argmax），但实现上仍需处理数值下溢

## 5. 自测

1. logits (3,1) 在 T=1 与 T=0.1 下的概率？（$0.88/0.12$；$0.9999997/\approx0$——低温悬崖化）
2. 为什么蒸馏训练时学生也要用同一 T？（KL 比较的两个分布须同温——一边烧一边冷比较无意义）
3. RLHF 的 β 与温度什么关系？（$\pi^\*\propto\pi_{ref}\,e^{r/\beta}$——β 即温度：β 大=高温=策略散）
4. T 只改分布不改 logits 排序——什么时候排序也会"变"？（任何单调变换都不改 argmax；变的是**采样的行为**与期望回报，不是最优类）
