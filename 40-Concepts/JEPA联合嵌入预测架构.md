# JEPA 联合嵌入预测架构

## 1. 定义（直觉 → 形式）

**直觉**：预测"下一帧像素"浪费算力——像素里大部分是不重要的纹理。JEPA 的主张：在**表示空间**里预测——先编码成抽象表征，再预测"抽象表征"，跳过像素重建。**预测想法，不预测像素**。

**形式**（I-JEPA 架构）：
$$\mathcal{L} = \| \mathrm{pred}_\theta(E_\phi(x_{\text{ctx}}), \rho_\psi(x_{\text{target}})) - E_\phi(x_{\text{target}}) \|_2^2$$
- $E_\phi$：上下文编码器（预测起点）
- $E_\psi$：目标编码器（EMA 更新，提供预测目标）
- $\mathrm{pred}_\theta$：预测器（按目标位置条件化）
- **关键装置**：目标编码器 EMA + 预测目标 stop-gradient——防止"表示坍缩"（两个编码器都输出常数即可白拿零损失）

## 2. 数学形式

- **坍缩问题**：对比学习用负样本对抗坍缩；JEPA 用非对称结构（EMA 教师 + 预测器）——**BYOL/SimSiam 的谱系**
- **与掩码建模对比**：MAE（何恺明）重建像素；I-JEPA 预测表征——同是"遮住猜内容"，猜的对象不同
- **能量视角**（LeCun 立场论文）：预测误差 = 能量；正确未来能量低、错误未来能量高——接 [[40-Concepts/能量模型]]
- **V-JEPA**：视频版（时空遮罩 + 表征预测）；V-JEPA 2 加动作条件化与规划能力

## 教程：坍缩作弊现场与防作弊装置

**第 1 步：作弊解手算。** 若两个编码器都学"输出常数向量 $c$"：预测目标 $= c$、预测器也输出 $c$——损失 $\|c - c\|^2 = 0$，**白拿零分**而表示毫无信息。这就是表示坍缩：联合嵌入架构的天然漏洞（对比学习用负样本堵它，JEPA 不想造负样本）。

**第 2 步：防作弊装置一（EMA 教师）。** 目标编码器 $E_\psi$ 不接收梯度，只按 $\psi \leftarrow m\psi + (1-m)\phi$ 慢速跟随学生（$m = 0.996$）——作弊解要求两侧**同时**塌到同一个 $c$，但教师走得太慢：学生先塌了也追不上教师的变化，零损失拿不到——**非对称性让"共同作弊"无法同步**。

**第 3 步：防作弊装置二（预测器背锅）。** 预测器 $\mathrm{pred}_\theta$ 接收全部预测难度：目标表征变好（教师慢慢在变），预测器负责追赶——**容量花在"追"上而不是"塌"上**。

**第 4 步：信息账（为什么预测表征而非像素）。** 遮住图片 70%，猜像素：损失里 90% 是纹理细节（天空的渐变、草的噪声）——与语义无关还得花容量记；猜表征：编码器已把纹理抽象掉，预测器只学"缺的块在抽象层该是什么"——**容量全部花在结构上**。MAE（猜像素）与 I-JEPA（猜表征）的分水岭。

**第 5 步：世界模型接口。** V-JEPA 2 在表征空间加动作条件与规划——"预测想法不预测像素"的世界模型（[[20-Algorithms/世界模型]] §对比表预测式路线）；能量视角（预测误差=能量）接 [[40-Concepts/能量模型]]。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| I-JEPA（Assran et al. 2023，图像版，未单独入库） | 图像版奠基 |
| V-JEPA / V-JEPA 2 | 视频理解、机器人规划（2024–25） |
| LeCun 世界模型蓝图 | "理解-预测-规划"自主智能的理论纲领 |
| Meta 的机器人路线 | V-JEPA 2 直接用于机械臂规划 |

## 4. 常见误区

- **误区**：JEPA 是生成模型——**反着来**：明确反对像素生成（认为浪费容量在不重要细节上）
- **误区**：与 MAE 差别不大——预测目标（像素 vs 表征）导致学到的表示抽象层级完全不同
- **误区**：坍缩已完全解决——EMA/非对称只是经验有效，理论仍在发展

## 5. 自测

1. 联合嵌入架构的作弊解是什么？（两侧都输出同一常数——零损失白拿、表示无信息）
2. EMA 教师怎么防作弊？（目标编码器慢速跟随——两侧无法同步塌缩，非对称性破共同作弊）
3. 猜表征 vs 猜像素的信息账？（像素 90% 是纹理细节浪费容量；表征已抽象——容量全花结构）
4. JEPA 与 MAE 的分水岭？（预测目标：抽象表征 vs 像素——学到的抽象层级不同）
