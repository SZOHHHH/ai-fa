# 朗之万动力学 Langevin Dynamics

## 1. 定义（直觉 → 形式）

**直觉**：只用 [[40-Concepts/Score函数]] 就能采样的迭代法：每步"沿 score 方向走一小步 + 抖一点随机噪声"。score 指路，噪声防陷死。步长够小时收敛到目标分布。

**形式**：
$$x_{k+1} = x_k + \frac{\eta}{2}\, \nabla_x \log p(x_k) + \sqrt{\eta}\, \epsilon_k, \qquad \epsilon_k \sim \mathcal{N}(0, I)$$

**退火版**：$p$ 用加噪版 $p_{\sigma_i}$（$\sigma$ 从大到小），每级跑若干步——解决"低密度区 score 不准"的问题，是 SMLD 的采样器。

## 2. 数学形式

- **为什么必须有噪声项**：纯梯度走会塌到众数点，噪声维持分布形状
- **与 MCMC 的关系**：它是 MH 的特例（步长小时接受率≈1）
- **缺陷**：慢（步数极多）、对步长/噪声级敏感——被 SDE 连续化与 [[40-Concepts/采样器]] 家族取代
- **物理出身**：分子动力学中的朗之万方程：$m\ddot x = -\nabla U - \gamma \dot x + \sqrt{2\gamma}\, w$——生成模型用的是过阻尼极限

## 4. 常见误区

- **误区**：朗之万 = SDE 反向——朗之万是 SDE 的一种特定形式（向平稳分布收敛），反向 SDE 是时间倒流
- **误区**：噪声项可以扔掉——扔了就不是分布采样而是众数搜索
- **误区**：步长大点更快——超过稳定性阈值直接发散
