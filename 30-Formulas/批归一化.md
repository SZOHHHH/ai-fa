# 批归一化 Batch Normalization

## 1. 标准形式

训练（对 mini-batch $\mathcal{B}$ 内**每个特征维**独立）：
$$\hat x = \frac{x - \mu_{\mathcal B}}{\sqrt{\sigma_{\mathcal B}^2 + \epsilon}}, \qquad y = \gamma \odot \hat x + \beta$$
$$\mu_{\mathcal B} = \frac{1}{m}\sum_{i\in\mathcal B} x_i, \qquad \sigma_{\mathcal B}^2 = \frac{1}{m}\sum_{i\in\mathcal B}(x_i - \mu_{\mathcal B})^2$$
推理：用训练期积累的**滑动平均** $\mu_{run}, \sigma_{run}$（不再依赖 batch）。

## 2. 教程：一个 4 样本 batch 手算全程

**第 1 步：设定。** 某层某个神经元对 4 个样本的输出 $x = (1,\ 3,\ 5,\ 7)$（batch 维上的四个数）。

**第 2 步：算 batch 统计。** $\mu = 4$；$\sigma^2 = \frac{(9+1+1+9)}{4} = 5$，$\sigma\approx2.24$。

**第 3 步：归一。** $\hat x = \frac{x-4}{2.24} \approx (-1.34,\ -0.45,\ 0.45,\ 1.34)$——均值 0、方差 1（[[40-Concepts/方差与协方差]] 的工程化：方差归一是防漂移的核心动作）。

**第 4 步：缩放平移（γ、β 的存在理由）。** 设学出 $\gamma=2,\ \beta=1$：$y = 2\hat x + 1 = (-1.68,\ 0.11,\ 1.89,\ 3.68)$——**分布又被调回 (1, 4)**（均值=β、标准差=γ）。看起来"白忙一场"？不：①归一化发生在**每一步训练中**（分布漂移实时冻结），γ/β 是让网络**慢慢学出**想要的分布；②若某层确实需要非零均值，γ/β 给它留了后门——**"先标准化，再学回去多少由你"**。

**第 5 步：训练/推理差异（BN 最大的工程坑）。** 训练用 batch 统计（每步变），推理用滑动平均（冻结）——**batch=1 训练或推理期忘了切模式 = 分布错乱**；batch 太小时 $\sigma_{\mathcal B}$ 噪声大（BN 在小 batch/序列任务上病根，LayerNorm 的动机）。

**第 6 步：BN 改变了什么（三种读法）。** ①原论文：压制 internal covariate shift（层间分布漂移）；②后续研究：**平滑损失面**（让梯度更可预测，可用更大学习率）；③副作用=正则（batch 统计的随机性=噪声注入，[[40-Concepts/过拟合与正则化]] §3 表）。三种读法并存，工程收益无争议。

## 4. 直觉解释

- **"分布漂移的实时减震器"**：上一层参数一动，这一层看到的输入分布就变——BN 在两层之间垫一层"先把分布拉回标准位"，上下解耦
- **四件套分工**：$\mu_{\mathcal B}, \sigma_{\mathcal B}$（冻结分布）+ $\gamma, \beta$（学回想要的分布）——归一化**不是目的**，是"给分布一个稳定的起点"
- 与 [[40-Concepts/方差与协方差]] 的关系=方差操作的逐维工程化
