# 梯度 Gradient

## 1. 定义（直觉 → 形式）

**直觉**：多元函数的"最陡上升方向指示器"。站在山坡任意点，梯度指向最陡上坡方向，长度是坡度大小。**负梯度 = 最快下降方向**——梯度下降的根据。

**形式**：
$$\nabla_x f(x) = \left( \frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_d} \right)^\top$$

**本库规范**：$\nabla$ **必须带下标**说明对谁求导——$\nabla_x$（对变量）、$\nabla_\theta$（对参数）。论文省略下标是常见坑点。

## 2. 数学形式

- **链式法则**（反向传播的数学本质）：$\frac{\partial f}{\partial x} = \frac{\partial f}{\partial g} \frac{\partial g}{\partial x}$
- **方向导数**：$\nabla_x f \cdot v$ = 沿 $v$ 方向的变化率
- **关键区分**：$\nabla_\theta f$（参数梯度，训练用）vs $\nabla_x f$（输入梯度，[[40-Concepts/Score函数]]、指导采样用）——扩散模型两种都在用，别混
- **梯度下降**：$\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}(\theta)$

## 教程：一个点的最陡方向验证（含链式法则微例）

**第 1 步：设定。** $f(x,y) = x^2 + y^2$（碗面），站在点 $(3, 4)$：$f = 25$（离原点的半径 5）。

**第 2 步：算梯度。** $\nabla f = (2x, 2y) = (6, 8)$，模长 $\|\nabla f\| = 10$。

**第 3 步：验证"最陡"。** 方向导数 $\nabla f \cdot v$：沿梯度单位化 $(0.6, 0.8)$：$6\times0.6 + 8\times0.8 = 10$——**恰等于梯度的模**（任何单位方向都不可能更大，柯西不等式）；沿正交向 $(0.8, -0.6)$：$4.8 - 4.8 = 0$——**等高线方向变化率为零**（沿着碗的等高线圈走，高度不变）✓ 最陡上坡/平切两方向自检完毕。

**第 4 步：下降一步。** lr $= 0.1$：$(3,4) - 0.1\times(6,8) = (2.4, 3.2)$，$f$ 从 25 降到 $5.76 + 10.24 = 16$（半径 5→4）——负梯度确实最陡下降。

**第 5 步：链式法则微例（反向传播的原子）。** $f = \sin(g)$、$g = x^2$、$x = 1$：$\frac{dg}{dx} = 2$、$\frac{df}{dg} = \cos(1) = 0.540$ → $\frac{df}{dx} = 2\times0.540 = 1.081$——**梯度沿计算图逐段相乘**，一百层网络 = 这个乘法重复一百次（[[20-Algorithms/反向传播]] 的全部数学）。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |
|---|---|
| 所有训练 | 反向传播 = 链式法则的工程实现（详见 [[20-Algorithms/反向传播]]） |
| [[40-Concepts/Score函数]] | $\nabla_x \log p$：对输入的梯度 |
| classifier guidance | 分类器对 $x_t$ 的梯度引导采样方向 |
| RL 策略梯度 | $\nabla_\theta \log \pi_\theta$ |
| 归一化（RMSNorm 等，线 1） | 沿梯度方向缩放特征 |

## 4. 常见误区

- **误区**：梯度指向"最优方向"——只指向**局部最陡**，不保证全局
- **误区**：$\nabla_x \log p$ 的 $x$ 是数据样本不是参数；两个"梯度"在扩散论文里频繁切换，读时盯紧下标
- **误区**：高维下梯度几乎从不为零——鞍点远多于局部极值

## 5. 自测

1. $f = x^2+y^2$ 在 $(3,4)$：梯度与最陡方向导数？（$(6,8)$；沿单位化方向 = 模长 10（柯西不等式保证最大））
2. 等高线方向的方向导数？（0——高度不变的方向与梯度正交）
3. 链式法则 $\sin(x^2)$ 在 $x=1$？（$2\cos(1) = 1.081$——梯度沿计算图逐段相乘）
4. $\nabla_\theta$ 与 $\nabla_x$ 的区分？（对参数（训练用）vs 对输入（score/引导用）——扩散论文两者都在，盯紧下标）
