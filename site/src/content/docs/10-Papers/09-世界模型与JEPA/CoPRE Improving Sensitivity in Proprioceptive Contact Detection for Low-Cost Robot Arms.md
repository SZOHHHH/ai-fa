# CoPRE（无接触本体感知响应估计）

## 1. 一句话贡献

不装力/触觉传感器、不要接触标签、不要解析动力学模型——只用**无接触运动数据**训练一个"期望关节力矩预测器"，观测力矩减去期望力矩得残差，经噪声加权雅可比聚合成接触分数，把低成本机械臂（ARX L5 / Unitree G1）的弱接触检测召回率从基线的 0%/16.3%/42.2% 拉到 74.1%/82.2%，并接入 belief-space 规划完成避障放置与插书任务。

## 2. 核心贡献

- **状态排除（state exclusion）保住接触信号**：预测 $$t$$ 时刻力矩只用 $$t-H$$ 之前的观测+指令——若让预测区间内的观测进模型，参考值会"跟着接触走"、残差被吃掉；这一步是把"由果找因"的果**截断在成因之后**的关键设计
- **噪声加权雅可比聚合**：残差按各关节接触自由波动方差 $$\sigma_j$$ 加权（噪声大的关节少发言），末端力方向的物理一致性由雅可比转置统一——解决"预测误差在不同关节/动作上量级不一，单一阈值必然漏报误报两难"
- **全程无接触数据闭环**：训练（拟合名义力矩）、校准（接触自由残差分布定阈值 $$\gamma$$，误报约束下取最低）、检测（连续 3 帧超阈值确认）全不用任何接触事件标签
- **实机+下游验证**：ARX 召回 74.1%（学习力矩预测/逆动力学两基线 0%）、G1 82.2%（基线 16.3%/42.2%）；90% 检出率对应 3.5N（ARX）/5.5N（G1）推力；检测信号更新空间 belief 地图，机器人遇阻自动撤退-调姿-重试

## 3. 方法概要

1. **无接触数据采集**：只录机器人自由运动（不碰任何东西）的状态+指令：$$x_t=[q_t,\dot q_t,\tau_t]$$（关节位置/速度/控制器力矩估计）、$$u_t=[q_t^{\text{cmd}},\dot q_t^{\text{cmd}}]$$
2. **训练名义力矩预测器**（Transformer）：从 $$t-H-L+1$$ 到 $$t-H$$ 的观测+指令预测未来 $$H$$ 步状态；损失以力矩 MSE 为主、位置/速度为辅；检测只用末步力矩预测
3. **状态排除推理**：$$t$$ 时刻的参考力矩 $$\hat\tau_t$$ 由被 mask 掉 $$t-H$$ 之后观测的输入产生——近期已被接触污染的状态进不了预测器，参考值保持"无接触视角"
4. **残差→分数**：$$r_t=\tau_t-\hat\tau_t$$（先按训练残差做偏差校正），各关节残差经噪声权重 $$w_j\propto 1/\sigma_j^2$$ 缩放后由雅可比聚合为标量接触分数 $$s_t$$
5. **校准+决策**：在独立接触自由录制上选"零误报约束下的最低阈值"$$\gamma$$；连续 3 帧超阈值才报警（$$D_\gamma$$ 规则）；下游把检测结果当观测更新 belief 地图（接触=附近有障碍证据、走过路径=自由空间证据），规划器据此换落点/插书位姿

## 4. 核心公式

因果检测器形式：

`$$s_t = g_\theta(x_{1:t},\ u_{1:t}),\quad \hat c_t = D_\gamma(s_{1:t}) \in \{0,1\}$$`

**直觉**：接触与否 $$c_t$$ 是隐变量，检测器只能从"看见的状态+下过的指令"打出非负分数，再由阈值规则连续 3 帧确认——本质是学一个"这个观测像不像无接触"的似然比。

预测器损失（力矩主项+运动学辅助）：

`$$\mathcal{L} = \ell_\tau + \alpha_q\, \ell_q + \alpha_{\dot q}\, \ell_{\dot q}$$`

**直觉**：三项都是归一化坐标下的 MSE；力矩是检测唯一消费的输出，位置/速度只当辅助监督帮网络理解动力学——多任务让"名义动力学模型"学得更稳但不参与检测。

残差与噪声加权聚合（按文中思想概括）：

`$$r_t = \tau_t - \hat\tau_t^{\text{cf}},\qquad s_t = \sum_j \frac{1}{\sigma_j^2}\, \left[J^\top r_t\right]_j$$`

**直觉**：残差=观测偏离"无接触预期"的量；$$\sigma_j$$ 是关节 $$j$$ 在接触自由运动中的残差标准差——自己平时就抖得厉害的关节说"有接触"不算数；雅可比把关节空间的偏差换算到末端力方向再求和，接触力才不会因关节构型不同而时大时小。

## 5. 与前作/矩阵关系

- ↔与 [逆动力学（IDM）](/ai-fa/explore/40-Concepts/逆动力学（IDM）) 同题异构：逆动力学基线（解析 $$\tau=f(q,\dot q,\ddot q)$$）在弱接触上完败（ARX 0%），本文用**学习式名义模型+残差**替代解析模型——正是 E2 IDM 头"学习式反推替代解析"路线在接触检测上的对应物
- ↔"由果找因"思想与 E2 后验反推同族（从观测反推隐因），但此处反推的是**二值接触事件**而非动作序列，且是判别式残差检验、无生成式 WM——与 [世界模型](/ai-fa/explore/20-Algorithms/世界模型) 谱系仅方法论擦边
- ⊥划界 [DexTacWAM: A Visuo-Tactile World-Action Model for Dexterous Manipulation](/ai-fa/explore/10-Papers/09-世界模型与JEPA/DexTacWAM A Visuo-Tactile World-Action Model for Dexterous Manipulation)：那边装触觉传感器做视触觉 WM，这边明确"零额外传感器"只用电机内置信号——低成本路线与高保真路线的分叉
- ←残差检测传统（model-based 残差观测器/动量观测器）的学习化：模型误差与摩擦不再需要辨识，但保留运动学模型（雅可比）做聚合

## 6. 影响后续

- 低成本硬件接触感知的实用上限被显著推高（3.5N 级推力可检），后续"无传感器操作"工作大概率以此为基线
- 状态排除技巧对一切"预测参考+残差检测"范式通用（异常检测/OOD/故障诊断），可迁移性强
- belief-space 规划+接触反馈的闭环展示，为"检测信号直接进规划"提供了轻量模板

## 7. 读前须知

- 机器人基础：关节空间 vs 任务空间（雅可比 $$J$$ 的换算角色）、力矩估计来自电机电流
- 残差检测范式：先理解"名义模型+残差+阈值"经典套路（动量观测器一族），再看本文如何把名义模型换成学习式
- 评估口径：recall 为主指标、误报约束下选阈值——注意基线 0% 是"同阈值同规则公平对比"的结果而非基线全废
