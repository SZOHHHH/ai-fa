# 信赖域 Trust Region

## 1. 定义（直觉 → 形式）

**直觉**：一步能迈多大？在"当前策略附近一小块区域"内相信线性近似，迈出区域就不信了。**用 KL 距离画圈**：新策略与旧策略的 KL 不超过 $$\delta$$——圈内随便优化，圈外禁止。

**形式**：
$$\max_\theta\ \hat{\mathbb{E}}\!\left[ \frac{\pi_\theta(a\mid s)}{\pi_{\text{old}}(a\mid s)}\, \hat A \right] \quad \text{s.t.}\quad \hat{\mathbb{E}}\!\left[ D_{\mathrm{KL}}(\pi_{\text{old}} \| \pi_\theta) \right] \le \delta$$
- 目标线性化（一阶）、约束二次化（Fisher 信息矩阵近似 KL）
- 解法：共轭梯度 + 线搜索——TRPO 的工程复杂度来源

## 2. 数学形式

- **为什么是 KL 不是欧氏距离**：策略是分布，分布的自然度量是 KL/[Wasserstein距离](/ai-fa/explore/40-Concepts/Wasserstein距离)；KL 二阶展开 = $$\frac12 (\theta-\theta_{\text{old}})^\top F (\theta-\theta_{\text{old}})$$（$$F$$ = Fisher 矩阵）
- **自然梯度**：$$\Delta\theta \propto F^{-1}\nabla J$$——预条件梯度，对参数化不敏感
- **单调性保证**：策略改进定理（Kakade & Langford 2002）保证信赖域内更新不劣化
- **PPO 的简化路径**：硬约束（解二阶问题）→ 软惩罚（KL 加进损失）→ **裁剪**（一阶搞定）——复杂度三级跳下降

## 教程：一维信赖域手算（画圈→线性化→求解）

**第 1 步：题目。** 当前参数 $$\theta_{old}=0$$，目标真函数 $$J(\theta) = 2\theta - 3\theta^2$$（山顶在 $$\theta=1/3$$），梯度 $$J'(0)=2$$。信赖域半径 $$\delta=0.01$$（KL 意义下；一维演示中直接当 $$|\Delta\theta|\le\sqrt{\delta}$$ 的欧氏代理）。

**第 2 步：圈内线性化。** 一阶近似 $$\tilde J(\theta) \approx J(0) + 2\Delta\theta = 2\Delta\theta$$——线性近似说"$$\Delta\theta$$ 越大越好"（永远增大），**没有内部极值**，最优解必**顶到边界**：$$\Delta\theta^\* = \sqrt{\delta} = 0.1$$。

**第 3 步：真函数上验证。** $$J(0.1) = 0.2 - 0.03 = 0.17 > J(0)=0$$ ✓ 改进成立。**若贪心走线性假象**（$$\Delta\theta=1$$）：真 $$J(1) = -1$$——**线性近似在远处撒谎**，一阶信息只在圈内可信——这就是"信赖"二字的本义。

**第 4 步：第二步迭代。** 移到 $$\theta=0.1$$，新梯度 $$J'(0.1) = 2-0.6=1.4$$，再走 $$\sqrt\delta$$……**步子随接近山顶自然变缓**（梯度变小+每步重新画圈）。对比固定学习率梯度下降：信赖域的"步长"由**函数几何**（二阶曲率通过 δ 隐含）决定而非全局常数——这是它对敏感任务（RL 策略更新）更稳的根源。

**第 5 步：策略版发生了什么变化。** 参数空间画圈 → 换成**策略分布空间画圈**（KL ≤ δ）：参数动一大步但分布只准动一小步（参数化不敏感——自然梯度的动机）；目标用 [重要性采样](/ai-fa/explore/40-Concepts/重要性采样) 估计（新旧策略比值×优势）。TRPO 解这个带约束问题（共轭梯度），PPO 发现"把约束软化成裁剪"（[PPO裁剪目标](/ai-fa/explore/30-Formulas/PPO裁剪目标)）效果不打折——**信赖域思想由 PPO 继承为事实标准**。

## 4. 常见误区

- **误区**：信赖域 = 学习率——信赖域约束**策略分布**变化，学习率是参数空间标量，量纲都不同
- **误区**：KL 约束仅为稳定——还保证"语言能力不崩"（对齐线的隐性目标）
- **误区**：TRPO 严格优于 PPO——工程上 PPO 更稳更简单，TRPO 的理论优雅多在论文里

## 5. 自测

1. 教程例里若 $$\delta=0.25$$（$$\sqrt\delta=0.5$$），第一步到哪？真函数值？（$$\theta=0.5$$；$$J=0.25$$——圈变大仍改进，但离山顶 1/3 已越过，说明 δ 过大时线性化的"顶格走"开始吃亏）
2. 信赖域的"步长"由什么决定？（函数几何：圈半径+圈内线性解的位置——非常数超参）
3. 为什么 RL 用 KL 而非参数欧氏距离画圈？（策略是分布；参数化扰动（改网络结构不改变策略）不应被罚——KL 测的是行为变化）
4. PPO 裁剪与信赖域的关系？（裁剪=软信赖域的一阶实现：比值出圈的部分梯度归零）
