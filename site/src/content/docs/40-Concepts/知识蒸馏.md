# 知识蒸馏 Knowledge Distillation

## 1. 定义（直觉 → 形式）

**直觉**：大模型（教师）不仅告诉学生"答案是猫"，还告诉它"我觉得 80% 是猫、15% 是狗、5% 是卡车"——**软标签携带的类间相似信息**远多于正确答案一个比特。学生学这些"暗知识"（dark knowledge），小身体装下大格局。

**形式**（Hinton KD 损失）：
$$\mathcal{L}_{\text{KD}} = \tau^2\, D_{\mathrm{KL}}\!\left( \mathrm{softmax}(z_T/\tau)\ \Big\|\ \mathrm{softmax}(z_S/\tau) \right)$$
- $$z_T, z_S$$：教师/学生的 logits
- $$\tau$$：温度——升高后分布软化，类间相对关系显形（$$\tau\to\infty$$ 时 ≈ 按 logits 差排序）
- 总损失通常 $$= \alpha\,\mathcal{L}_{\text{KD}} + (1-\alpha)\,\mathcal{L}_{\text{CE}}$$（软硬标签混合）

## 2. 数学形式

- **为什么软标签好**：硬标签是 one-hot（信息量 $$\log K$$ 比特里只用了 1），软标签含**负类间的结构**（猫狗相近、猫卡车无关）——梯度信号更丰富、方差更小
- **温度的数学**：$$\tau$$ 放大 logits 差异的相对重要性；KL 两分布随 $$\tau$$ 同步软化，$$\tau^2$$ 系数补偿梯度尺度
- **与 [KL散度](/ai-fa/explore/40-Concepts/KL散度)**：KD 就是"学生分布拟合教师分布"的 KL 最小化
- **蒸馏的三种对象**：logits 蒸馏（KD）/ 特征蒸馏（中间层匹配，TinyBERT）/ 轨迹蒸馏（扩散模型步数压缩，见 [一致性模型](/ai-fa/explore/20-Algorithms/一致性模型)）——**同一思想在三个层面复用**

## 教程：一比特 vs 暗知识（软标签的账本）

**第 1 步：硬标签的世界。** 三分类样本（真实为猫），硬标签 $$(1, 0, 0)$$——交叉熵只对猫的 logit 产生梯度，狗和卡车收到"零"：**猫狗相似、猫卡车疏远这些结构信息全部丢失**，学生只能从"答案对错"里自己慢慢悟。

**第 2 步：软标签的世界。** 教师 logits $$(2,1,0)$$、$$\tau=4$$ 软化为 $$(0.419,\ 0.326,\ 0.254)$$（软化手算见 [归一化温度与蒸馏](/ai-fa/explore/30-Formulas/归一化温度与蒸馏) 教程）——三个类都有连续信号：猫:狗 $$= 1.29:1$$（相近）、猫:卡车 $$= 1.65:1$$（疏远）。**一次前向传递 $$\binom{3}{2} = 3$$ 对关系**；$$K$$ 类时 $$\binom{K}{2}$$ 对——暗知识的规模优势随类别数平方增长。

**第 3 步：为什么小模型更需要。** 学生参数少：①拟合硬标签容易把训练集的偶然巧合背下来（过拟合噪声）；②软标签的目标面平滑连续（相邻类的目标彼此接近），损失地形更友好——DistilBERT（参数减 40%、保留 97% 能力）的实证基础。

**第 4 步：暗知识的"暗"字。** 这些类间关系在 one-hot 评估下永远看不见（教师考 100 分与考 100 分无差别），但在**软化后的负类分布**里全部显形——蒸馏挖的是教师"会但没说"的部分。也是 [Token Ceiling](/ai-fa/explore/10-Papers/03-后处理/Breaking the Token Ceiling - Distilling Smaller Stronger Byte Models（字节蒸馏scaling）) 关心的问题的另一面：教师分布的保真度（精确 EOT 转换）决定这部分暗知识能不能无损到达 byte 学生。

**第 5 步：三个层面的复用。** logits（分布匹配）/ 特征（中间层对齐）/ 轨迹（扩散步数压缩）——同一思想三层落地的家族表见 [蒸馏损失](/ai-fa/explore/30-Formulas/蒸馏损失) §2。

## 4. 常见误区

- **误区**：蒸馏只是"训练一个小模型"——核心是**教师信号的复用**（无教师直接训小模型效果差得多）
- **误区**：温度越高越好——过高分布过平，信息被稀释；通常 2–10
- **误区**：蒸馏与量化等价——蒸馏改**参数/结构**，量化改**数值精度**，正交可组合（QLoRA 上蒸馏很常见）

## 5. 自测

1. 软标签 $$(0.419, 0.326, 0.254)$$ 比硬标签 $$(1,0,0)$$ 多传了什么？（$$\binom{K}{2}$$ 对类间相似关系——暗知识）
2. 为什么小模型从软标签受益更大？（参数少易过拟合硬标签噪声；软目标面平滑、梯度信号丰富）
3. "暗"知识暗在哪？（one-hot 评估下不可见（答案全对无差别），软化后的负类分布里显形）
4. 蒸馏的三种对象？（logits / 特征（中间层）/ 轨迹（扩散步数）——同一思想三层复用）
