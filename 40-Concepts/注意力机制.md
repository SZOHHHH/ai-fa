# 注意力机制 Attention

## 1. 定义（直觉 → 形式）

**直觉**：序列里每个词"回头看"所有其他词，按**相关度加权**吸收信息——像开会时每个人决定听谁多听谁少。相关度 = 查询向量与键向量的点积（方向越一致越相关）。

**形式**（缩放点积注意力，本库标准记号）：
$$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left( \frac{Q K^\top}{\sqrt{d_k}} \right) V$$
- $Q = XW_Q$（查询）、$K = XW_K$（键）、$V = XW_V$（值）：同一输入经三个投影
- $QK^\top \in \mathbb{R}^{n \times n}$：两两相关度矩阵
- $\sqrt{d_k}$：缩放——防点积随维度增大而过大、softmax 饱和梯度消失

## 2. 数学形式

- **多头注意力（MHA）**：$h$ 组独立 $(W_Q, W_K, W_V)$ 并行算注意力再拼接——不同头看不同关系（语法/位置/语义）
$$\mathrm{MHA}(X) = \mathrm{Concat}(\text{head}_1, \dots, \text{head}_h) W_O$$
- **多头家族谱系**（推理成本优化的演进主线）：

| 变体 | K/V 头数 | KV Cache | 出处 |
|---|---|---|---|
| MHA | $h$ | 全量 | [[10-Papers/01-架构演进/Attention Is All You Need（Transformer）]] |
| MQA（多查询） | 1 | $\frac{1}{h}$ | [[10-Papers/01-架构演进/Efficiently Scaling Transformer Inference（MQA）]] |
| GQA（分组查询） | $g$（$1<g<h$） | $\frac{g}{h}$ | [[10-Papers/01-架构演进/GQA- Training Generalized Multi-Query Transformer Models from Multi-Head Checkoffs（GQA）]] |
| MLA（多头潜在） | 潜在压缩 + 升维 | 低秩潜在 KV | [[10-Papers/01-架构演进/DeepSeek-V2- A Strong, Economical, and Efficient Mixture-of-Experts Language Model（MLA）]] |

- **softmax**：$\mathrm{softmax}(z)_i = e^{z_i}/\sum_j e^{z_j}$——把打分变概率分布（可微）
- **因果掩码**：解码时把"未来"位置置 $-\infty$ 再 softmax——自回归的语言模型不能偷看答案

## 教程：一句话怎么流过注意力层（端到端追踪"追"字）

**第 0 步：任务。** "猫 追 球"——理解"追"需要知道谁追什么。注意力前的词向量是三个孤岛（各自身份），注意力负责**按需搬运**。

**第 1 步：三个身份投影。** "追"的向量 $x_{追}$ 分别乘 $W_Q, W_K, W_V$ 得到 $q_{追}$（我找什么）、$k_{追}$（我能被怎样找到）、$v_{追}$（我携带什么货）——**每个词同时是提问者（Q）、被查者（K）、货物（V）**。

**第 2 步：打分（谁跟我相关）。** $q_{追}$ 与全部 $k$ 做内积（[[40-Concepts/内积]]）："追"对"猫"打 3.2（高相关——语义上"追"需要施动者）、对"球"打 2.8、对"追"自己打 1.1；除 $\sqrt{d_k}$ 后 softmax → 权重 $(0.45, 0.15, 0.40)$（猫/追/球）。

**第 3 步：取货混合。** $\mathrm{out}_{追} = 0.45\,v_{猫} + 0.15\,v_{追} + 0.40\,v_{球}$——**"追"的新表示里揉进了"谁追、追什么"**。逐字手算数字版见 [[30-Formulas/注意力核心公式]] §教程（两词全程）。

**第 4 步：多头分工（8 个头同时开）。** 头 1 的权重也许 $(0.8, 0.1, 0.1)$（专注句法主语）、头 2 也许 $(0.05, 0.05, 0.9)$（专注宾语）——每头用**自己的** $W_Q/W_K/W_V$ 打各自的分；Concat 后 $W_O$ 融合成"追"的最终新表示。**多头=同一句话的多张关系网**。

**第 5 步：位置与掩码（两件外挂）。** ①注意力本身**不知道词序**（打分只看向量内容）——顺序信息靠 [[40-Concepts/位置编码]] 外挂进向量；②自回归训练时未来词的 k/v 不许被看——因果掩码把未来位打分设 $-\infty$（softmax 后恰为 0 权重）。

**第 6 步：从"回头看"到 KV 缓存。** 生成第 100 个词时前 99 个词的 $k, v$ **不变**（只依赖历史词）——算一次存起来反复用=[[40-Concepts/KV缓存]]；优化这条缓存（MQA/GQA/MLA 压缩它）=§2 谱系表的全部剧情。

## 4. 常见误区

- **误区**：$\sqrt{d_k}$ 可省——不缩放时点积方差 $\propto d_k$，softmax 进饱和区、梯度消失
- **误区**：注意力权重 = 可解释性——权重热图常与因果归因不一致（学界著名争议）
- **误区**：多头 = 更强表达能力——更是**多样性**：单头也能表达，多头并行更高效
- **误区**：Q/K/V 三个矩阵必须不同——数学上允许共享（事实上一体两面：$QK^\top = X W_Q W_K^\top X^\top$，真正学的是 $W_Q W_K^\top$ 这一个组合）

## 5. 自测

1. 一个词的三个投影各扮演什么角色？（Q=我要找什么；K=我能被谁找到；V=我交出什么）
2. 注意力输出是什么数学形态？（全部位置的凸组合——权重和为 1 的加权平均）
3. 为什么注意力必须外挂位置编码？（打分只依赖向量内容，对顺序完全盲）
4. MQA→GQA→MLA 优化的是什么量？（KV cache 体积——推理显存/带宽）
