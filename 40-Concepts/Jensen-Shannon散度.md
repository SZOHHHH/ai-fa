# Jensen–Shannon 散度

## 1. 定义（直觉 → 形式）

**直觉**：两个分布"各一半混合后，与各自的信息差"。它是 [[40-Concepts/KL散度]] 的**对称化、有界版**——用两个 KL 的平均构造，消除了 KL 的不对称和无穷大问题（但没解决不重叠时的梯度消失）。

**形式**：
$$D_{\mathrm{JS}}(P \| Q) = \frac{1}{2} D_{\mathrm{KL}}\!\left( P \,\Big\|\, \frac{P+Q}{2} \right) + \frac{1}{2} D_{\mathrm{KL}}\!\left( Q \,\Big\|\, \frac{P+Q}{2} \right)$$

## 2. 数学形式

- **对称**：$D_{\mathrm{JS}}(P\|Q) = D_{\mathrm{JS}}(Q\|P)$，有界 $[0, \log 2]$
- **GAN 的等价距离**：原版 GAN 在判别器最优时，生成器的目标 = 最小化 $D_{\mathrm{JS}}(p_{\text{data}} \| p_G)$
- **致命弱点**：$P, Q$ 支撑不重叠（高维几乎必然）时 $D_{\mathrm{JS}} = \log 2$ **恒定**——梯度为零，生成器学不到任何东西。这是 GAN 训练不稳定的数学根源，也是 WGAN 换用 [[40-Concepts/Wasserstein距离]] 的全部动机

## 教程：手算一对伯努利的 JS（含"为什么不重叠=死刑"）

**第 1 步：设定与混合。** $P=(0.9, 0.1)$、$Q=(0.5, 0.5)$（与 [[40-Concepts/KL散度]] §教程同一对——方便对照）。混合 $M=\frac{P+Q}{2}=(0.7, 0.3)$。

**第 2 步：算两个 KL（借 KL 卡的分步）。**
$$D_{\mathrm{KL}}(P\|M) = 0.9\log\tfrac{0.9}{0.7} + 0.1\log\tfrac{0.1}{0.3} = 0.9\times0.251 + 0.1\times(-1.099) = 0.226-0.110 = 0.116$$
$$D_{\mathrm{KL}}(Q\|M) = 0.5\log\tfrac{0.5}{0.7} + 0.5\log\tfrac{0.5}{0.3} = 0.5\times(-0.336) + 0.5\times0.511 = 0.087$$

**第 3 步：平均。** $D_{\mathrm{JS}} = \frac{1}{2}(0.116+0.087) \approx 0.10$ nat——**换方向算不变**（M 对称构造）✓，且 $0 \le 0.10 \le \log 2 \approx 0.693$ ✓。

**第 4 步：为什么不重叠=死刑（GAN 的病根）。** 设 $P=(1, 0)$、$Q=(0, 1)$（支撑完全分离）：$M=(0.5, 0.5)$；$D_{\mathrm{KL}}(P\|M) = 1\cdot\log\frac{1}{0.5} + 0\cdot(\ldots) = \log 2$（P 为零处不再罚——**JS 把 ∞ 剪掉了**）；对称另一半同样 $\log 2$ → $D_{\mathrm{JS}}=\log 2$。**问题**：只要不重叠，无论 Q 离 P 是一步之遥还是十万八千里，JS 恒 $\log 2$——**梯度为 0，生成器失去一切学习信号**（高维空间两个低维流形几乎必然不重叠 → 原版 GAN 起步即熄火）。WGAN 改用 [[40-Concepts/Wasserstein距离]]（不重叠时也随距离线性增长，梯度永活）——这就是那张著名迁移的全部数学。

## 4. 常见误区

- **误区**：JS 有界就"好优化"——有界恰恰意味着不重叠时梯度消失
- **误区**：JS = 对称 KL——是"对混合分布的 KL 平均"，不是两个方向 KL 的平均
- **误区**：$\log 2$ 是自然对数底——是（nats）；底数 2 时上界为 1

## 5. 自测

1. $P=Q$ 时 JS=？$P,Q$ 完全分离时=？（0；$\log 2$——两端封顶）
2. JS 为什么永远有限？（KL 的 ∞ 触发点在"P 有质而 M 无质"——M 是平均，只要 P 或 Q 有质 M 就有质）
3. JS 对称但解决了"不重叠梯度消失"吗？（没有——对称与有界是另一码事；WGAN 动机正在此）
4. 为什么说 JS=两个 KL 对混合分布取平均，而不是"两个方向 KL 取平均"？（定义形式决定——对 M 的 KL 各自有限且对称）
