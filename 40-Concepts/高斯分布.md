# 高斯分布 Gaussian Distribution

## 1. 定义（直觉 → 形式）

**直觉**：钟形曲线。自然界大量现象（测量误差、噪声）近似服从它；中心极限定理保证了多个独立小扰动叠加趋近高斯。它是"最无信息"的连续分布——只知道均值和方差时的最佳猜测。

**形式**（一维）：
$$p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left( -\frac{(x-\mu)^2}{2\sigma^2} \right)$$
多维标准形式（本库标准记号）：$x \sim \mathcal{N}(\mu, \Sigma)$，各向同性时 $\Sigma = \sigma^2 I$。

## 2. 数学形式

**本库最重要的四条性质**：

1. **线性变换仍高斯**：$x \sim \mathcal{N}(\mu, \Sigma) \Rightarrow Ax + b \sim \mathcal{N}(A\mu + b,\ A\Sigma A^\top)$
2. **两高斯相加仍高斯**：$x + y \sim \mathcal{N}(\mu_x + \mu_y,\ \Sigma_x + \Sigma_y)$（独立时）
3. **条件分布是高斯**：高斯联合 → 给定一部分，另一部分的条件分布仍是高斯（DDPM 后验可算出闭式解的根源）
4. **重参数化友好**：$x = \mu + \sigma \odot \epsilon,\ \epsilon \sim \mathcal{N}(0, I)$——见 [[40-Concepts/重参数化]]

## 教程：四条性质各算一遍（数字入手）

**第 1 步：68-95-99.7（先建立量级感）。** $\mu=0,\sigma=1$：$P(|x|\le1)\approx68\%$、$P(|x|\le2)\approx95\%$、$P(|x|\le3)\approx99.7\%$。换算直觉：$\sigma=5$ 的测量误差，一次偏差超过 10 的概率约 5%——**σ 是"典型偏差"的标尺**（[[40-Concepts/方差与协方差]]）。

**第 2 步：性质 1 手算——线性变换。** $x\sim\mathcal{N}(1, \sigma^2{=}4)$，令 $y=2x+1$：$\mu_y = 2\times1+1=3$，$\sigma_y^2 = 2^2\times4=16$（**斜率平方进方差**，[[40-Concepts/方差与协方差]] §3）。DDPM 的 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$ 正是这条性质：线性组合两个高斯 → $x_t$ 仍是高斯，均值方差逐项算出（[[30-Formulas/DDPM前向过程]] 的全部秘密）。

**第 3 步：性质 2 手算——独立相加。** $x\sim\mathcal{N}(0,1)$、$y\sim\mathcal{N}(0,1)$ 独立：$x+y\sim\mathcal{N}(0, 2)$（方差**相加**，σ 变 $\sqrt2$）。配合性质 1：任意"独立高斯加权和"仍是高斯——噪声叠加世界还是高斯。

**第 4 步：性质 3（条件高斯）看一个具体形状。** 联合 $\begin{bmatrix}x\\y\end{bmatrix}\sim\mathcal{N}\!\left(\begin{bmatrix}0\\0\end{bmatrix}, \begin{bmatrix}1 & 0.5\\ 0.5 & 1\end{bmatrix}\right)$：给定 $y=1$，$x\mid y \sim \mathcal{N}(0.5\times1,\ 1-0.5^2)=\mathcal{N}(0.5,\ 0.75)$——**条件化=均值被"拉向"已知变量（按相关度）、方差缩小**（知道 y 比不知道时对 x 更有底）。DDPM 反向后验 $q(x_{t-1}\mid x_t, x_0)$ 的闭式解就是这套公式套三遍（[[30-Formulas/DDPM后验分布]]）。

**第 5 步：重参数化验证期望方差。** $x=\mu+\sigma\epsilon$：$\mathbb{E}[x]=\mu+\sigma\mathbb{E}[\epsilon]=\mu$；$\mathrm{Var}(x)=\sigma^2\mathrm{Var}(\epsilon)=\sigma^2$ ✓——分布分毫未变，只是换了生成方式。

## 3. 为什么 AI 需要它

| 出现场景 | 用法 |

| [[30-Formulas/DDPM前向过程]] | 每一步加高斯噪声，任意时刻 $x_t$ 服从闭式高斯（性质 1+2） |

| 所有扩散/流模型 | 噪声源 $z \sim \mathcal{N}(0, I)$ 是生成的起点 |
| VAE | 先验与后验都设为高斯 |
| 初始化 | 网络权重高斯初始化 |

## 4. 常见误区

- **误区**：$\mathcal{N}(0, I)$ 的 $I$ 是单位矩阵（各向同性），不是数字 1
- **误区**：高斯的"标准差 $\sigma$"与 [[40-Concepts/Score函数]]（score）无关，纯记号撞车
- **误区**：多维高斯密度里的 $\exp$ 前系数含 $(2\pi)^{-d/2}|\Sigma|^{-1/2}$，推导时漏掉会错

## 5. 自测

1. $x\sim\mathcal{N}(2, 9)$，$P(x\le 2)$=？（50%——对称中心）
2. $3x-1$ 的分布？（$\mathcal{N}(3\times2-1,\ 9\times9)=\mathcal{N}(5, 81)$）
3. 两个独立 $\mathcal{N}(0, 4)$ 相加？（$\mathcal{N}(0, 8)$——方差相加，σ² 不是 σ）
4. 条件高斯方差为什么永远 $\le$ 边缘方差？（多知道一个相关变量只会减少不确定性；缩减量由相关系数决定）
