# 残差连接

## 1. 标准形式

$$y = \mathcal{F}(x) + x$$

- $\mathcal{F}(x)$：残差分支（堆叠的卷积/注意力/FFN）
- $x$：恒等捷径——原样直通
- ResNet 块：$y = \mathcal{F}(x, W) + x$；维度不匹配时 $y = \mathcal{F}(x) + W_s x$（投影捷径）

## 2. 表示对照表

| 表示名 | 核心 | 出处 | 说明 |

| 卷积残差块 | 两三层 conv + BN + 捷径 | [[10-Papers/01-架构演进/Deep Residual Learning for Image Recognition（ResNet）]] | 原始 |

| 密集连接 DenseNet | 拼接全部前层（不是相加） | 2017 | 姊妹方案 |

## 3. 直觉解释

- **要学的只是"增量"**：网络不必从零学变换 $\mathcal{H}(x)$，只需学修正量 $\mathcal{F} = \mathcal{H} - x$——"默认不变，有意见再改"
- **梯度高速公路**：$\frac{\partial y}{\partial x} = \frac{\partial \mathcal{F}}{\partial x} + 1$——那个"+1"保证梯度至少原样回流，**深网络不消失**（百层/千层成为可能）
- **为什么深而不崩**：退化问题（degradation）的实证解——更深普通网络训练误差反而更高（2015 之前未解之谜），残差一举突破
- **Transformer 的结构胶水**：每个块都是"读改写"模式——注意力/FFN 永远嵌在 $x + \ldots$ 里——现代 LLM 的所有组件（MoE、adapter）都沿用此式接入
